Asosiy PHP Mavzu #1

PHP Nima?

PHP (PHP: Hypertext Preprocessor) — server tomonida ishlaydigan dunyodagi eng mashhur dasturlash tili. U 1994-yilda Rasmus Lerdorf tomonidan yaratilgan. Internetdagi barcha veb-saytlarning qariyb 77% dan ortig'i (jumladan WordPress, Wikipedia, Facebook ning dastlabki qismi) aynan PHP asosida ishlaydi.

  • Server tomonida (Server-side) bajariladi va brauzerga sof HTML javob qaytaradi.
  • HTML ichiga bevosita <?php ... ?> teglari bilan qulay joylashtiriladi.
  • MySQL, PostgreSQL, Oracle va boshqa ma'lumotlar bazalari bilan a'lo darajada integratsiyalashgan.
  • Laravel, Symfony kabi eng kuchli va xavfsiz zamonaviy veb freymvorklarga ega.
PHP 8 Kodi 
<?php
// PHP dagi eng birinchi dastur
echo "Assalomu alaykum, PHP Dunyosi! 🐘\n";

$sayt = "W3Learn";
$yil = 2026;

echo "Siz $sayt platformasida $yil-yilda ta'lim olyapsiz.";
?>
🖥️ Server Natijasi:
💡 PHP kodi faqat serverda bajariladi — foydalanuvchi brauzerda sahifa kodini ko'rganda PHP kodlarini hech qachon ko'ra olmaydi.

O'rnatish PHP Mavzu #2

PHP ni O'rnatish (XAMPP / WAMP)

PHP kodlarini kompyuteringizda sinab ko'rish uchun mahalliy veb-server kerak bo'ladi. Buning uchun eng qulay yo'l — bir vaqtning o'zida Apache, MySQL va PHP ni o'rnatib beruvchi XAMPP dasturidir.

  • XAMPP rasmiy sayti: apachefriends.org dan yuklab olinadi.
  • XAMPP Control Panel orqali Apache va MySQL xizmatlari 'Start' qilinadi.
  • Loyihalar papkasi: C:\xampp\htdocs\mening-saytim.
  • Brauzerda ochish: http://localhost/mening-saytim/index.php.
PHP 8 Kodi 
<?php
// PHP versiyasini va server sozlamalarini ko'rish
echo "PHP Versiyasi: " . phpversion() . "\n";
echo "Server dasturi: " . $_SERVER['SERVER_SOFTWARE'];
?>
🖥️ Server Natijasi:
⚡ XAMPP ning htdocs papkasi sizning mahalliy serveringizning asosiy ildiz papkasi (root directory) hisoblanadi.

Asoslar PHP Mavzu #3

Asosiy Sintaksis va Izohlar

PHP skripti doimo <?php bilan boshlanadi va ?> bilan tugaydi. Har bir buyruq oxirida albatta nuqta-vergul ; qo'yilishi shart.

  • Chiqarish operatorlari: echo (tezroq va bir nechta parametr oladi) va print.
  • Bir qatorli izoh: // yoki #.
  • Ko'p qatorli izoh: /* ... */.
  • Katta-kichik harflar: kalit so'zlar (if, echo, class) sezgir emas, ammo o'zgaruvchilar sezgir!
PHP 8 Kodi 
<?php
// Bu bir qatorli izoh
# Bu ham bir qatorli izoh

/*
 Bu esa ko'p qatorli
 batafsil izohdir
*/

ECHO "Kalit so'zlar katta-kichik harfga sezgir emas!\n";
echo "Lekin o'zgaruvchi nomlari sezgir.";
?>
🖥️ Server Natijasi:
📌 Faqat PHP kodidan iborat bo'lgan fayllarda oxirgi ?> yopilish tegini qo'ymaslik xavfsizlik va bo'shliqlar xatosini oldini oladi.

Asoslar PHP Mavzu #4

O'zgaruvchilar va Ma'lumot Turlari

PHP da barcha o'zgaruvchilar dollar belgisi $ bilan boshlanadi. PHP dinamik tiplashtirilgan til bo'lib, o'zgaruvchi turini avtomatik aniqlaydi.

  • Nomlash: harf yoki pastki chiziq bilan boshlanadi: $ism, $_yosh.
  • Asosiy turlar: String, Integer, Float, Boolean, Array, Object, NULL.
  • Ma'lumot turini va qiymatini to'liq ko'rish uchun var_dump() ishlatiladi.
  • O'zgarmaslar (Konstantalar): define('SAYT_NOMI', 'W3Learn'); yoki const PI = 3.14;.
PHP 8 Kodi 
<?php
$matn = "Dasturlash";       // String
$son = 42;                  // Integer
$narx = 19.99;              // Float
$mavjud = true;             // Boolean
$bosh = null;               // NULL

define("MAKTAB", "W3Learn Akademiyasi");

echo MAKTAB . "\n";
var_dump($narx);
var_dump($mavjud);
?>
🖥️ Server Natijasi:
💡 Satrlarni bir-biriga ulash (konkatenatsiya) uchun plyus + emas, balki nuqta . belgisi ishlatiladi.

Asoslar PHP Mavzu #5

Matn (String) va Satr Funksiyalari

PHP da satrlar bir tirnoq ' yoki qo'shtirnoq " ichida yoziladi. Qo'shtirnoq ichidagi o'zgaruvchilar avtomatik tarzda qiymatiga aylanadi (interpolatsiya).

  • strlen($matn) — satr uzunligini (baytlarda) hisoblaydi.
  • mb_strlen($matn) — o'zbekcha va kirill harflari uzunligini to'g'ri o'lchaydi.
  • str_replace('eski', 'yangi', $matn) — so'zni almashtirish.
  • strtoupper() va strtolower() — katta/kichik harfga o'tkazish.
  • explode(',', $satr) — matnni massivga bo'lish.
PHP 8 Kodi 
<?php
$ism = "Sardor";
echo "Salom, $ism! (Qo'shtirnoqda ishlaydi)\n";
echo 'Salom, $ism! (Bir tirnoqda matn deb o\'ylaydi)\n';

$xabar = "PHP o'rganish juda qiziq";
echo "Uzunligi: " . strlen($xabar) . " belgi\n";
echo "Almashtirish: " . str_replace("qiziq", "oson", $xabar);
?>
🖥️ Server Natijasi:
📌 Kirill yoki o'zbek harflari (o', g') bilan ishlaganda doimo mb_ prefiksli funksiyalardan (mb_substr, mb_strtoupper) foydalaning.

Asoslar PHP Mavzu #6

Massivlar (Indeksli va Assotsiativ)

PHP da massivlar (Arrays) juda moslashuvchan. Ular ham oddiy raqamli indeksli, ham kalit-qiymatli (assotsiativ) bo'lishi mumkin.

  • Indeksli massiv: $mevalar = ['Olma', 'Banan', 'Uzum'];
  • Assotsiativ massiv: $user = ['ism' => 'Ali', 'yosh' => 25];
  • Element qo'shish: $mevalar[] = 'Anor'; yoki array_push().
  • Elementlar soni: count($mevalar).
  • Chiqarib ko'rish: print_r($user).
PHP 8 Kodi 
<?php
// Assotsiativ massiv
$talaba = [
    "ism" => "Zarina",
    "kurs" => "Backend",
    "ball" => 94
];

$talaba["stipendiya"] = true; // Yangi element qo'shish

echo "Talaba: " . $talaba["ism"] . "\n";
echo "Kurs: " . $talaba["kurs"] . "\n";
echo "Jami maydonlar: " . count($talaba);
?>
🖥️ Server Natijasi:
💡 PHP dagi massivlar aslida tartiblangan xesh-jadval (Hash Map) hisoblanadi.

Asoslar PHP Mavzu #7

Shart Operatorlari (if, else, switch, match)

Dastur mantig'ini boshqarish uchun shart operatorlari xizmat qiladi. PHP 8.0 dan boshlab zamonaviy va xavfsiz match ifodasi qo'shilgan.

  • Standart: if ($shart) { ... } elseif ($shart2) { ... } else { ... }
  • Ternar operator: $natija = ($yosh >= 18) ? 'Katta' : 'Kichik';
  • Null Coalescing: $ism = $_GET['ism'] ?? 'Mehmon';
  • match ifodasi — qat'iy tekshiruvchi (strict ===) va qiymat qaytaruvchi zamonaviy switch.
PHP 8 Kodi 
<?php
$statusKodi = 200;

// PHP 8 zamonaviy match ifodasi
$xabar = match($statusKodi) {
    200, 201 => "✅ Muvaffaqiyatli so'rov",
    400 => "❌ Noto'g'ri so'rov",
    404 => "🔍 Sahifa topilmadi",
    500 => "⚠️ Server xatosi",
    default => "Noma'lum status"
};

echo "Natija: " . $xabar;
?>
🖥️ Server Natijasi:
📌 match ifodasida break yozish shart emas va u avtomatik qiymat qaytaradi.

Asoslar PHP Mavzu #8

Sikllar (for, while, foreach)

Amallarni takrorlash uchun sikllar ishlatiladi. Massivlar va obyektlar bo'ylab aylanishda eng ko'p ishlatiladigani — bu foreach siklidir.

  • for ($i = 0; $i < 5; $i++) — aniq qadamli takrorlash.
  • while ($shart) — shart to'g'ri turguncha takrorlash.
  • foreach ($massiv as $qiymat) — massiv elementlari bo'ylab aylanish.
  • foreach ($massiv as $kalit => $qiymat) — kalit va qiymatni birga olish.
PHP 8 Kodi 
<?php
$narxlar = [
    "Non" => 3000,
    "Sut" => 9000,
    "Go'sht" => 85000
];

echo "Bozorlik ro'yxati:\n";
foreach ($narxlar as $mahsulot => $narx) {
    echo " • $mahsulot: $narx so'm\n";
}
?>
🖥️ Server Natijasi:
💡 foreach siklida massiv qiymatini to'g'ridan-to'g'ri o'zgartirish uchun havola belgisi qo'yiladi: foreach ($arr as &$val).

Asoslar PHP Mavzu #9

Funksiyalar va Qat'iy Tiplashtirish (Type Hinting)

PHP da funksiyalar function kalit so'zi bilan yaratiladi. Zamonaviy PHP 8 da argumentlar va qaytish qiymatiga aniq turlar ko'rsatish (Type Hinting) tavsiya etiladi.

  • E'lon qilish: function qoshish(int $a, int $b): int { return $a + $b; }
  • Standart qiymatlar: function salom($ism = 'Mehmon').
  • Ixtiyoriy argumentlar: ?string (yoki string, yoki null bo'lishi mumkin).
  • Nomsiz funksiyalar va Arrow functions: fn($x) => $x * 2;.
PHP 8 Kodi 
<?php
// Qat'iy tiplashtirilgan funksiya
function chegirmaHisobla(float $narx, float $foiz = 10.0): float {
    $chegirma = $narx * ($foiz / 100);
    return $narx - $chegirma;
}

$aslNarx = 100000.0;
$yakuniy = chegirmaHisobla($aslNarx, 15.0);

echo "Asl narx: $aslNarx so'm\n";
echo "15% chegirma bilan: $yakuniy so'm";
?>
🖥️ Server Natijasi:
📌 Fayl boshiga declare(strict_types=1); qo'yilsa, noto'g'ri tur kiritilganda darhol xatolik chiqaradi.

OOP PHP Mavzu #10

OOP — Klasslar va Obyektlar

Obyektga Yo'naltirilgan Dasturlash (OOP) yirik loyihalarni tartibli qilish uchun eng muhim uslubdir. Klass shablon bo'lib, undan new operatori orqali obyektlar olinadi.

  • Ko'rinish darajalari (Access Modifiers): public (hamma joyda ochiq), protected (faqat vorislarda), private (faqat o'zida).
  • Konstruktor: public function __construct().
  • Joriy obyektga murojaat: $this->xossa.
  • PHP 8 Constructor Property Promotion: konstruktor parametrining o'zidayoq xossani e'lon qilish mumkin.
PHP 8 Kodi 
<?php
class Foydalanuvchi {
    // PHP 8 qisqa konstruktor
    public function __construct(
        public string $ism,
        public string $email,
        private string $parol
    ) {}

    public function getInfo(): string {
        return "👤 {$this->ism} ({$this->email})";
    }
}

$user1 = new Foydalanuvchi("Alijon", "ali@mail.uz", "parol123");
echo $user1->getInfo();
?>
🖥️ Server Natijasi:
💡 PHP 8 dagi public function __construct(public string $ism) usuli kod hajmini ikki barobar qisqartiradi.

OOP PHP Mavzu #11

OOP — Merosxo'rlik (Inheritance)

Merosxo'rlik — bir klass boshqa klassning imkoniyatlarini extends kalit so'zi orqali o'zlashtirib olishidir.

  • Sintaksis: class Admin extends Foydalanuvchi.
  • Ota klass konstruktorini chaqirish: parent::__construct().
  • Metodni qayta yozish (Override): ota klass metodini bola klassda o'zgartirish.
  • final kalit so'zi — klass yoki metoddan meros olishni taqiqlaydi.
PHP 8 Kodi 
<?php
class Xodim {
    public function __construct(public string $ism, public int $maosh) {}

    public function ishla(): string {
        return "{$this->ism} ishlamoqda...";
    }
}

class Dasturchi extends Xodim {
    public function __construct(string $ism, int $maosh, public string $til) {
        parent::__construct($ism, $maosh);
    }

    public function ishla(): string {
        return "💻 {$this->ism} {$this->til} tilida kod yozmoqda!";
    }
}

$dev = new Dasturchi("Jasur", 2000, "PHP/Laravel");
echo $dev->ishla();
?>
🖥️ Server Natijasi:
📌 PHP faqat bitta klassdan to'g'ridan-to'g'ri meros olishga ruxsat beradi (Single Inheritance).

OOP PHP Mavzu #12

OOP — Interface va Abstraktsiya

Interface — klasslar qanday metodlarni amalga oshirishi shartligini belgilovchi qat'iy shartnomadir. implements kalit so'zi bilan ulanadi.

  • Interface ichidagi barcha metodlar faqat e'lon qilinadi, tanasi (body) bo'lmaydi.
  • Bir klass bir vaqtning o'zida bir nechta interfeyslarni qabul qilishi mumkin.
  • To'lov tizimlari (Payme, Click, Uzum) uchun yagona interfeys yaratishda keng qo'llaniladi.
  • Abstrakt klass (abstract class) ham qisman yozilgan, ham yozilmagan metodlarni saqlaydi.
PHP 8 Kodi 
<?php
interface TolovTizimi {
    public function tolovQil(int $summa): string;
}

class ClickTolov implements TolovTizimi {
    public function tolovQil(int $summa): string {
        return "💳 Click orqali $summa so'm to'landi.";
    }
}

class PaymeTolov implements TolovTizimi {
    public function tolovQil(int $summa): string {
        return "💳 Payme orqali $summa so'm to'landi.";
    }
}

$tolov = new ClickTolov();
echo $tolov->tolovQil(50000);
?>
🖥️ Server Natijasi:
💡 Interfeyslar Dependency Injection va toza arxitektura (SOLID tamoyillari) ning asosi hisoblanadi.

OOP PHP Mavzu #13

Trait — Kodlarni Qayta Ishlatish

PHP da bir vaqtda faqat bitta ota klassdan meros olish mumkin. Trait esa bir xil metodlarni turli mustaqil klasslar ichiga osongina qo'shish (mix-in) imkonini beradi.

  • E'lon qilish: trait LogYozuvchi { ... }
  • Klass ichida ishlatish: use LogYozuvchi;
  • Bir nechta traitlarni vergul bilan ulash mumkin.
  • Laravel freymvorkida (masalan, HasFactory, Notifiable) keng qo'llaniladi.
PHP 8 Kodi 
<?php
trait Logger {
    public function log(string $xabar): void {
        echo "📝 [LOG " . date('H:i') . "]: $xabar\n";
    }
}

class Buyurtma {
    use Logger; // Trait ulandi

    public function yarat(): void {
        $this->log("Buyurtma yaratildi");
    }
}

$b = new Buyurtma();
$b->yarat();
?>
🖥️ Server Natijasi:
📌 Trait dan to'g'ridan-to'g'ri new Trait() deb obyekt yaratib bo'lmaydi.

OOP PHP Mavzu #14

Namespace (Nomlar Fazosi)

Namespace — bir xil nomli klasslar, funksiyalar va konstantalar bir-biri bilan to'qnashib qolmasligi uchun loyihani mantiqiy papkalarga ajratish usulidir.

  • Faylning eng birinchi qatorida e'lon qilinadi: namespace App\Services;
  • Boshqa nomlar fazosidagi klassni chaqirish: use App\Models\User;
  • Katta kutubxonalar va Composer paketlarida nomlar chalkashmasligini ta'minlaydi.
  • Teskari slash \ bilan qismlarga bo'linadi.
PHP 8 Kodi 
<?php
namespace App\Hisob;

class Hisoblagich {
    public static function kvadrat(int $x): int {
        return $x * $x;
    }
}

// Boshqa joyda ishlatish:
// use App\Hisob\Hisoblagich;
echo "5 ning kvadrati: " . \App\Hisob\Hisoblagich::kvadrat(5);
?>
🖥️ Server Natijasi:
💡 Standart PHP klasslariga (masalan, Exception, DateTime) murojaat qilishda boshiga teskari slash qo'yiladi: new \DateTime().

Web PHP Mavzu #15

Formalar bilan Ishlash ($_GET va $_POST)

HTML formalaridan yuborilgan ma'lumotlarni qabul qilish uchun PHP ning superglobal massivlari — $_GET va $_POST ishlatiladi.

  • $_GET — ma'lumotlar URL manzil orqali uzatiladi (qidiruv, filtrlar uchun).
  • $_POST — ma'lumotlar HTTP so'rov tanasida maxfiy uzatiladi (parol, to'lov uchun).
  • Xavfsizlik: XSS xujumining oldini olish uchun htmlspecialchars() ishlatilishi shart!
  • Tekshirish: isset($_POST['tugma']) orqali forma yuborilganini bilish mumkin.
PHP 8 Kodi 
<?php
// Xayoliy forma qabul qilish namunasi
$_POST['ism'] = "Olimjon";
$_POST['email'] = "olim@uz.uz";

if ($_SERVER["REQUEST_METHOD"] === "POST") {
    // Xavfsiz tozalash
    $ism = htmlspecialchars($_POST['ism']);
    $email = filter_var($_POST['email'], FILTER_VALIDATE_EMAIL);
    
    echo "✅ Qabul qilindi: $ism ($email)";
}
?>
🖥️ Server Natijasi:
⚠️ Hech qachon $_POST['ism'] ni to'g'ridan-to'g'ri ekranga chiqarmang yoki bazaga yozmang — doim filtrlang!

Web PHP Mavzu #16

Session va Cookie (Sessiyalar)

Foydalanuvchi sahifadan sahifaga o'tganda uning login holatini va savatchasidagi tovarlarni saqlab turish uchun Session va Cookie ishlatiladi.

  • Sessiyani boshlash: fayl boshida albatta session_start(); yoziladi.
  • Sessiyaga yozish: $_SESSION['user_id'] = 42;
  • Cookie o'rnatish: setcookie('til', 'uz', time() + 3600 * 24);
  • Sessiyani to'liq o'chirish (Logout): session_destroy();.
PHP 8 Kodi 
<?php
session_start();

// Foydalanuvchi ma'lumotini eslab qolish
$_SESSION['user'] = "Botir";
$_SESSION['rol'] = "admin";

echo "Sessiya ochildi! Foydalanuvchi: " . $_SESSION['user'] . "\n";
echo "Sessiya ID: " . session_id();
?>
🖥️ Server Natijasi:
📌 session_start() har qanday HTML yoki echo chiqishidan OLDIN chaqirilishi shart, aks holda xatolik beradi.

Web PHP Mavzu #17

Fayllarni Serverga Yuklash ($_FILES)

Foydalanuvchilar tomonidan rasm, hujjat yoki videolarni serverga yuklash uchun HTML formasi enctype="multipart/form-data" ga ega bo'lishi va PHP da $_FILES massivi ishlatilishi kerak.

  • $_FILES['rasm']['name'] — faylning asl nomi.
  • $_FILES['rasm']['tmp_name'] — serverdagi vaqtinchalik saqlangan joyi.
  • $_FILES['rasm']['size'] — baytlardagi hajmi.
  • Ko'chirish: move_uploaded_file($tmp, $maqsad).
  • Xavfsizlik: faqat ruxsat etilgan kengaytmalarni (jpg, png, pdf) qabul qilish kerak.
PHP 8 Kodi 
<?php
// Yuklash mantiqi namunasi
$ruxsat = ['image/jpeg', 'image/png'];
$faylTuri = 'image/jpeg';
$faylHajmi = 1024 * 500; // 500 KB

if (in_array($faylTuri, $ruxsat) && $faylHajmi < 2000000) {
    echo "✅ Fayl talablarga to'liq javob beradi va yuklandi!";
} else {
    echo "❌ Noto'g'ri format yoki katta hajm!";
}
?>
🖥️ Server Natijasi:
⚠️ Fayllar nomini saqlashda ularni uniqid() bilan yangilash boshqa fayllar ustidan yozilib ketishini oldini oladi.

Web PHP Mavzu #18

Email Yuborish (mail va PHPMailer)

PHP da xatlarni yuborish uchun oddiy mail() funksiyasi bor, ammo zamonaviy loyihalarda SMTP orqali xavfsiz va kafolatli yuboruvchi PHPMailer kutubxonasi ishlatiladi.

  • Standart: mail($qayerga, $mavzu, $xat, $headers).
  • PHPMailer — Gmail, Yandex yoki shaxsiy pochta serverlari (SMTP) orqali yuboradi.

PDO (PHP Data Objects) — Xavfsiz Baza Ulanishi

PDO — PHP da ma'lumotlar bazalari (MySQL, PostgreSQL, SQLite) bilan ishlashning eng zamonaviy, universal va xavfsiz usulidir. U SQL Injection hujumlaridan to'liq himoyalaydi.

  • Prepared Statements: so'rov va parametrlar alohida uzatiladi.
  • Turli bazalar uchun bir xil kod: MySQL dan PostgreSQL ga o'tish juda oson.
  • Ulanish: new PDO("mysql:host=localhost;dbname=test", "root", "");
  • Xatoliklarni Exception sifatida ushlash imkoniyati.
PHP 8 Kodi 
<?php
try {
    // Xotiradagi SQLite bazasiga ulanish

    $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);

Ilg'or PHP Mavzu #25

Veb Xavfsizlik (SQL Injection, XSS, CSRF)

Saytni buzg'unchilar (hackerlar) hujumidan himoya qilish har bir backend dasturchining birinchi galdagi vazifasidir.

  • SQL Injection dan himoya: PDO Prepared Statements ishlatish.
  • XSS (Cross-Site Scripting) dan himoya: matnlarni htmlspecialchars() bilan tozalash.
  • CSRF (Cross-Site Request Forgery) dan himoya: har bir formaga maxfiy token qo'yish.
  • Parollarni himoyalash: password_hash() va password_verify() dan foydalanish.
PHP 8 Kodi 
<?php
// Parolni xavfsiz shifrlash
$parol = "maxfiy123";
$xesh = password_hash($parol, PASSWORD_BCRYPT);

echo "Xavfsiz xesh: " . substr($xesh, 0, 30) . "...\n";

// Tekshirish
if (password_verify("maxfiy123", $xesh)) {
    echo "✅ Parol to'g'ri, xavfsiz kirish tasdiqlandi!";
}
?>
🖥️ Server Natijasi:
⚠️ Hech qachon parollarni md5() yoki sha1() bilan shifrlamang — bu usullar eskirgan va osonlikcha buziladi!
