Asosiy Vue Mavzu #1

Vue.js Nima?

Vue.js — foydalanuvchi interfeyslarini yaratish uchun mo'ljallangan ilg'or (progressive) JavaScript freymvorki. Evan You tomonidan yaratilgan bo'lib, o'rganishga eng oson va intuitiv frontend vositalaridan biridir.

  • Progressive: bitta oddiy HTML sahifaga kutubxona sifatida ulab ishlatish ham, ulkan Single Page Application (SPA) lar qurish ham mumkin.
  • Reaktivlik (Reactivity System): ma'lumotlar o'zgarganda DOM avtomatik va bir zumda yangilanadi.
  • Single-File Components (SFC): HTML (template), CSS (style) va JS (script) bitta .vue faylda birlashadi.
Vue 3 Kodi 
<!-- Vue 3 oddiy komponenti -->
<script setup>
import { ref } from 'vue';
const xabar = ref('Salom, Vue 3! 💚');
</script>

<template>
  <div style="background: #1e293b; padding: 15px; border-radius: 8px;">
    <h2 style="color: #42b883;">{{ xabar }}</h2>
    <button @click="xabar = 'Vue o'rganish juda qulay!'" style="background: #42b883; color: white; border: none; padding: 6px 12px; border-radius: 4px; cursor: pointer;">
      Xabarni O'zgartirish
    </button>
  </div>
</template>
📺 Natija:
💡 Vue.js dunyodagi eng oson va qulay sintaksisga ega bo'lgani uchun yangi boshlovchilar orasida juda mashhur.

O'rnatish Vue Mavzu #2

Vue.js O'rnatish

Vue loyihasini kompyuterda ishga tushirish uchun rasmiy tezkor vosita mavjud.

  • Rasmiy yaratish vositasi: npm create vue@latest.
  • Kutubxonalarni o'rnatish: cd mening-loyiha && npm install.
  • Ishga tushirish: npm run dev.
  • CDN orqali HTMLga oddiy ulab ishlatish: <script src="https://unpkg.com/vue@3"></script>.
Vue 3 Kodi 
// Terminalda bajarish:
// npm create vue@latest
// Loyiha nomi: mening-app
// TypeScript: Yes / No
// Vue Router, Pinia: Yes

// cd mening-app
// npm install
// npm run dev
📺 Natija:
⚡ Vite vositasi tufayli Vue loyihalari bir zumda ishga tushadi.

Tuzilma Vue Mavzu #3

Vue Loyiha Tuzilmasi

Standart Vue 3 loyihasining ichki arxitekturasi.

  • src/App.vue: asosiy bosh komponent.
  • src/main.js?v=20261123_4: Vuedan createApp() orqali ilovani yaratib HTMLga ulovchi fayl.
  • src/components/: qayta ishlatiluvchi komponentlar papkasi.
  • src/assets/: rasmlar, CSS stillari va shriftlar.
Vue 3 Kodi

import { createApp } from 'vue';
import App from './App.vue';
import './assets/main.css';

const app = createApp(App);
app.mount('#app');

Text Interpolation (Mustache {{ }})

Direktivalar Vue Mavzu #5

v-bind Direktisasi (Qisqartmasi :)

HTML atributlariga (href, src, class, disabled) dinamik JavaScript qiymatlarini bog'lash vositasi.

  • To'liq sintaksis: v-bind:href="url".
  • Qisqa sintaksis (har doim ishlatiladi): :href="url".
  • Rasmlarga dinamik yo'l berish: :src="rasmManzili".
  • Tugmani faolsizlantirish: :disabled="yuklanmoqda".
Vue 3 Kodi 
<template>
  <a :href="saytManzili" target="_blank" style="color: #42b883; font-weight: bold;">
    W3Learn Saytiga O'tish
  </a>
  <br><br>
  <button :disabled="tugmaOchiqmi" style="padding: 6px 12px; border-radius: 4px;">
    Holatga bog'liq tugma
  </button>
</template>
📺 Natija:
⚡ Professional Vue dasturchilari hech qachon 'v-bind' deb yozishmaydi, faqatgina ikki nuqta : qo'yishadi.

Shartlar Vue Mavzu #6

v-if / v-else-if / v-else

Shartga qarab HTML elementlarini DOMga qo'shish yoki butunlay DOMdan o'chirib tashlash.

  • v-if="shart": shart rost bo'lsa element yaratiladi.
  • v-else-if="boshqa_shart": ikkinchi shart.
  • v-else: yuqoridagilar bajarilmaganda chiqadi.
Vue 3 Kodi 
<template>
  <div v-if="tizimgaKirganmi" style="color: #42b883;">
    Hush kelibsiz, Admin! 👋
  </div>
  <div v-else style="color: #ef4444;">
    Iltimos, avval tizimga kiring! 🔒
  </div>
</template>

📌 v-if elementni yashirib qo'ymaydi, balki DOMdan to'liq olib tashlaydi.

Sikllar Vue Mavzu #7

v-for Direktisasi (Sikllar)

Massivdagi har bir element bo'yicha aylanib chiqib, ro'yxat yoki kartalarni hosil qilish.

  • Sintaksis: v-for="element in massiv" :key="element.id".
  • :key majburiydir! Virtual DOM elementlarni to'g'ri kuzatib borishi uchun har bir elementga unikal :key berilishi shart.
Vue 3 Kodi 
<template>
  <ul style="padding-left: 20px; color: #cbd5e1;">
    <li v-for="kurs in kurslar" :key="kurs.id">
      {{ kurs.nomi }} — <span style="color: #42b883;">{{ kurs.daraja }}</span>
    </li>
  </ul>
</template>
📺 Natija:
⚠️ :key atributiga hech qachon massiv indeksini bermang, ma'lumotning o'zining unikal ID sini bering.

Hodisalar Vue Mavzu #8

v-on Direktisasi (Qisqartmasi @)

Foydalanuvchi harakatlarini (click, submit, keyup) tinglash va unga javob qaytarish.

Vue 3 Kodi 
<template>
  <button @click="sanash" style="background: #42b883; color: white; border: none; padding: 8px 14px; border-radius: 4px; cursor: pointer;">
    Bosildi: {{ hisob }} marta
  </button>
</template>

✨ @submit.prevent bilan JavaScriptdagi e.preventDefault() ni yozishdan butunlay qutulasiz.

Formalar Vue Mavzu #9

v-model Direktisasi (Ikki tomonlama bog'lanish)

Input maydonidagi matn bilan JavaScriptdagi o'zgaruvchini ikki tomonlama (Two-Way Data Binding) uzviy bog'lash.

  • Foydalanuvchi inputga yozsa — o'zgaruvchi o'zgaradi.
  • Koddagi o'zgaruvchi o'zgarsa — inputdagi matn darhol yangilanadi.
  • Modifikatorlar: v-model.lazy, v-model.number, v-model.trim.
Vue 3 Kodi 
<template>
  <input v-model="ism" placeholder="Ismingizni yozing" style="padding: 6px; border-radius: 4px; background: #1e293b; color: white; border: 1px solid #475569;" />
  <p style="color: #42b883;">Jonli aks: Salom, {{ ism }}!</p>
</template>
📺 Natija:
🌟 Reactda buning uchun value va onChange yozish kerak, Vueda esa bitta v-model ning o'zi yetarli!

Shartlar Vue Mavzu #10

v-show Direktisasi

Elementni ko'rsatish yoki yashirish, lekin uni DOMdan o'chirmasdan faqat CSS display: none berish.

  • v-if elementni butunlay o'chiradi/yaratadi (og'ir amal).
  • v-show elementni doim DOMda saqlaydi, faqat ko'rinmas qilib turadi (juda yengil).
  • Tez-tez ochilib-yopiladigan menyu va tablar uchun v-show ancha samarali.
Vue 3 Kodi 
<template>
  <button @click="ochiq = !ochiq">Menyuni ochish/yopish</button>
  <div v-show="ochiq" style="background: #1e293b; padding: 10px; margin-top: 6px;">
    Bu menyu v-show orqali boshqarilmoqda!
  </div>
</template>
📺 Natija:
💡 Agar element sahifada tez-tez ko'rinib-yashirinishi kerak bo'lsa, har doim v-show ishlating.

ref() — Reaktiv Primitivlar

Vue 3 Composition API da oddiy primitiv qiymatlarni (son, matn, boolean) reaktiv qilish vositasi.

Vue 3 Kodi

function oshir() {
  son.value++; // JS ichida .value orqali
}
</script>

computed() — Hisoblangan Qiymatlar

Mavjud reaktiv ma'lumotlar asosida yangi qiymatni hisoblab chiqarish va natijani keshlab saqlash.

Hayotiy Sikl Vue Mavzu #23

Lifecycle Hooks (Hayotiy Sikl)

Komponent yaratilayotganda, ekranga chiqayotganda va yopilayotganda ma'lum bir kodlarni ishga tushirish.

  • onMounted(): komponent ekranda paydo bo'lganda (API dan ma'lumot olish uchun eng asosiy joy).
  • onUpdated(): DOM yangilanganda.
  • onUnmounted(): komponent ekrandan yo'qolayotganda (taymerlarni tozalash).
Vue 3 Kodi 
<script setup>
import { onMounted, onUnmounted } from 'vue';

onMounted(() => {
  console.log("Komponent ekranda muvaffaqiyatli chizildi!");
});

onUnmounted(() => {
  console.log("Komponent yopildi.");
});
</script>

📌 Serverdan ma'lumotlarni yuklab olishni doimo onMounted ichida bajaring.
