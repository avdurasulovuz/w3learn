React Nima?

⏱ 8 daqiqa 🟡 O'rta 👁 9,230 marta ko'rilgan

React — Facebook (Meta) tomonidan yaratilgan JavaScript kutubxonasi bo'lib, foydalanuvchi interfeyslari (UI) yaratish uchun ishlatiladi. React komponentlarga asoslangan arxitekturani qo'llaydi.

React Virtual DOM texnologiyasi yordamida sahifani juda tez yangilaydi — faqat o'zgargan qismlarni qayta chizadi.

💡 Eslatma: React — kutubxona (library), framework emas. U faqat UI qatlami uchun javobgar.

JSX — JavaScript XML

JSX — JavaScript ichida HTML yozish imkonini beruvchi sintaksis kengaytmasi. Brauzer JSX ni tushunmaydi, Babel uni oddiy JS ga aylantiradi.

// Oddiy JSX komponenti

  const ism = "Ali";
  return (
    <div>
      <h1>Salom, {ism}!</h1>
      <p>React bilan tanishing.</p>
    </div>
  );
}

// Eksport qilish
export default Salomlash;

useState Hook

useState — komponent ichida o'zgaruvchi holat (state) saqlash uchun ishlatiladigan eng asosiy hook.

JSX 
import { useState } from 'react';

function Hisoblagich() {
  // [qiymat, o'zgartiruvchi] = useState(boshlang'ich_qiymat)
  const [son, setSon] = useState(0);

  return (
    <div>
      <h2>Son: {son}</h2>
      <button onClick={() => setSon(son + 1)}>
        ➕ Oshirish
      </button>
      <button onClick={() => setSon(son - 1)}>
        ➖ Kamaytirish
      </button>
      <button onClick={() => setSon(0)}>
        🔄 Nolga qaytarish
      </button>
    </div>
  );
}

export default Hisoblagich;

useEffect Hook

JSX 
import { useState, useEffect } from 'react';

function FoydalanuvchiList() {
  const [foydalanuvchilar, setFoydalanuvchilar] = useState([]);
  const [yuklanmoqda, setYuklanmoqda] = useState(true);

  // Komponent chiqqanda API dan ma'lumot olish
  useEffect(() => {
    fetch('https://jsonplaceholder.typicode.com/users')
      .then(res => res.json())
      .then(data => {
        setFoydalanuvchilar(data.slice(0, 5));
        setYuklanmoqda(false);
      });
  }, []); // [] — faqat bir marta ishlaydi

  if (yuklanmoqda) return <p>⏳ Yuklanmoqda...</p>;

  return (
    <ul>
      {foydalanuvchilar.map(user => (
        <li key={user.id}>{user.name} — {user.email}</li>
      ))}
    </ul>
  );
}
