C# Nima? Kirish va .NET Ekotizimi

C# (C-Sharp) — Microsoft kompaniyasi tomonidan Anders Hejlsberg boshchiligida yaratilgan, zamonaviy, xavfsiz va ob'ektga yo'naltirilgan dasturlash tilidir. U kuchli .NET platformasi ustida ishlaydi va korporativ backend, veb-ilovalar (ASP.NET), mobil ilovalar (.NET MAUI), o'yinlar (Unity dvigateli) va bulut xizmatlarida (Azure) yetakchi hisoblanadi.

  • Kuchli tiplashtirilgan (Type-safe) va xavfsiz til — xotira o'chirilishini Garbage Collector (GC) avtomatik boshqaradi.
  • Kross-platforma: Windows, Linux va macOS da bir xil yuqori tezlikda ishlaydi.
  • Unity o'yin dvigatelining rasmiy asosiy tili.
  • Dunyoning eng yirik banklari, elektron tijorat va tibbiyot tizimlari C# va ASP.NET Core asosida ishlaydi.
C# / .NET 8 
// C# dasturining eng sodda ko'rinishi (.NET 8/9 Top-level statements)
using System;

Console.WriteLine("Assalomu alaykum, C# Dunyosi! 💜");
Console.WriteLine(".NET 8 zamonaviy, chaqqon va xavfsiz ekotizim.");

💡 C# tili C++ ning tezligini va Java ning qulayligini o'zida birlashtirgan, ayni paytda eng zamonaviy sintaksis imkoniyatlariga ega tildir.

Sintaksis C# Mavzu #3

Hello World — Program.cs va Top-level Statements

Zamonaviy C# versiyalarida (C# 9 dan boshlab) ortiqcha 'boilerplate' kodlardan (namespace, class Program, static void Main) voz kechilib, Top-level statements joriy qilingan. Bu dasturni o'rganishni bir necha qator kod bilan boshlash imkonini beradi.

  • Klassik usul: namespace -> class Program -> static void Main(string[] args).
  • Zamonaviy usul: to'g'ridan-to'g'ri kod yozish (faylning o'zi Main vazifasini bajaradi).
  • Konsolga chiqarish: Console.WriteLine("...") (yangi satr bilan) yoki Console.Write("...").
C# / .NET 8 
// Program.cs
using System;

string dasturchi = "Rustam";
int tajriba = 3;

Console.WriteLine($"Dasturchi: {dasturchi}");
Console.WriteLine($"Tajriba: {tajriba} yil");
Console.WriteLine("W3Learn platformasida C# kursini o'rganmoqda.");

Asoslar C# Mavzu #4

O'zgaruvchilar va var Kalit So'zi

C# da o'zgaruvchilarni aniq tip ko'rsatib (explicit) yoki var kalit so'zi yordamida (implicit) e'lon qilish mumkin. var ishlatilganda ham o'zgaruvchi qat'iy tipli bo'lib qoladi.

  • Aniq e'lon qilish: int yosh = 25;, string shahar = "Toshkent";.
  • Tipni avtomatik aniqlash: var narx = 99.99; (kompilyator buni double deb biladi).
  • O'zgarmaslar: const double Soliq = 0.12;.
  • C# katta va kichik harflarni farqlaydi (Case-sensitive).
C# / .NET 8 
using System;

int talabalarSoni = 45;
var kursNomi = "C# Backend";
const string Valyuta = "UZS";

// var ga boshqa turdagi ma'lumot yuklab bo'lmaydi (xatolik beradi)
// kursNomi = 100; // XATO!

Console.WriteLine($"Kurs: {kursNomi}");
Console.WriteLine($"Guruhdagi talabalar: {talabalarSoni} nafar");
Console.WriteLine($"Hisob valyutasi: {Valyuta}");
🖥️ .NET Runtime / Terminal Natijasi:
⚡ var JavaScript dagi kabi dinamik tip emas. Kompilyatsiya vaqtida uning tipi aniqlanadi va uni keyinchalik o'zgartirib bo'lmaydi.

Tiplar C# Mavzu #5

Ma'lumot Turlari — Value vs Reference Types

C# dagi barcha ma'lumot turlari ikkita katta toifaga bo'linadi: Value Types (Stack xotirada qiymatning o'zi saqlanadi) va Reference Types (Heap xotirada ob'ekt, Stack da unga ko'rsatkich saqlanadi).

  • Value types: int, double, float, decimal (moliyaviy hisob-kitoblar uchun aniq), bool, char, struct.
  • Reference types: string, class, interface, array, delegate.
  • Nullable Types: int? raqam = null; — qiymat bo'lmasligi mumkin bo'lgan maydonlar uchun.
  • C# dagi barcha turlarning eng oliy ajdodi — System.Object hisoblanadi.
C# / .NET 8 
using System;

// Decimal - moliyaviy hisoblar uchun eng aniq tur
decimal oylikMaosh = 14500000.50m; // oxiriga 'm' qo'yiladi

// Nullable turi (qiymat yo'q bo'lishi mumkin)
int? passportRaqami = null;

if (passportRaqami.HasValue) {
    Console.WriteLine($"Passport: {passportRaqami.Value}");
} else {
    Console.WriteLine("Passport ma'lumotlari kiritilmagan.");
}

Console.WriteLine($"Oylik: {oylikMaosh:N2} so'm");
🖥️ .NET Runtime / Terminal Natijasi:
💡 Bank va to'lov tizimlarida sonlarni yaxlitlashdagi yo'qotishlarning oldini olish uchun doimo double emas, decimal ishlatiladi.

Mantiq C# Mavzu #6

Shartlar — if, else va Switch Expressions

C# dastur oqimini boshqarish uchun an'anaviy if-else bilan birga C# 8 da kiritilgan ajoyib va ixcham Switch Expressions sintaksisini taqdim etadi.

  • Klassik if-else bloklari.
  • Pattern Matching: o'zgaruvchi turiga va qiymatiga qarab shart tekshirish.
  • Switch Expression: qiymat switch { holat1 => natija1, _ => sukut }.
C# / .NET 8 
using System;

int kun = 6;

// Zamonaviy Switch Expression
string kunNomi = kun switch
{
    1 => "Dushanba",
    2 => "Seshanba",
    3 => "Chorshanba",
    4 => "Payshanba",
    5 => "Juma (Muborak)",
    6 or 7 => "Dam olish kuni 🎉",
    _ => "Noto'g'ri kun raqami"
};

Console.WriteLine($"Hafta kuni: {kunNomi}");
🖥️ .NET Runtime / Terminal Natijasi:
⚡ Switch expression da pastki chiziq _ belgisi klassik switch dagi default vazifasini bajaradi.

Sikllar C# Mavzu #7

Sikllar — for, while va foreach

Takroriy amallarni bajarish uchun C# da to'rtta sikl turi mavjud. Ro'yxat va massivlar bilan ishlashda eng mashhuri foreach siklidir.

  • for (int i = 0; i < n; i++) — ma'lum sondagi takrorlanishlar.
  • foreach (var element in toplom) — to'plamdagi har bir elementni navbati bilan o'qish.
  • while (shart) va do { ... } while (shart);.
  • Siklni boshqarish: break va continue.
C# / .NET 8 
using System;

string[] tillar = { "C#", "Python", "JavaScript", "Go", "Java" };

Console.WriteLine("Dasturlash tillari ro'yxati:");
foreach (var til in tillar)
{
    if (til == "JavaScript") continue; // O'tkazib yuborish
    Console.WriteLine($"- {til}");
}
🖥️ .NET Runtime / Terminal Natijasi:
💡 foreach siklida to'plam elementlari faqat o'qish uchun (read-only) bo'ladi, sikl ichida ularni o'zgartirib bo'lmaydi.

To'plamlar C# Mavzu #8

Massivlar va List To'plami

C# da o'lchami o'zgarmas massivlar (T[]) va o'lchami dinamik o'suvchi generik ro'yxatlar (List<T>) ishlatiladi.

  • Statik massiv: int[] raqamlar = new int[5];.
  • Dinamik ro'yxat: List<string> shaharlar = new();.
  • Element qo'shish: list.Add("Samarqand");.
  • Element o'chirish: list.Remove("Buxoro");.
  • Elementlar soni: list.Count (massivda esa arr.Length).
C# / .NET 8 
using System;
using System.Collections.Generic;

List<string> viloyatlar = new List<string> { "Toshkent", "Samarqand", "Farg'ona" };

viloyatlar.Add("Buxoro");
viloyatlar.Add("Xorazm");

Console.WriteLine($"Jami viloyatlar soni: {viloyatlar.Count}");
Console.WriteLine($"Birinchi viloyat: {viloyatlar[0]}");

viloyatlar.Remove("Farg'ona");
Console.WriteLine($"O'chirilgandan so'ng soni: {viloyatlar.Count}");
🖥️ .NET Runtime / Terminal Natijasi:
⚡ 99% amaliy loyihalarda statik massiv o'rniga qulayligi va xavfsizligi tufayli List<T> ishlatiladi.

String C# Mavzu #9

String va StringBuilder bilan Ishlash

C# da string o'zgarmas (immutable) tur hisoblanadi. Agar matn ustida ko'p sonli o'zgartirishlar bajarilsa, xotirani tejash uchun StringBuilder ishlatiladi.

  • String Interpolation: $"Salom, {ism}!".
  • Matn metodlari: ToUpper(), ToLower(), Contains(), Replace(), Split().
  • Ko'p qatorli matnlar: @"C:\Papkalar\Fayl.txt" (Verbatim string) yoki uchta qo'shtirnoq """ ... """ (Raw string literals).
  • Katta matnlarni birlashtirishda StringBuilder.Append() eng yuqori unumdorlik beradi.
C# / .NET 8 
using System;
using System.Text;

// String metodlari
string kitob = "  C# Asoslari va Algoritmlar  ";
string tozaKitob = kitob.Trim();

Console.WriteLine($"Tozalangan: '{tozaKitob}'");
Console.WriteLine($"Katta harflarda: {tozaKitob.ToUpper()}");
Console.WriteLine($"'Asos' so'zi bormi: {tozaKitob.Contains("Asos")}");

// StringBuilder yordamida tezkor matn yig'ish
StringBuilder sb = new StringBuilder();
for (int i = 1; i <= 3; i++) {
    sb.Append($"Qator #{i}; ");
}
Console.WriteLine($"StringBuilder natijasi: {sb.ToString()}");
🖥️ .NET Runtime / Terminal Natijasi:
💡 Tsikl ichida matnlarni + bilan qo'shish har safar yangi xotira ajratadi, bunday holatda doimo StringBuilder dan foydalaning.

OOP C# Mavzu #10

Klasslar va Xususiyatlar (Properties)

Klass — bu ob'ektning modeli. C# tili xususiyatlar (Properties) uchun get; set; avtomatik sintaksisini taqdim etadi. Bu Java dagi kabi uzun getter/setter metodlarini yozish zaruriyatini yo'q qiladi.

  • Auto-properties: public string Ism { get; set; }.
  • Faqat o'qish uchun (Init-only / Read-only): public int Id { get; init; }.
  • Konstruktor: ob'ekt yaratilganda xususiyatlarni boshlang'ich qiymat bilan to'ldiradi.
C# / .NET 8 
using System;

public class Foydalanuvchi
{
    // Auto-implemented Properties
    public int Id { get; set; }
    public string Ism { get; set; }
    public string Email { get; set; }

    // Konstruktor
    public Foydalanuvchi(int id, string ism, string email)
    {
        Id = id;
        Ism = ism;
        Email = email;
    }

    public void MalumotBer()
    {
        Console.WriteLine($"[User #{Id}] Ism: {Ism}, Email: {Email}");
    }
}

// Ishlatilishi:
var user = new Foydalanuvchi(1, "Davron", "davron@w3learn.uz");
user.MalumotBer();
🖥️ .NET Runtime / Terminal Natijasi:
⚡ get; init; yozilsa, xususiyatga faqat ob'ekt yaratilayotgan paytda qiymat berish mumkin bo'ladi, keyinchalik uni o'zgartirib bo'lmaydi (Immutability).

OOP C# Mavzu #11

Meros (Inheritance) va base Kalit So'zi

Meros olish orqali bola klass ota klassning barcha ochiq (public, protected) a'zolarini o'zlashtiradi. C# da klass faqat bitta ota klassdan meros olishi mumkin (Single Inheritance).

  • Sintaksis: public class Xodim : Shaxs { ... }.
  • Ota klass konstruktoriga murojaat: : base(parametrlar).
  • base.Metod() orqali ota klass metodlarini chaqirish mumkin.
C# / .NET 8 
using System;

public class Shaxs
{
    public string Ism { get; set; }
    public Shaxs(string ism) { Ism = ism; }

    public void Salomlash()
    {
        Console.WriteLine($"Salom, mening ismim {Ism}.");
    }
}

public class Dasturchi : Shaxs
{
    public string Til { get; set; }

    // Ota klass konstruktorini chaqirish
    public Dasturchi(string ism, string til) : base(ism)
    {
        Til = til;
    }

    public void KodYoz()
    {
        Console.WriteLine($"{Ism} hozirda {Til} tilida kod yozmoqda 💻");
    }
}

var dev = new Dasturchi("Nodir", "C#");
dev.Salomlash();
dev.KodYoz();
🖥️ .NET Runtime / Terminal Natijasi:
💡 Ota klassning umumiy mantiqini bola klassda qayta yozmasdan to'g'ridan-to'g'ri ishlatish dasturlashni tezlashtiradi.

OOP C# Mavzu #12

Interface (Interfeyslar) va Shartnomalar

Interface — bu klass qanday metodlarga ega bo'lishi kerakligini belgilab beruvchi shartnomadir (Contract). Klass bir nechta interfeysni birdaniga amalga oshirishi (implement) mumkin.

  • Interfeys nomlari C# an'anasiga ko'ra doimo katta I harfi bilan boshlanadi: IRepository, IPayment.
  • Klass interfeysdagi barcha metodlarni o'z ichida to'liq yozishi shart.
  • Dependency Injection (DI) va testlashning asosi hisoblanadi.
C# / .NET 8 
using System;

public interface ITo'lovXizmati
{
    void TolovQil(decimal summa);
    bool HolatniTekshir();
}

public class ClickTolov : ITo'lovXizmati
{
    public void TolovQil(decimal summa)
    {
        Console.WriteLine($"Click orqali {summa:N0} so'm to'lov muvaffaqiyatli amalga oshirildi ✅");
    }

    public bool HolatniTekshir() => true;
}

public class PaymeTolov : ITo'lovXizmati
{
    public void TolovQil(decimal summa)
    {
        Console.WriteLine($"Payme tizimida {summa:N0} so'm yechildi ✅");
    }

    public bool HolatniTekshir() => true;
}

ITo'lovXizmati tolov = new ClickTolov();
tolov.TolovQil(250000);
🖥️ .NET Runtime / Terminal Natijasi:
⚡ Interfeyslar tufayli kodni o'zgartirmasdan bitta to'lov tizimini boshqasiga bir zumda almashtirish mumkin (Polimorfizm).

OOP C# Mavzu #13

Abstract Klasslar va Metodlar

Abstract klass — bu to'liq yakunlanmagan klass bo'lib, undan to'g'ridan-to'g'ri ob'ekt olib bo'lmaydi (new AbstractClass() xato beradi). U faqat boshqa klasslar uchun qolip bo'lib xizmat qiladi.

  • abstract kalit so'zi bilan belgilanadi.
  • Abstract metodlar tanaga ega bo'lmaydi, ularni bola klass override bilan to'ldirishi shart.
  • Oddiy metodlar va maydonlarga ham ega bo'lishi mumkin (Interfeysdan farqi shunda).
C# / .NET 8 
using System;

public abstract class GeometrikShakl
{
    public string Nomi { get; set; }
    public GeometrikShakl(string nomi) { Nomi = nomi; }

    // Bola klass albatta yozishi shart bo'lgan abstrakt metod
    public abstract double YuzaHisobla();

    public void Malumot()
    {
        Console.WriteLine($"{Nomi} ning yuzasi: {YuzaHisobla()} kv birlik");
    }
}

public class Kvadrat : GeometrikShakl
{
    public double Tomon { get; set; }
    public Kvadrat(double tomon) : base("Kvadrat") { Tomon = tomon; }

    public override double YuzaHisobla() => Tomon * Tomon;
}

var kv = new Kvadrat(5.0);
kv.Malumot();
🖥️ .NET Runtime / Terminal Natijasi:
💡 Abstract klass umumiy holat (state) va tayyor metodlarni merosxo'rlarga ulashish kerak bo'lganda eng maqbul tanlovdir.

Polimorfizm C# Mavzu #14

Polimorfizm — virtual, override va sealed

Ota klassdagi metod xatti-harakatini bola klassda qayta yozish uchun ota metodga virtual, bola metodga esa override kalit so'zi qo'yiladi.

  • virtual — ota klass: 'Bu metodni bolalar qayta yozishi mumkin'.
  • override — bola klass: 'Men ota klassning metodini o'zimga moslab o'zgartirdim'.
  • sealed — boshqa hech kim bu metodni yoki klassni qayta yoza olmasligi uchun taqiqlaydi.
C# / .NET 8 
using System;

public class Xabarnoma
{
    public virtual void Yubor(string xabar)
    {
        Console.WriteLine($"Standart xabarnoma: {xabar}");
    }
}

public class SmsXabarnoma : Xabarnoma
{
    public override void Yubor(string xabar)
    {
        Console.WriteLine($"📱 SMS orqali yuborildi: {xabar}");
    }
}

public class TelegramXabarnoma : Xabarnoma
{
    public override void Yubor(string xabar)
    {
        Console.WriteLine($"✈️ Telegram Bot orqali yuborildi: {xabar}");
    }
}

Xabarnoma bot = new TelegramXabarnoma();
bot.Yubor("W3Learn da yangi dars joylandi!");
🖥️ .NET Runtime / Terminal Natijasi:
⚡ Agar metodga virtual yozilmasa, bola klassda override qilib bo'lmaydi.

LINQ C# Mavzu #15

LINQ — Language Integrated Query

LINQ — C# ning eng sevimli va qudratli imkoniyati bo'lib, massivlar, ro'yxatlar, XML va ma'lumotlar bazalaridan SQL ga o'xshash qulay sintaksis bilan ma'lumotlarni qidirish, filtrlash va tartiblash imkonini beradi.

  • Filtrlash: Where(x => shart).
  • Tanlash va o'zgartirish: Select(x => x.Maydon).
  • Saralash: OrderBy(x => x) yoki OrderByDescending().
  • Boshqa foydali metodlar: First(), FirstOrDefault(), Any(), Count(), Sum(), Take().
C# / .NET 8 
using System;
using System.Collections.Generic;
using System.Linq;

var sonlar = new List<int> { 12, 5, 8, 20, 15, 3, 30, 7 };

// 10 dan katta juft sonlarni topish va saralash
var saralangan = sonlar
    .Where(s => s > 10 && s % 2 == 0)
    .OrderBy(s => s)
    .ToList();

Console.WriteLine("Natija:");
foreach (var s in saralangan)
{
    Console.WriteLine($"- {s}");
}

Console.WriteLine($"Elementlar yig'indisi: {sonlar.Sum()}");
Console.WriteLine($"Eng kattasi: {sonlar.Max()}");
🖥️ .NET Runtime / Terminal Natijasi:
🚀 LINQ yozilgan so'rovlar 'Deferred execution' (kechiktirilgan bajarilish) prinsipiga ega — ular ToList() chaqirilgandagina haqiqatda bajariladi.

Generics C# Mavzu #16

Generics (Umumlashgan Turlar)

Generics — kodni ma'lum bir ma'lumot turiga bog'lab qo'ymasdan, istalgan tur uchun xavfsiz va unumdor ishlaydigan universal klass va metodlar yaratish usulidir.

  • Sintaksis: <T> (Type placeholder).
  • Boxing va Unboxing ortiqcha yuklamasini yo'qotadi va dastur tezligini oshiradi.
  • Cheklovlar (Constraints): where T : class yoki where T : struct.
C# / .NET 8 
using System;

// Universal qiymatlarni almashtiruvchi generik metod
public class Yordamchi
{
    public static void Almashtir<T>(ref T a, ref T b)
    {
        T temp = a;
        a = b;
        b = temp;
    }
}

int x = 10, y = 99;
Yordamchi.Almashtir(ref x, ref y);
Console.WriteLine($"Sonlar: x={x}, y={y}");

string matn1 = "Oq", matn2 = "Qora";
Yordamchi.Almashtir(ref matn1, ref matn2);
Console.WriteLine($"Matnlar: {matn1}, {matn2}");
🖥️ .NET Runtime / Terminal Natijasi:
💡 List<T>, Dictionary<TKey, TValue> kabi to'plamlar aynan Generics asosiga qurilgan.

Delegates C# Mavzu #17

Delegates — Action, Func va Predicate

Delegate — bu funksiyaga havola (ko'rsatkich) saqlaydigan xavfsiz turdir. U funksiyalarni boshqa funksiyalarga parametr sifatida uzatish imkonini beradi.

  • Action<T>: Hech narsa qaytarmaydigan (void) funksiyalar uchun.
  • Func<T, TResult>: Qiymat qaytaradigan funksiyalar uchun (oxirgi parametr qaytariladigan tur).
  • Predicate<T>: Faqat bool (true/false) qaytaradigan tekshiruvchi funksiyalar uchun.
C# / .NET 8 
using System;

// Func: ikkita int qabul qilib int qaytaradi
Func<int, int, int> qoshish = (a, b) => a + b;
Console.WriteLine($"5 + 7 = {qoshish(5, 7)}");

// Action: parametr oladi, hech narsa qaytarmaydi
Action<string> chopEt = xabar => Console.WriteLine($"[LOG]: {xabar}");
chopEt("Tizim muvaffaqiyatli ishga tushdi");

// Predicate: tekshirish
Predicate<int> juftmi = son => son % 2 == 0;
Console.WriteLine($"8 juftmi? {juftmi(8)}");

⚡ Zamonaviy C# da maxsus delegate deb yozib o'tirmasdan, deyarli har doim tayyor Func va Action ishlatiladi.

Events C# Mavzu #18

Events (Hodisalar) — Publisher-Subscriber

Event (Hodisa) — bu biror amal sodir bo'lganda (masalan, tugma bosildi, to'lov muvaffaqiyatli bo'ldi) boshqa qismlarni xabardor qilish mexanizmidir.

  • event EventHandler<T> e'lon qilinadi.
  • Obuna bo'lish: hodisa += MeniFunksiyam;.
  • Obunani bekor qilish: hodisa -= MeniFunksiyam;.
  • Hodisani chaqirish: HodisaNomi?.Invoke(this, EventArgs);.
C# / .NET 8 
using System;

public class BankHisob
{
    public decimal Balans { get; private set; }
    // Hodisa e'loni
    public event Action<decimal> PulYechildi;

    public void YechibOlish(decimal summa)
    {
        if (Balans >= summa)
        {
            Balans -= summa;
            PulYechildi?.Invoke(summa); // Barcha obunachilarni xabardor qilish
        }
    }

    public BankHisob(decimal boshlangich) { Balans = boshlangich; }
}

var hisob = new BankHisob(1000000);

// SMS xabarnoma obunachisi
hisob.PulYechildi += s => Console.WriteLine($"SMS: Hisobingizdan {s:N0} so'm yechildi!");

hisob.YechibOlish(150000);

💡 Hodisalar interfeys dasturlashda va asinxron arxitekturada kodlarning bir-biriga qattiq bog'lanib qolmasligini ta'minlaydi.

async va await — Asinxron Dasturlash

Fayldan o'qish, tarmoq so'rovlari yoki ma'lumotlar bazasi amallari bajarilayotganda butun dasturni to'xtatib qo'ymaslik (UI qotib qolmasligi) uchun async / await ishlatiladi.

  • Metod sarlavhasiga async Task yoki async Task<T> yoziladi.
  • Uzoq kutiladigan amallar oldiga await qo'yiladi.
  • Thread (oqim) bloklanmaydi, boshqa vazifalarni bajarishda davom etadi.
C# / .NET 8 
using System;
using System.Threading.Tasks;

public class Dastur
{
    public static async Task Main()
    {
        Console.WriteLine("Ma'lumotlar bazasidan yuklanmoqda...");
        
        string natija = await MalumotYuklaAsync();
        Console.WriteLine($"Qabul qilindi: {natija}");

    public static async Task<string> MalumotYuklaAsync()
    {
        // 1 soniya asinxron kutish (tarmoq simulyatsiyasi)

    }
}

Lambda C# Mavzu #20

Lambda Expressions (Anonim Funksiyalar)

Lambda ifodasi — bu => (bunday ketadi / goes to) operatori yordamida yoziladigan ixcham nomsiz funksiyadir. U LINQ va delegatlar bilan ishlashda doimiy qo'llaniladi.

  • Sintaksis: (parametrlar) => ifoda;.
  • Bitta parametr bo'lsa qavslar ixtiyoriy: x => x * 2.
  • Blokli lambda: (x, y) => { int s = x + y; return s; }.
C# / .NET 8 
using System;
using System.Collections.Generic;

List<int> sonlar = new() { 1, 2, 3, 4, 5, 6, 7, 8 };

// Lambda yordamida toq sonlarni topish
var toqlar = sonlar.FindAll(n => n % 2 != 0);

Console.WriteLine("Toq sonlar: " + string.Join(", ", toqlar));

// Lambda orqali har biriga amal qo'llash
sonlar.ForEach(n => Console.Write($"{n * 10} "));
Console.WriteLine();

Web API C# Mavzu #22

Web API — Controllers va Routing

Katta korporativ loyihalarda API larni tuzilmali va tartibli tashkil qilish uchun Controller asosidagi yondashuv ishlatiladi.

  • [ApiController] va [Route("api/[controller]")] atributlari.
  • HTTP metodlari: [HttpGet], [HttpPost], [HttpPut], [HttpDelete].
  • Swagger / OpenAPI hujjati avtomatik generatsiya bo'ladi (/swagger).
C# / .NET 8 
using Microsoft.AspNetCore.Mvc;
using System.Collections.Generic;

[ApiController]
[Route("api/[controller]")]
public class MahsulotlarController : ControllerBase
{
    private static List<string> tovarlar = new() { "Laptop", "Smartfon", "Planshet" };

    [HttpGet]
    public IActionResult GetAll()
    {
        return Ok(tovarlar);
    }

    [HttpPost]
    public IActionResult Create([FromBody] string yangiTovar)
    {
        tovarlar.Add(yangiTovar);
        return Created("", new { Xabar = "Tovar qo'shildi", Tovar = yangiTovar });
    }
}

EF Core C# Mavzu #23

Entity Framework Core (EF Core) — ORM

EF Core — bu C# va .NET uchun rasmiy ORM (Object-Relational Mapper) kutubxonasidir. U ma'lumotlar bazasi jadvallarini C# klasslariga bog'laydi va SQL yozmasdan LINQ orqali bazani boshqarishga imkon beradi.

  • DbContext: Ma'lumotlar bazasi bilan ulanish sessiyasi.
  • DbSet<T>: Baza jadvalining C# dagi ko'rinishi.
  • Migratsiyalar: dotnet ef migrations add InitialCreate va dotnet ef database update.
  • PostgreSQL, SQL Server, MySQL, SQLite ni to'liq qo'llab-quvvatlaydi.
C# / .NET 8 
using Microsoft.EntityFrameworkCore;
using System.Collections.Generic;

public class Mahsulot
{
    public int Id { get; set; }
    public string Nomi { get; set; }
    public decimal Narxi { get; set; }
}

public class IlovaDbContext : DbContext
{
    public DbSet<Mahsulot> Mahsulotlar { get; set; }

    protected override void OnConfiguring(DbContextOptionsBuilder options)
    {
        options.UseSqlite("Data Source=dokon.db");
    }
}

// Ishlatilishi:
using var db = new IlovaDbContext();
db.Database.EnsureCreated();

db.Mahsulotlar.Add(new Mahsulot { Nomi = "Klaviatura", Narxi = 250000 });
db.SaveChanges(); // SQL INSERT bajariladi
