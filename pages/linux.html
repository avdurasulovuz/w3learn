Asosiy Linux Mavzu #1

Linux Nima? Dunyo Infratuzilmasining Yuragi

Linux — 1991-yilda Linus Torvalds tomonidan yaratilgan erkin va ochiq kodli Unix-simon operatsion tizim yadrosidir (Kernel). Bugungi kunda global internet serverlarining 90% dan ortig'i, dunyodagi eng kuchli 500 ta superkompyuterning 100% i, barcha Android smartfonlar va bulutli platformalar (AWS, Google Cloud, Azure) aynan Linux boshqaruvida ishlaydi.

  • Ochiq kodli (Open Source): Har kim kodni ko'rishi, o'zgartirishi va o'z ehtiyojiga moslashi mumkin.
  • O'ta barqaror va xavfsiz: Oylarcha yoki yillarcha qayta yuklanmasdan (no reboot) to'xtovsiz ishlay oladi.
  • Virus va zararli dasturlarga yuqori chidamlilik va qat'iy foydalanuvchi huquqlari tizimi.
  • Har qanday backend dasturchi, DevOps va kiberxavfsizlik mutaxassisi uchun Linux ni bilish majburiy hisoblanadi.
Bash / Linux Shell 
# Linux yadrosi va tizim ma'lumotlarini ko'rish
uname -a
🐧 Linux Terminal Natijasi:
💡 'Linux' aslida faqat yadro (kernel) hisoblanadi; uning atrofidagi utilitalar GNU loyihasi vositalari bo'lgani uchun to'liq nomi GNU/Linux dir.

Distributivlar Linux Mavzu #2

Linux Distributivlari (Ubuntu, Debian, CentOS, Alpine)

Linux yadrosi turli dasturlar va paket menejerlari bilan birlashtirilib, Distributivlar (Distros) ko'rinishida chiqariladi.

  • Ubuntu: Yangi o'rganuvchilar va serverlar uchun eng mashhur va qulay tizim (Debian asosida).
  • Debian: Favqulodda toshdek qattiq barqarorlik (Rock-solid stability).
  • RHEL / Rocky / AlmaLinux / CentOS: Katta korxonalar va moliya institutlari korporativ standarti.
  • Alpine Linux: O'ta kichik (atigi 5 MB), Docker konteynerlari uchun 1-raqamli tanlov.
  • Arch Linux: Doim eng so'nggi dasturiy ta'minot (Rolling release), ilg'or foydalanuvchilar uchun.
Bash / Linux Shell 
# O'rnatilgan distributiv nomini ko'rish
cat /etc/os-release
🐧 Linux Terminal Natijasi:
💡 Serverlar uchun doimo LTS (Long Term Support - 5 yillik rasmiy qo'llab-quvvatlanuvchi) versiyalarni tanlash zarur.

Terminal Linux Mavzu #3

Terminal va CLI (Buyruqlar Qatori) Asoslari

Linux boshqaruvining asosiy kuchi grafik oynalarda emas, balki Terminal (Command Line Interface - CLI) orqali buyruqlar berishdadir.

  • Buyruq strukturasi: buyruq [bayroqlar/options] [argumentlar].
  • Masalan: ls -l /var/log (buyruq: ls, bayroq: -l, argument: /var/log).
  • Katta-kichik harflar qat'iy farqlanadi: Fayl.txt va fayl.txt ikki xil fayldir.
  • Tab tugmasi buyruq va fayl nomlarini avtomatik to'ldiradi (Auto-complete).
Bash / Linux Shell 
# Terminalda oddiy salomlashish
echo "Assalomu alaykum, Linux dunyosi!"
whoami
date
🐧 Linux Terminal Natijasi:
💡 Terminalda Tab tugmasini ikki marta bosish mos keluvchi barcha variantlarni ko'rsatadi.

Fayl tizimi Linux Mavzu #4

Linux Fayllar Tizimi Strukturasi (FHS)

Windows dagi 'C:', 'D:' disklari o'rniga, Linux da hamma narsa bitta umumiy ildiz — / (Root) katalogidan boshlanadigan daraxt ko'rinishida tuzilgan.

  • / — Butun tizimning boshlang'ich ildizi (Root directory).
  • /bin va /usr/bin — Barcha asosiy ijro etiluvchi dasturlar (ls, cp, python).
  • /etc — Tizim va dasturlarning konfiguratsiya (sozlama) fayllari (nginx.conf, passwd).
  • /home — Oddiy foydalanuvchilarning shaxsiy ishchi papkalari (/home/user).
  • /var — Doimiy o'zgaruvchi ma'lumotlar: loglar (/var/log), keshlar, ma'lumotlar bazalari.
  • /tmp — Vaqtinchalik fayllar (tizim qayta yonganda avtomatik tozalanadi).
Bash / Linux Shell 
# Ildiz katalog tarkibini ko'rish
ls -d /*
🐧 Linux Terminal Natijasi:
💡 Linux da mashhur falsafa bor: 'Everything is a file' (Hamma narsa fayldir) — hatto qattiq disklar va tarmoq ulanishlari ham fayl sifatida ifodalanadi.

Fayllar Linux Mavzu #5

ls: Fayllar va Jildlar Ro'yxati

Joriy yoki ko'rsatilgan papka ichidagi barcha fayllar va jildlarni ko'rish buyrug'i.

  • ls — oddiy ro'yxat.
  • ls -l — batafsil ma'lumot (ruxsatlar, egasi, hajmi, o'zgartirilgan vaqti).
  • ls -a — yashirin fayllarni ham ko'rsatish (nuqta . bilan boshlanuvchilar).
  • ls -lh — hajmlarni inson o'qiy oladigan formatda (KB, MB, GB) ko'rsatish.
  • ls -lt — eng so'nggi o'zgartirilgan vaqti bo'yicha saralash.
Bash / Linux Shell 
# Batafsil va yashirin fayllar ro'yxatini ko'rish
ls -lah
🐧 Linux Terminal Natijasi:
💡 `.` joriy papkani, `..` esa bitta yuqoridagi ota-papkani bildiradi.

Navigatsiya Linux Mavzu #6

cd: Papkalar Bo'ylab Harakatlanish

Bitta papkadan boshqa papkaga o'tish buyrug'i (Change Directory).

  • cd /var/log — mutlaq yo'l (absolute path) bo'yicha o'tish.
  • cd w3learn_app — nisbiy yo'l (relative path) bo'yicha o'tish.
  • cd .. — bitta qavat yuqoriga chiqish.
  • cd ~ yoki oddiygina cd — shaxsiy foydalanuvchi jildiga (/home/user) qaytish.
  • cd - — oldingi turgan papkaga qaytish.
Bash / Linux Shell 
# Papkalar bo'ylab sayohat
cd /var/log/nginx
pwd
cd -
pwd
🐧 Linux Terminal Natijasi:
💡 `cd -` buyrug'i ikki papka o'rtasida tez-tez almashib turishda juda qo'l keladi.

cp va mv: Nusxalash va Ko'chirish

Xavfli Linux Mavzu #11

rm va rmdir: Fayllarni O'chirish

Fayl va jildlarni butunlay diskdan yo'q qilish. ⚠️ Linux terminalida 'Savatcha' (Recycle Bin) yo'q — o'chirilgan faylni qaytarib bo'lmaydi!

  • rm fayl.txt — bitta faylni o'chirish.
  • rm -r papka/ — papkani barcha ichki elementlari bilan birga rekurziv o'chirish.
  • rm -rf papka/ — hech qanday so'rovsiz, majburiy o'chirish (-f = force).
  • rmdir bush_papka — faqat bo'sh papkani o'chiradi.
Bash / Linux Shell 
# Keraksiz faylni o'chirish
rm config.backup.json
ls config.backup.json
🐧 Linux Terminal Natijasi:
⚠️ HECH QACHON `sudo rm -rf /` buyrug'ini yozmang! Bu butun operatsion tizimni va unga ulangan barcha disklarni butunlay yo'q qilib tashlaydi.

Matn Linux Mavzu #12

cat, less va more: Fayllarni O'qish

Fayl ichidagi matnni tahrirlovchini ochmasdan to'g'ridan-to'g'ri terminalda ko'rish.

  • cat fayl.txt — kichik fayllar mazmunini to'liq chop etish.
  • cat -n fayl.txt — satr raqamlari bilan chiqarish.
  • head -n 10 fayl.log — faylning eng yuqorigi 10 ta satrini ko'rish.
  • tail -n 10 fayl.log — faylning eng pastki 10 ta satrini ko'rish.
  • tail -f /var/log/syslog — faylga qo'shilayotgan yangi satrlarni jonli rejimda kuzatish.

# Tizim loglarining oxirgi satrlarini o'qish
tail -n 3 /var/log/dpkg.log
🐧 Linux Terminal Natijasi:
💡 `tail -f` dasturchilarning sevimli buyrug'i bo'lib, server xatolarini real-vaqtda ushlash imkonini beradi.

Qidiruv Linux Mavzu #14

find: Fayllarni Qidirish

Butun tizim yoki belgilangan katalog ichidan fayl nomi, hajmi, turi yoki sanasi bo'yicha kuchli qidiruv tizimi.

  • find . -name "*.js" — joriy papkadan barcha JS fayllarni topish.
  • find /var/log -type f -name "*.log" — faqat log fayllarni qidirish.
  • find . -size +100M — hajmi 100 MB dan katta fayllarni aniqlash.
  • find . -mtime -7 — oxirgi 7 kun ichida o'zgartirilgan fayllarni topish.
Bash / Linux Shell 
# Barcha HTML fayllarni topish
find . -name "*.html" -type f
🐧 Linux Terminal Natijasi:
💡 `-iname` bayrog'i katta-kichik harflarni farqlamasdan (case-insensitive) qidiradi.

Qidiruv Linux Mavzu #15

grep: Matn Ichidan Qidirish va Filtrlash

Global Regular Expression Print — fayllar ichidan yoki boshqa buyruq chiqarishidan aniq so'z yoki shablonni chaqmoqdek tezlikda qidirib topadi.

  • grep "qidirilayotgan_so'z" fayl.txt — mos keluvchi satrlarni ko'rsatish.
  • grep -i "error" server.log — katta-kichik harflarni inkor qilish.
  • grep -r "function auth" ./src — papka ichidagi barcha fayllar bo'ylab qidirish (rekurziv).
  • grep -n "PORT" .env — qaysi satrda joylashganini raqami bilan ko'rsatish.
Bash / Linux Shell 
# Log faylidan xatoliklarni ajratib olish
grep -i "error" /var/log/nginx/error.log
🐧 Linux Terminal Natijasi:
💡 grep Linux da eng ko'p ishlatiladigan vosita bo'lib, quvurlar (|) bilan birgalikda mo''jizalar yaratadi.

Arxiv Linux Mavzu #16

tar va gzip: Arxivlash va Qisqartirish

Bir nechta fayl va papkalarni bitta ixcham arxivga yig'ish (tar) va hajmini siqish (gzip, .tar.gz).

  • Yaratish: tar -czvf arxiv.tar.gz /papkaga_yo'l (c = create, z = gzip, v = verbose, f = file).
  • Ochish (Extract): tar -xzvf arxiv.tar.gz (x = extract).
  • Ko'rish: tar -tf arxiv.tar.gz — arxivni ochmasdan ichidagi fayllarni ro'yxat qilish.
Bash / Linux Shell 
# Loyihani arxivlab siqish va ochish
tar -czvf w3learn-backup.tar.gz ./pages
tar -tf w3learn-backup.tar.gz | head -n 3
🐧 Linux Terminal Natijasi:
💡 Linux olamida zip o'rniga asosan `.tar.gz` (tarball) standarti qo'llaniladi.

Xavfsizlik Linux Mavzu #17

chmod: Fayl Ruxsatlari (Permissions)

Linux da har bir fayl va papka uchun 3 toifa foydalanuvchiga 3 xil ruxsat belgilanadi: Read (r=4), Write (w=2), Execute (x=1).

  • Foydalanuvchilar toifasi: u (egasi), g (guruhi), o (boshqalar).
  • chmod 755 script.sh — Egasi: rwx (4+2+1=7), Guruh va boshqalar: r-x (4+0+1=5). Skriptlar uchun standart.
  • chmod 644 index.html — Egasi: rw- (6), Boshqalar: r-- (4). Oddiy fayllar uchun standart.
  • chmod 600 id_rsa — Faqat egasiga o'qish va yozish. Maxfiy SSH kalitlar uchun.
  • chmod +x script.sh — faylga ishga tushirish huquqini qo'shish.
Bash / Linux Shell 
# Skriptga ijro ruxsatini berish
chmod +x deploy.sh
ls -l deploy.sh
🐧 Linux Terminal Natijasi:
💡 Skriptni `./deploy.sh` deb yurgizishdan oldin unga albatta `chmod +x` berilishi shart.

Xavfsizlik Linux Mavzu #18

chown: Egasini O'zgartirish

Fayl yoki jildning egasini (owner) va guruhini (group) boshqa foydalanuvchiga o'tkazish.

  • chown yangi_ega fayl.txt — fayl egasini o'zgartirish.
  • chown ega:guruh fayl.txt — ham egasini, ham guruhini bir yo'la belgilash.
  • chown -R www-data:www-data /var/www/html — butun sayt papkasi va uning ichidagilarini veb-server foydalanuvchisiga o'tkazish (-R = rekurziv).
Bash / Linux Shell 
# Veb fayllar egaligini Nginx foydalanuvchisiga berish
sudo chown -R www-data:www-data /var/www/w3learn
ls -ld /var/www/w3learn
🐧 Linux Terminal Natijasi:
💡 Nginx yoki Apache sayt fayllarini o'qishi yoki rasm yuklashi uchun papka egaligi `www-data` ga beriladi.

Administrator Linux Mavzu #19

sudo va root: Bosh Administrator Huquqlari

root — Linux tizimida mutlaq cheklanmagan huquqlarga ega bosh super-foydalanuvchidir. sudo (SuperUser DO) esa oddiy foydalanuvchiga vaqtincha administratorlik huquqlari bilan buyruq bajarish imkonini beradi.

  • Xavfsizlik qoidasi: Kundalik ishlarda hech qachon to'g'ridan-to'g'ri root sifatida o'tirmang; faqat kerak bo'lganda sudo ishlating.
  • sudo buyruq — buyruqni administrator nomidan bajarish (o'z parolingizni kiritish so'raladi).
  • sudo -i yoki sudo su — root qobig'iga o'tish.
Bash / Linux Shell 
# Administrator huquqlari bilan yangilash
sudo apt update
🐧 Linux Terminal Natijasi:
💡 sudo orqali qilingan har bir harakat `/var/log/auth.log` faylida qayd etib boriladi.

Tizim Linux Mavzu #20

Foydalanuvchilar va Guruhlar Boshqaruvi

Serverda yangi foydalanuvchilar ochish, ularga parol berish va guruhlarga kiritish.

  • useradd -m dasturchi — yangi foydalanuvchi yaratish (-m = uy papkasini ochish).
  • passwd dasturchi — foydalanuvchiga parol belgilash.
  • usermod -aG sudo dasturchi — foydalanuvchini sudoers guruhiga qo'shish.
  • userdel -r dasturchi — foydalanuvchi va uning uy papkasini butunlay o'chirish.
Bash / Linux Shell 
# Yangi dasturchi akkaunti yaratish
sudo useradd -m -s /bin/bash sherzod
sudo usermod -aG docker sherzod
id sherzod
🐧 Linux Terminal Natijasi:
💡 `-s /bin/bash` yangi foydalanuvchiga standart qulay qobiqni biriktiradi.

Monitoring Linux Mavzu #21

ps va top: Jarayonlarni Kuzatish (Processes)

Tizimda ishlayotgan barcha jarayonlar (Programs/Processes), ularning CPU va operativ xotirani sarflashini tahlil qilish.

  • ps aux — barcha foydalanuvchilarning barcha ishlayotgan jarayonlarini chiqarish.
  • ps aux | grep node — Node.js dasturi qaysi PID (Process ID) bilan ishlayotganini topish.
  • top — tizim holatini real-vaqtda ko'rsatuvchi interaktiv panel (q bilan chiqiladi).
  • htop — qulay, rangli va sichqonchani qo'llab-quvvatlovchi yaxshilangan monitoring utilitasi.
Bash / Linux Shell 
# Node jarayonini qidirish
ps aux | grep -i "node"
🐧 Linux Terminal Natijasi:
💡 PID (Process ID) — har bir jarayonning tizimdagi noyob raqamidir; masalan yuqorida node ning PID si `12450`.

Jarayonlar Linux Mavzu #22

kill va pkill: Jarayonlarni To'xtatish

Qotib qolgan yoki resurslarni yeb yotgan dasturlarni to'xtatish buyruqlari.

  • kill — SIGTERM (15) yumshoq to'xtatish signalini yuboradi (dastur o'z ma'lumotlarini saqlab yopiladi).
  • kill -9 — SIGKILL (9) majburiy bir lahzada o'ldirish signali (keskin to'xtatadi).
  • pkill -f dastur_nomi — PID raqamini qidirmasdan, dastur nomi bo'yicha to'xtatish.
  • killall nginx — berilgan nomdagi barcha jarayonlarni o'ldiradi.
Bash / Linux Shell 
# PID bo'yicha jarayonni to'xtatish
kill 12450
# Yoki nom bo'yicha majburiy to'xtatish
pkill -9 -f "node server.js"
🐧 Linux Terminal Natijasi:
💡 Dastlab har doim oddiy `kill` (SIGTERM) ishlatiladi, faqat dastur bo'ysunmay qotib qolsagina `kill -9` qo'llanadi.

Jarayonlar Linux Mavzu #23

jobs, bg va fg: Fon Rejimida Ishlash

Uzoq vaqt oluvchi vazifalarni terminalni band qilmasdan fonda yurgizish.

  • Buyruq oxiriga & qo'yish — buyruq darhol fonda (background) boshlanadi (masalan: python script.py &).
  • Ctrl + Z — ishlab turgan dasturni vaqtincha to'xtatib (pause) orqa fonga o'tkazish.
  • bg — to'xtatilgan vazifani orqa fonda davom ettirish.
  • fg — orqa fondagi vazifani oldinga (foreground) qaytarib olish.
  • nohup buyruq & — terminal yopilib ketsa ham dastur fonda o'lmasdan ishlashda davom etadi.
Bash / Linux Shell 
# Skriptni fonda ishga tushirish va tekshirish
nohup python3 worker.py > worker.log 2>&1 &
jobs -l
🐧 Linux Terminal Natijasi:
💡 Masofaviy SSH orqali uzoq muddatli dasturlarni ishlatganda `nohup` yoki `tmux` / `screen` vositalaridan foydalanish shart.

systemctl: Tizim Servislarini Boshqarish

Linux da doimiy ishlovchi xizmatlar (Nginx, PostgreSQL, Docker, Redis) systemd orqali boshqariladi.

Tarmoq Linux Mavzu #25

ssh: Masofaviy Serverga Xavfsiz Ulanish

Secure Shell (SSH) — dunyoning istalgan burchagida joylashgan Linux serverining konsoliga shifrlangan xavfsiz kanal orqali ulanish protokoli.

  • ssh foydalanuvchi@server_ip — serverga parol orqali ulanish (masalan: ssh ubuntu@192.168.1.100).
  • Standart port: 22 (agar boshqa port bo'lsa: -p 2222).
  • SSH kalitlari (Asymmetric Keys): Parolsiz, favqulodda xavfsiz ulanish usuli.
  • Kalit juftligini yaratish: ssh-keygen -t ed25519 -C "email@mail.uz".
  • Ochiq kalitni serverga o'tkazish: ssh-copy-id ubuntu@server_ip.
Bash / Linux Shell 
# SSH kalit orqali serverga ulanish
ssh -i ~/.ssh/id_ed25519 ubuntu@192.168.1.50
🐧 Linux Terminal Natijasi:
💡 Production serverlarda parol bilan kirishni o'chirib qo'yish (PasswordAuthentication no) va faqat SSH kalitlar orqali kirish xavfsizlikning oltin qoidasidir.

Tarmoq Linux Mavzu #28

netstat, ss va lsof: Tarmoq Portlarini Tekshirish

Serverda qaysi portlar ochiqligi (80, 443, 3000, 5432) va qaysi dastur ularni egallab turganini aniqlash.

Quvurlar Linux Mavzu #29

Quvurlar (| - Pipe): Buyruqlarni Birlashtirish

Unix falsafasining eng buyuk kashfiyoti: bitta buyruqning chiqish natijasini (Output) to'g'ridan-to'g'ri keyingi buyruqning kirishiga (Input) quvur | orqali ulash.

Oqimlar Linux Mavzu #30

Kiritish/Chiqarishni Yo'naltirish (Redirection)

Natijani ekranga chiqarmasdan faylga yozish yoki fayldan o'qish yo'naltirish belgilari.

  • > fayl.txt — yangitdan yozish (mavjud fayl ustiga bostirib yozadi - overwrite).
  • >> fayl.txt — fayl oxiriga qo'shish (append).
  • < fayl.sql — fayldan ma'lumotni kiritish sifatida o'qish (masalan: mysql < dump.sql).
  • 2>&1 — standart xatoliklar (stderr) va oddiy chiqarishlarni (stdout) bitta joyga birlashtirish.
  • /dev/null — 'qora tuynuk'; natijani butunlay yutib yuborish (> /dev/null 2>&1).
Bash / Linux Shell 
# Tizim ma'lumotlarini faylga saqlab borish
echo "Loyiha boshlandi: $(date)" > report.log
echo "Server holati: OK" >> report.log
cat report.log
🐧 Linux Terminal Natijasi:
💡 `>>` dan foydalanish juda muhim, chunki `>` adashib eski yozuvlarni o'chirib yuborishi mumkin.

Avtomatlashtirish Linux Mavzu #32

crontab: Rejali Vazifalarni Avtomatlashtirish
