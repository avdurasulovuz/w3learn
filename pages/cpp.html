Asosiy C++ Mavzu #1

C++ Nima? Kirish

C++ — 1979-yilda Bjarne Stroustrup tomonidan Bell Labs da yaratilgan, dunyodagi eng tezkor, kuchli va universal dasturlash tillaridan biridir. U C tilining kengaytmasi bo'lib, ob'ektga yo'naltirilgan dasturlash (OOP), quyi darajadagi xotirani bevosita boshqarish va maksimal unumdorlikni ta'minlaydi.

  • Operatsion tizimlar (Windows, Linux, macOS yadrolari), o'yin dvigatellari (Unreal Engine) va brauzerlar (Chrome V8) C++ da yozilgan.
  • Kompilyatsiya qilinadigan til — kod to'g'ridan-to'g'ri mashina kodiga (0 va 1 ga) aylanadi va maksimal tezlikda bajariladi.
  • Xotirani (RAM) dasturchi o'zi to'liq nazorat qila oladi.
  • Ko'p paradigmali til: protsedurali, ob'ektga yo'naltirilgan va umumiy (generic) dasturlashni qo'llab-quvvatlaydi.
C++20 Kodi 
// C++ dasturining umumiy ko'rinishi
#include <iostream>

int main() {
    std::cout << "Salom, C++ Dunyosi! 🚀\n";
    std::cout << "Tezlik va qudrat birlashgan til!\n";
    return 0;
}
🖥️ C++ Kompilyator Natijasi:
💡 C++ boshqa tillarga qaraganda kompyuter apparatiga (hardware) eng yaqin bo'lgan yuqori darajadagi tildir.

O'rnatish C++ Mavzu #2

C++ Kompilyatori (GCC / MinGW / Clang / MSVC)

C++ kodlarini ishga tushirish uchun kompilyator kerak. Kompilyator inson o'qiydigan .cpp faylni kompyuter tushunadigan .exe ikkilik (binary) faylga aylantiradi.

  • Windows uchun: MinGW-w64 (GCC) yoki Visual Studio (MSVC).
  • Linux uchun: sudo apt install g++ build-essential.
  • macOS uchun: xcode-select --install (Clang).
  • Kompilyatsiya buyrug'i: g++ -O3 main.cpp -o main.exe.
C++20 Kodi 
# Terminalda versiyani tekshirish:
g++ --version

# Dasturni kompilyatsiya qilish va ishga tushirish:
g++ -std=c++20 main.cpp -o dastur
./dastur
🖥️ C++ Kompilyator Natijasi:
⚡ -std=c++20 bayrog'i kompilyatorga C++20 zamonaviy standartlaridan foydalanishni buyuradi.

Hello World va Dastur Tuzilishi

Har qanday C++ dasturi main() funksiyasidan boshlanadi. Har bir satr oxiriga nuqta-vergul ; qo'yilishi shart.

int main() {

Asoslar C++ Mavzu #4

O'zgaruvchilar va Nomlash Qoidalari

C++ qat'iy tipli (statically-typed) til hisoblanadi. O'zgaruvchi e'lon qilinayotganda uning qaysi turdagi ma'lumot saqlashi oldindan ko'rsatilishi shart.

  • Sintaksis: tip o'zgaruvchi_nomi = qiymat;.
  • Konstantalar: const double PI = 3.14159; — qiymatini o'zgartirib bo'lmaydi.
  • Zamonaviy C++ da auto kalit so'zi tipni berilgan qiymatdan o'zi aniqlab oladi.
C++20 Kodi 
#include <iostream>
#include <string>

int main() {
    int yosh = 22;
    double vazn = 74.5;
    char baxo = 'A';
    bool talabami = true;
    std::string ism = "Jahongir";

    const int YORUG_TEZLIGI = 300000; // km/s

    std::cout << "Ismi: " << ism << ", Yoshi: " << yosh << "\n";
    std::cout << "Vazni: " << vazn << " kg, Baxosi: " << baxo << "\n";
    return 0;
}

Tiplar C++ Mavzu #5

Ma'lumot Turlari va Xotira Hajmi (sizeof)

C++ da har bir ma'lumot turi xotirada (RAM) aniq bayt miqdorini egallaydi. Buni sizeof() operatori orqali tekshirish mumkin.

  • int — butun sonlar (odatda 4 bayt: -2 milliarddan +2 milliardgacha).
  • double — 8 bayt, o'nli kasr sonlar (aniqligi yuqori).
  • char — 1 bayt, bitta belgi ('A', 'z', '7').
  • bool — 1 bayt, mantiqiy qiymat (true = 1, false = 0).
  • long long — 8 bayt, juda katta butun sonlar uchun.
C++20 Kodi 
#include <iostream>

int main() {
    std::cout << "int hajmi: " << sizeof(int) << " bayt\n";
    std::cout << "double hajmi: " << sizeof(double) << " bayt\n";
    std::cout << "char hajmi: " << sizeof(char) << " bayt\n";
    std::cout << "bool hajmi: " << sizeof(bool) << " bayt\n";
    std::cout << "long long hajmi: " << sizeof(long long) << " bayt\n";
    return 0;
}
🖥️ C++ Kompilyator Natijasi:
💡 Katta sonlar (masalan 10 milliard) bilan ishlaganda oddiy int sig'may qoladi va overflow yuz beradi, bunday holatda long long ishlatish shart.

Operatorlar C++ Mavzu #6

Operatorlar — Arifmetik, Taqqoslash va Mantiqiy

C++ tili boy operatorlar to'plamiga ega bo'lib, ular sonlar va mantiqiy ifodalar ustida amallar bajarishga xizmat qiladi.

  • Arifmetik: +, -, *, /, % (qoldiqli bo'lish).
  • Inkrament/Dekrament: ++a, a++, --a.
  • Taqqoslash: ==, !=, >, <, >=, <=.
  • Mantiqiy: && (VA / AND), || (YOKI / OR), ! (EMAS / NOT).
C++20 Kodi 
#include <iostream>

int main() {
    int a = 17, b = 5;
    
    std::cout << "Bo'lish (butun qism): " << a / b << "\n";
    std::cout << "Qoldiq (%): " << a % b << "\n";
    
    bool natija = (a > 10) && (b == 5);
    std::cout << "Mantiqiy ifoda natijasi: " << std::boolalpha << natija << "\n";
    return 0;
}
🖥️ C++ Kompilyator Natijasi:
⚡ Butun sonlarni bo'lganda (17 / 5) kasr qismi tashlab yuboriladi va natija 3 bo'ladi. Haqiqiy kasr natija olish uchun kamida bittasini double qilish kerak: 17.0 / 5.

Mantiq C++ Mavzu #7

Shart Operatorlari — if, else if, else va switch

Dastur oqimini ma'lum shartlarga qarab tarmoqlantirish uchun if-else va switch-case operatorlari ishlatiladi.

  • if (shart) { ... } else if (shart2) { ... } else { ... }.
  • Ternar operator: int max = (a > b) ? a : b;.
  • switch (qiymat) faqat butun sonlar (int, char, enum) bilan ishlaydi va har bir case oxiriga break; qo'yiladi.
C++20 Kodi 
#include <iostream>

int main() {
    int ball = 85;

    if (ball >= 90) {
        std::cout << "A'lo (A)\n";
    } else if (ball >= 80) {
        std::cout << "Yaxshi (B)\n";
    } else if (ball >= 70) {
        std::cout << "Qoniqarli (C)\n";
    } else {
        std::cout << "Qoniqarsiz (F)\n";
    }

    int kun = 3;
    switch(kun) {
        case 1: std::cout << "Dushanba\n"; break;
        case 2: std::cout << "Seshanba\n"; break;
        case 3: std::cout << "Chorshanba\n"; break;
        default: std::cout << "Boshqa kun\n";
    }
    return 0;
}
🖥️ C++ Kompilyator Natijasi:
💡 switch da break yozishni unutsangiz, dastur keyingi holatlarni ham shartsiz bajarib yuboradi (fall-through effekti).

Sikllar C++ Mavzu #8

Sikllar — for, while, do-while va Range-based for

Bir xil kod blokini bir necha marta takrorlash uchun sikllar ishlatiladi. Zamonaviy C++ da to'plamlar ustida aylanish uchun Range-based for eng qulay usuldir.

  • for: qadamlar soni oldindan ma'lum bo'lganda.
  • while: shart bajarilib turguncha takrorlanadi.
  • do-while: shartdan qat'i nazar kamida bir marta bajariladi.
  • Range-based for: for (auto item : collection) — massiv yoki vektorlarni qulay aylanish.
C++20 Kodi 
#include <iostream>

int main() {
    // Standart for
    std::cout << "for sikli: ";
    for (int i = 1; i <= 5; ++i) {
        std::cout << i << " ";
    }
    std::cout << "\n";

    // Range-based for (C++11)
    int sonlar[] = {10, 20, 30, 40, 50};
    std::cout << "Massiv elementlari: ";
    for (int x : sonlar) {
        std::cout << x << " ";
    }
    std::cout << "\n";
    return 0;
}
🖥️ C++ Kompilyator Natijasi:
⚡ break siklni muddatidan oldin to'xtatadi, continue esa joriy qadamni o'tkazib yuborib keyingi iteratsiyaga o'tadi.

Funksiyalar C++ Mavzu #9

Funksiyalar va Parametrlarni Uzatish

Funksiya — ma'lum vazifani bajaruvchi mustaqil kod blokidir. C++ da parametrlarni qiymat bo'yicha (by value) yoki havola bo'yicha (by reference) uzatish mumkin.

  • Hech narsa qaytarmaydigan funksiyalar void tipi bilan belgilanadi.
  • Qiymat bo'yicha uzatish parametrning nusxasini oladi, asl qiymat o'zgarmaydi.
  • Havola bo'yicha uzatish (int &x) asl o'zgaruvchining o'zini o'zgartiradi va xotirani tejaydi.
  • Standart qiymatli parametrlar: void greet(std::string name = "Mehmon").
C++20 Kodi 
#include <iostream>

// Qiymatlarni almashtirish (Swap by reference)
void almashtir(int &a, int &b) {
    int temp = a;
    a = b;
    b = temp;
}

int kvadrat(int son) {
    return son * son;
}

int main() {
    int x = 10, y = 50;
    std::cout << "Oldin: x=" << x << ", y=" << y << "\n";
    almashtir(x, y);
    std::cout << "Keyin: x=" << x << ", y=" << y << "\n";
    std::cout << "7 ning kvadrati: " << kvadrat(7) << "\n";
    return 0;
}
🖥️ C++ Kompilyator Natijasi:
💡 Katta ob'ektlar yoki matnlarni funksiyaga uzatganda nusxa ko'chirish vaqtini tejash uchun const std::string &matn ko'rinishida uzatish eng to'g'ri amaliyotdir.

Massivlar C++ Mavzu #10

Massivlar (Arrays) — 1D va Ko'p O'lchovli

Massiv — bir xil turdagi elementlarning xotirada ketma-ket joylashgan qat'iy o'lchamli to'plamidir. Indekslash 0 dan boshlanadi.

  • E'lon qilish: int baholar[5] = {5, 4, 5, 3, 4};.
  • Elementga murojaat: baholar[0] — birinchi element.
  • Ko'p o'lchamli massivlar: int matritsa[3][3]; (matritsa, jadval).
  • Statik massiv o'lchamini dastur davomida o'zgartirib bo'lmaydi.
C++20 Kodi 
#include <iostream>

int main() {
    int jadval[2][3] = {
        {1, 2, 3},
        {4, 5, 6}
    };

    std::cout << "Matritsa elementlari:\n";
    for (int i = 0; i < 2; ++i) {
        for (int j = 0; j < 3; ++j) {
            std::cout << jadval[i][j] << " ";
        }
        std::cout << "\n";
    }
    return 0;
}
🖥️ C++ Kompilyator Natijasi:
⚡ Massiv chegarasidan tashqariga chiqish (masalan 5 ta elementli massivning 10-elementiga murojaat qilish) xavfli xatolik (Segmentation Fault) keltirib chiqaradi.

String C++ Mavzu #11

String — std::string Klassi va Metodlari

C tilidagi noqulay char[] massivlari o'rniga zamonaviy C++ da kuchli va qulay std::string klassi ishlatiladi.

  • Uzunlikni aniqlash: s.length() yoki s.size().
  • Matnlarni birlashtirish: + operatori orqali (konkatenatsiya).
  • Qidirish: s.find("so'z").
  • Qism matnni qirqib olish: s.substr(boshlanish, uzunlik).
  • Bo'shliq bilan butun satrni o'qish: std::getline(std::cin, s).
C++20 Kodi 
#include <iostream>
#include <string>

int main() {
    std::string matn = "O'zbekiston kelajagi buyuk davlat!";
    
    std::cout << "Uzunligi: " << matn.length() << "\n";
    std::cout << "Qism matn (substr): " << matn.substr(0, 11) << "\n";
    
    // Matn oxiriga qo'shish
    matn += " 🇺🇿";
    std::cout << "Yangi matn: " << matn << "\n";
    return 0;
}
🖥️ C++ Kompilyator Natijasi:
💡 std::string xotira hajmini dinamik ravishda o'zi boshqaradi, dasturchi xotira ajratish haqida bosh qotirishi shart emas.

Pointer C++ Mavzu #12

Pointer (Ko'rsatkich) Nima? Xotira Manzillari

Pointer (Ko'rsatkich) — C va C++ ning eng qudratli vositasi bo'lib, o'zida qiymat emas, balki boshqa o'zgaruvchining kompyuter tezkor xotirasidagi (RAM) manzilini saqlaydigan maxsus o'zgaruvchidir.

  • Manzil olish operatori: &x (x o'zgaruvchisining RAM dagi 16-lik manzili).
  • Pointer e'lon qilish: int *ptr = &x;.
  • Dereferencing (qiymatni olish): *ptr — ko'rsatkich qaratilgan manzildagi haqiqiy qiymatni o'qiydi yoki o'zgartiradi.
  • Bo'sh ko'rsatkich: nullptr.
C++20 Kodi 
#include <iostream>

int main() {
    int son = 42;
    int *ptr = &son; // ptr son ning manzilini saqlaydi

    std::cout << "son ning qiymati: " << son << "\n";
    std::cout << "son ning RAM dagi manzili: " << &son << "\n";
    std::cout << "ptr saqlayotgan manzil: " << ptr << "\n";
    std::cout << "*ptr orqali qiymatni o'qish: " << *ptr << "\n";

    // Pointer orqali qiymatni o'zgartirish:
    *ptr = 100;
    std::cout << "Yangi qiymat (son): " << son << "\n";
    return 0;
}
🖥️ C++ Kompilyator Natijasi:
⚡ Pointerlar orqali operativ xotiradagi ma'lumotlarni nusxa ko'chirmasdan eng yuqori tezlikda boshqarish mumkin.

Reference C++ Mavzu #13

Reference (&) — Taxallus (Alias)

Reference (Havola) — mavjud o'zgaruvchining ikkinchi nomi (taxallusi) dir. Ko'rsatkichdan farqli ravishda u nullptr bo'la olmaydi va e'lon qilingan zahoti aniq bir o'zgaruvchiga bog'lanishi shart.

  • E'lon qilish: int &ref = x;.
  • ref ustida bajarilgan har qanday amal to'g'ridan-to'g'ri x ning o'zida sodir bo'ladi.
  • Pointerga qaraganda xavfsizroq va sintaksisi oddiy o'zgaruvchidek qulay.
C++20 Kodi 
#include <iostream>

int main() {
    int asl = 50;
    int &taxallus = asl; // asl ning ikkinchi nomi

    taxallus += 25; // asl ham 75 ga aylanadi

    std::cout << "asl: " << asl << "\n";
    std::cout << "taxallus: " << taxallus << "\n";
    std::cout << "Ikkalasining manzili bir xil: " << &asl << " == " << &taxallus << "\n";
    return 0;
}
🖥️ C++ Kompilyator Natijasi:
💡 C++ da funksiyalarga obyektlarni uzatishda ko'rsatkichdan ko'ra const ClassName &obj reference ishlatish tavsiya etiladi.

Xotira C++ Mavzu #14

Dinamik Xotira — Stack vs Heap

Kompyuter xotirasi ikkita asosiy qismdan iborat: Stack va Heap. Stack tez ishlaydi va avtomatik tozalanadi, Heap esa dasturchi tomonidan boshqariladigan katta xotira maydonidir.

  • Stack: mahalliy o'zgaruvchilar va funksiya chaqiriqlari saqlanadi. Hajmi cheklangan (odatda 1-8 MB).
  • Heap: dastur ishlashi davomida (runtime) kerakli miqdorda ajratiladi. Gigabaytlab hajmga ega bo'lishi mumkin.
  • Heap xotirasidan olingan joyni dasturchi o'zi qo'lda bo'shatishi shart, aks holda Memory Leak (xotira sizib chiqishi) yuz beradi.
C++20 Kodi 
#include <iostream>

int main() {
    // Stack dagi o'zgaruvchi (avtomatik o'chadi)
    int stackSon = 10;

    // Heap dagi dinamik xotira (dasturchi boshqaradi)
    int *heapSon = new int(200);

    std::cout << "Stack qiymat: " << stackSon << "\n";
    std::cout << "Heap qiymat: " << *heapSon << "\n";

    // Heap dagi xotirani bo'shatish shart!
    delete heapSon;
    heapSon = nullptr;
    
    return 0;
}
🖥️ C++ Kompilyator Natijasi:
⚡ Xotirani bo'shatgandan so'ng pointerni nullptr ga tenglab qo'yish xavfsizlik (Dangling pointer oldini olish) uchun juda muhim.

Xotira C++ Mavzu #15

new va delete Operatorlari

Heap dan dinamik xotira ajratish uchun new, uni qaytarib operatsion tizimga topshirish uchun delete operatori ishlatiladi. Dinamik massivlar uchun new[] va delete[] qo'llaniladi.

  • Bitta element ajratish: int *p = new int(15); -> delete p;.
  • Dinamik massiv: int *arr = new int[n]; -> delete[] arr;.
  • Agar kvadrat qavsli delete[] ishlatilmasa, faqat birinchi element o'chadi va qolganlari xotirada qolib ketadi.
C++20 Kodi 
#include <iostream>

int main() {
    int n = 5;
    // O'lchami runtime da belgilanadigan massiv
    int *massiv = new int[n];

    for (int i = 0; i < n; ++i) {
        massiv[i] = (i + 1) * 10;
    }

    std::cout << "Dinamik massiv: ";
    for (int i = 0; i < n; ++i) {
        std::cout << massiv[i] << " ";
    }
    std::cout << "\n";

    // Butun massiv xotirasini bo'shatish:
    delete[] massiv;
    massiv = nullptr;
    return 0;
}
🖥️ C++ Kompilyator Natijasi:
💡 Har bir new ga bitta delete, har bir new[] ga bitta delete[] mos kelishi shart.

OOP C++ Mavzu #16

Klasslar va Ob'ektlar (OOP Asoslari)

C++ ob'ektga yo'naltirilgan dasturlash (OOP) tamoyillariga to'liq asoslangan. Klass — bu yangi ma'lumot turining qolipi (blueprint), ob'ekt esa shu klass asosida yaratilgan aniq nusxadir.

  • Kirish huquqlari (Access Specifiers): public (hammaga ochiq), private (faqat klass ichida), protected (merosxo'rlarga ochiq).
  • Inkapsulyatsiya (Encapsulation) — ma'lumotlarni private qilib, ularga getter/setter metodlari orqali kirishni ta'minlash.
  • Klass e'lonidan so'ng oxiriga nuqta-vergul }; qo'yish shart.
C++20 Kodi 
#include <iostream>
#include <string>

class Mashina {
private:
    std::string model;
    int yil;

public:
    // Metodlar (Getter va Setter)
    void setModel(std::string m) { model = m; }
    std::string getModel() { return model; }

    void setYil(int y) { yil = y; }
    int getYil() { return yil; }

    void signalChal() {
        std::cout << model << ": Bip-bip! 🚗\n";
    }
};

int main() {
    Mashina gentra;
    gentra.setModel("Chevrolet Gentra");
    gentra.setYil(2024);

    std::cout << "Model: " << gentra.getModel() << ", Yil: " << gentra.getYil() << "\n";
    gentra.signalChal();
    return 0;
}

OOP C++ Mavzu #17

Konstruktor va Destruktor

Konstruktor — ob'ekt xotirada yaratilayotgan paytda avtomatik ishga tushadigan maxsus metod. Destruktor — ob'ekt o'chirilayotganda resurslarni tozalash uchun avtomatik chaqiriladigan metoddir.

  • Konstruktor nomi klass nomi bilan bir xil bo'ladi va hech qanday qaytarish turiga (hatto void ga ham) ega emas.
  • Destruktor nomi oldiga tilda ~ belgisi qo'yiladi (masalan, ~KlassNomi()).
  • Destruktor hech qanday parametr qabul qilmaydi va xotirani bo'shatish uchun ayni muddao.
C++20 Kodi 
#include <iostream>
#include <string>

class Kitob {
public:
    std::string nom;
    double narx;

    // Parametrli konstruktor
    Kitob(std::string n, double p) : nom(n), narx(p) {
        std::cout << "Konstruktor: '" << nom << "' yaratildi.\n";
    }

    // Destruktor
    ~Kitob() {
        std::cout << "Destruktor: '" << nom << "' xotiradan o'chirildi.\n";
    }
};

int main() {
    {
        Kitob k1("C++ Dasturlash Asoslari", 85000);
    } // k1 ning yashash sohasi tugadi, destruktor avtomatik ishlaydi
    
    std::cout << "Dastur davom etmoqda...\n";
    return 0;
}

OOP C++ Mavzu #18

Meros Olish (Inheritance)

Meros — mavjud ota klass (Base class) xususiyatlari va metodlarini yangi bola klassga (Derived class) o'tkazish imkoniyatidir. Bu kodni qayta ishlatishni ta'minlaydi.

  • Sintaksis: class Bola : public Ota { ... };.
  • public meros olinganda ota klassning public va protected a'zolari bolaga ham o'tadi.
  • C++ ko'p martalik meros olishni (Multiple Inheritance — bitta klass bir vaqtning o'zida ikkita ota klassdan voris olishi) qo'llab-quvvatlaydi.
C++20 Kodi 
#include <iostream>
#include <string>

// Ota klass
class Hayvon {
public:
    void ovqatlan() {
        std::cout << "Bu hayvon ovqatlanmoqda...\n";
    }
};

// Bola klass
class Kuchuk : public Hayvon {
public:
    void vovulla() {
        std::cout << "Vov-vov! 🐕\n";
    }
};

int main() {
    Kuchuk bobik;
    bobik.ovqatlan(); // Ota klass metodi
    bobik.vovulla();   // O'z metodi
    return 0;
}
🖥️ C++ Kompilyator Natijasi:
⚡ Agar ota klassning biror maydoni faqat bola klasslarga ko'rinishi, lekin tashqariga yopiq bo'lishi kerak bo'lsa, uni protected qilish lozim.

Polimorfizm C++ Mavzu #19

Virtual Funksiyalar va Polimorfizm

Polimorfizm — bitta interfeys orqali turli obyektlarning har xil o'ziga xos harakatini boshqarish imkoniyatidir. Bunga C++ da virtual funksiyalar va override orqali erishiladi.

  • Ota klassdagi metod oldiga virtual yozilsa, chaqiruv paytida ko'rsatkich qaysi obyektga qaratilgan bo'lsa, aynan o'sha bolaning metodi bajariladi (Dynamic Dispatch).
  • Sof virtual funksiya (Pure virtual): virtual void chiz() = 0; — bu klassni Abstrakt klassga aylantiradi.
C++20 Kodi 
#include <iostream>
#include <vector>

class Shakl {
public:
    virtual void chiz() {
        std::cout << "Noma'lum shakl chizilmoqda\n";
    }
    virtual ~Shakl() {}
};

class Aylana : public Shakl {
public:
    void chiz() override {
        std::cout << "Aylana chizildi: ⭕\n";
    }
};

class Tortburchak : public Shakl {
public:
    void chiz() override {
        std::cout << "To'rtburchak chizildi: ⬛\n";
    }
};

int main() {
    Shakl *s1 = new Aylana();
    Shakl *s2 = new Tortburchak();

    s1->chiz(); // Aylana metodi chaqiriladi
    s2->chiz(); // Tortburchak metodi chaqiriladi

    delete s1;
    delete s2;
    return 0;
}
🖥️ C++ Kompilyator Natijasi:
💡 Agar klassingizda kamida bitta virtual funksiya bo'lsa, uning destruktorini ham albatta virtual ~Klass() qilish shart!

OOP C++ Mavzu #20

Operator va Funksiya Overloading (Qayta Yuklash)

C++ da bir xil nomli funksiyalarni turli parametrlar bilan bir necha marta e'lon qilish mumkin (Function Overloading). Shuningdek, +, -, << kabi standart operatorlarning o'z klasslaringiz uchun qanday ishlashini ham belgilashingiz mumkin (Operator Overloading).

  • Funksiya qayta yuklash: parametrlar soni yoki turlari bilan farqlanishi shart.
  • Operator qayta yuklash: Natija operator+(const Klass &other).
  • Foydalanuvchi klasslarini xuddi sonlar kabi qo'shish yoki cout << obj orqali chiqarish imkonini beradi.
C++20 Kodi 
#include <iostream>

class Nuqta {
public:
    int x, y;
    Nuqta(int x = 0, int y = 0) : x(x), y(y) {}

    // + operatorini qayta yuklash
    Nuqta operator+(const Nuqta &boshqa) {
        return Nuqta(this->x + boshqa.x, this->y + boshqa.y);
    }
};

int main() {
    Nuqta p1(5, 10);
    Nuqta p2(15, 20);

    Nuqta p3 = p1 + p2; // Operator overloading tufayli ishlaydi!

    std::cout << "Yangi nuqta: (" << p3.x << ", " << p3.y << ")\n";
    return 0;
}
🖥️ C++ Kompilyator Natijasi:
⚡ Operator overloading kodni juda tabiiy va o'qish uchun sodda qiladi, ammo uni me'yorida ishlatish tavsiya etiladi.

Templates C++ Mavzu #21

Templates (Shablonlar) — Generic Dasturlash

Shablonlar — ma'lumotlar turiga bog'liq bo'lmagan universal funksiya va klasslar yozish imkonini beradi. Bitta funksiya yozib, uni ham int, ham double, ham string uchun ishlatishingiz mumkin.

  • Sintaksis: template <typename T>.
  • Kompilyatsiya paytida (Compile-time) kerakli turlar uchun avtomatik alohida funksiyalar generatsiya qilinadi.
  • STL (Standard Template Library) to'liq shablonlar asosiga qurilgan.
C++20 Kodi 
#include <iostream>
#include <string>

    return (a > b) ? a : b;
}

int main() {
    std::cout << "Sonlar: " << kattasi(15, 42) << "\n";

    std::cout << "Matnlar: " << kattasi(std::string("Olma"), std::string("Banan")) << "\n";
    return 0;
}

std::vector — Zamonaviy Dinamik Massiv

std::vector — C++ STL (Standard Template Library) ning eng ko'p ishlatiladigan konteyneridir. U avtomatik ravishda o'lchamini kengaytiruvchi xavfsiz dinamik massivdir.

STL C++ Mavzu #23

std::map va unordered_map — Kalit-Qiymat Juftligi

Lug'at (Dictionary yoki Hash Table) tuzilmasi. Har bir kalitga (key) unga mos keluvchi qiymat (value) biriktiriladi.

  • std::map: Qizil-qora daraxt (Red-Black tree) asosida ishlaydi, kalitlar doimo avtomatik o'sish tartibida saralangan bo'ladi. Qidirish vaqti: O(log N).
  • std::unordered_map: Xesh-jadval (Hash Table) asosida ishlaydi, saralanmagan. Qidirish vaqti o'rtacha: O(1) — chaqmoqdek tez!
  • Elementga murojaat: lugat["kalit"] = qiymat;.
C++20 Kodi 
#include <iostream>
#include <string>
#include <unordered_map>

int main() {
    std::unordered_map<std::string, int> narxlar;

    narxlar["Olma"] = 12000;
    narxlar["Non"] = 4000;
    narxlar["Go'sht"] = 95000;

    std::cout << "Non narxi: " << narxlar["Non"] << " so'm\n";

    // Barcha tovarlarni aylanib chiqish
    std::cout << "\nDo'kondagi mahsulotlar:\n";
    for (const auto &[nom, narx] : narxlar) {
        std::cout << "- " << nom << ": " << narx << " so'm\n";
    }
    return 0;
}
🖥️ C++ Kompilyator Natijasi:
⚡ Agar kalitlar tartibi muhim bo'lmasa, maksimal tezlik uchun unordered_map ni tanlang.

STL C++ Mavzu #25

algorithm Kutubxonasi — Saralash va Qidirish

C++ ning <algorithm> sarlavha fayli konteynerlar ustida tezkor operatsiyalarni bajarish uchun 100 dan ortiq tayyor yuqori unumdorlikdagi funksiyalarni taqdim etadi.

  • std::sort(begin, end) — eng tezkor Introsort algoritmi (O(N log N)).
  • std::reverse(begin, end) — teskari o'girish.
  • std::find(begin, end, val) — elementni izlash.
  • std::count(begin, end, val) — element necha marta uchrashini sanash.
  • std::binary_search(begin, end, val) — ikkilik qidiruv (saralangan massivda chaqmoqdek tez).
C++20 Kodi 
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    std::vector<int> v = {9, 2, 7, 4, 5, 2, 8};

    std::sort(v.begin(), v.end());
    std::cout << "Saralangan: ";
    for (int x : v) std::cout << x << " ";
    std::cout << "\n";

    int qidirilayotgan = 7;
    if (std::binary_search(v.begin(), v.end(), qidirilayotgan)) {
        std::cout << qidirilayotgan << " to'plamda mavjud! ✅\n";
    }

    std::cout << "2 soni " << std::count(v.begin(), v.end(), 2) << " marta qatnashgan.\n";
    return 0;
}
🖥️ C++ Kompilyator Natijasi:
⚡ O'zingiz qidiruv yoki saralash algoritmini noldan yozishga vaqt sarflamang, std::algorithm funksiyalari apparat darajasida optimallashtirilgan.

Fayl C++ Mavzu #26

Fayl Bilan Ishlash — fstream (I/O)

Ma'lumotlarni qattiq diskdagi fayllarga yozish va ulardan o'qish uchun <fstream> kutubxonasi ishlatiladi.

  • std::ofstream (output file stream) — faylga yozish.
  • std::ifstream (input file stream) — fayldan o'qish.
  • std::fstream — bir vaqtning o'zida ham yozish, ham o'qish.
  • Fayl bilan ishlab bo'lgach, uni fayl.close() orqali yopish kerak.
C++20 Kodi 
#include <iostream>
#include <fstream>
#include <string>

int main() {
    // 1. Faylga yozish
    std::ofstream yozuvchi("malumot.txt");
    if (yozuvchi.is_open()) {
        yozuvchi << "C++ bilan faylga yozish juda oson!\n";
        yozuvchi << "W3Learn platformasi 2026\n";
        yozuvchi.close();
        std::cout << "Faylga muvaffaqiyatli yozildi.\n";
    }

    // 2. Fayldan o'qish
    std::ifstream oquvchi("malumot.txt");
    std::string qator;
    if (oquvchi.is_open()) {
        std::cout << "\nFayldan o'qilgan ma'lumotlar:\n";
        while (std::getline(oquvchi, qator)) {
            std::cout << ">> " << qator << "\n";
        }
        oquvchi.close();
    }
    return 0;
}

Xatolar C++ Mavzu #27

Istisnolar — try, catch va throw

Dastur ishlash jarayonida yuz berishi mumkin bo'lgan kutilmagan favqulodda xatoliklarni (masalan, nolga bo'lish, xotira yetishmasligi, fayl topilmasligi) ushlash va dastur qulab tushishining oldini olish uchun Istisnolar (Exceptions) ishlatiladi.

  • try — xato yuz berishi mumkin bo'lgan kod bloki.
  • throw — xatolik haqida xabar (istisno) otish.
  • catch (tur &e) — otilgan xatoni ushlab xavfsiz qayta ishlash.
  • Barcha standart xatolar std::exception klassidan kelib chiqadi.
C++20 Kodi 
#include <iostream>
#include <stdexcept>

double bolish(double a, double b) {
    if (b == 0.0) {
        throw std::runtime_error("Xatolik: Nolga bo'lish mumkin emas!");
    }
    return a / b;
}

int main() {
    try {
        std::cout << "10 / 2 = " << bolish(10, 2) << "\n";
        std::cout << "10 / 0 = " << bolish(10, 0) << "\n";
    } catch (const std::exception &e) {
        std::cerr << "Ushlangan xato: " << e.what() << "\n";
    }
    std::cout << "Dastur xatosiz ishlashda davom etmoqda.\n";
    return 0;
}
🖥️ C++ Kompilyator Natijasi:
⚡ Agar xatolik try-catch bilan ushlanmasa, operatsion tizim dasturni majburiy to'xtatadi (crash).

SmartPtr C++ Mavzu #29

Smart Pointerlar — unique_ptr va shared_ptr

Zamonaviy C++ (C++11 va undan keyingi) dasturlashda qo'lda delete yozish eskirgan usul hisoblanadi. Smart Pointerlar ob'ekt o'z vazifasini bajarib bo'lgach (yashash sohasi tugaganda) xotirani avtomatik tozalaydi, bu esa Memory Leak xatolarini 100% yo'q qiladi.

  • std::unique_ptr: Ob'ektga faqat bitta egasi (owner) bo'ladi. Nusxa olib bo'lmaydi, faqat ko'chirish (move) mumkin. Eng tezkor!
  • std::shared_ptr: Ob'ektga bir nechta ko'rsatkich bir vaqtning o'zida egalik qilishi mumkin. Murojaatlar hisoblagichi (reference count) 0 bo'lganda ob'ekt avtomatik o'chadi.
  • Yaratish: auto p = std::make_unique<Klass>();.
C++20 Kodi 
#include <iostream>
#include <memory>

class Foydalanuvchi {
public:
    Foydalanuvchi() { std::cout << "Foydalanuvchi obyekti yaratildi.\n"; }
    ~Foydalanuvchi() { std::cout << "Foydalanuvchi xotiradan AVTOMATIK tozalandi! 🧹\n"; }
    void salom() { std::cout << "Smart pointer orqali metod chaqirildi!\n"; }
};

int main() {
    {
        // unique_ptr: delete yozish shart emas!
        std::unique_ptr<Foydalanuvchi> u = std::make_unique<Foydalanuvchi>();
        u->salom();
    } // Blok tugashi bilan destruktor avtomatik ishlaydi va xotira ozod bo'ladi

    std::cout << "Blokdan chiqildi.\n";
    return 0;
}
🖥️ C++ Kompilyator Natijasi:
🚀 Zamonaviy C++ dasturchilarining shiori: 'Oddiy xom ko'rsatkichlar (raw pointers) bilan xotira ajratmang, doimo std::make_unique yoki std::make_shared dan foydalaning!'
