Asosiy SQL Mavzu #1

SQL Nima? Kirish va Tarixi

SQL (Structured Query Language) — relyatsion ma'lumotlar bazalarini (RDBMS) boshqarish, so'rovlar yuborish, ma'lumotlarni saqlash, o'zgartirish va tahlil qilish uchun xalqaro standart dasturlash tilidir. U 1970-yillarda IBM tadqiqotchilari Raymond Boyce va Donald Chamberlin tomonidan yaratilgan.

  • Dunyoning 90% dan ortiq axborot tizimlari ma'lumotlarni saqlashda SQL dan foydalanadi.
  • Deklarativ til: siz kompyuterga qanday qilishni emas, qanday natija kerakligini aytasiz.
  • MySQL, PostgreSQL, Oracle, Microsoft SQL Server, SQLite barchasi SQL tilida so'rov qabul qiladi.
  • Backend dasturchilar, Data Scientistlar va ma'lumotlar tahlilchilari (Data Analyst) uchun eng birlamchi qurol.
SQL So'rovi 
-- SQL dagi eng mashhur birinchi so'rov
SELECT 
    'Assalomu alaykum, SQL Dunyosi! 🗄️' AS Salomlashuv,
    CURRENT_DATE AS BugungiSana;
🗄️ SQL RDBMS Natijasi:
💡 SQL kalit so'zlari katta yoki kichik harflarga sezgir emas (case-insensitive), ammo xalqaro odatga ko'ra kalit so'zlar KATTA harflar bilan yoziladi: SELECT, FROM, WHERE.

DBMS SQL Mavzu #2

DBMS Turlari — Relyatsion vs NoSQL

DBMS (Database Management System) — ma'lumotlar bazasini xavfsiz saqlash, boshqarish va unga ko'p foydalanuvchili kirishni ta'minlovchi dasturiy majmuadir. Ular asosan Relyatsion (RDBMS) va NoSQL turlariga bo'linadi.

  • RDBMS (Jadvalli): PostgreSQL, MySQL, SQL Server, Oracle, SQLite — qat'iy jadvallar va Primary/Foreign Key aloqalariga ega.
  • NoSQL (Hujjatsiz/Grafli): MongoDB (JSON hujjatlar), Redis (In-Memory Key-Value), Cassandra.
  • SQLite: Server talab qilmaydigan, to'g'ridan-to'g'ri bitta faylda saqlanuvchi eng ixcham va mobil ilovalar uchun mashhur baza.
SQL So'rovi 
-- Relyatsion tuzilma: Foydalanuvchilar va Buyurtmalar bog'liqligi
-- Jadvallar o'zaro ID orqali bog'lanadi (Foreign Key)

SELECT 
    f.ism, 
    f.shahar, 
    b.mahsulot, 
    b.narx
FROM foydalanuvchilar f
JOIN buyurtmalar b ON f.id = b.foydalanuvchi_id;
🗄️ SQL RDBMS Natijasi:
⚡ Relyatsion bazalarning ustunligi — ma'lumotlar yaxlitligi (Integrity) va qat'iy mantiqiy tuzilishidadir.

Sintaksis SQL Mavzu #3

SQL Sintaksisi va Buyruqlar Guruhlari

SQL buyruqlari o'z vazifasiga ko'ra to'rtta asosiy guruhga bo'linadi: DDL, DML, DQL va DCL.

  • DQL (Data Query Language): SELECT — ma'lumotlarni o'qish.
  • DML (Data Manipulation Language): INSERT, UPDATE, DELETE — ma'lumotlarni o'zgartirish.
  • DDL (Data Definition Language): CREATE, ALTER, DROP, TRUNCATE — jadvallar tuzilishini yaratish va o'chirish.
  • DCL / TCL: GRANT, REVOKE, COMMIT, ROLLBACK — ruxsatlar va tranzaksiyalar.
SQL So'rovi 
-- SQL izohlari:
-- Bu bir satrli izoh

/* Bu esa
   ko'p satrli izoh */

SELECT 100 * 1.12 AS NarxQQS;
🗄️ SQL RDBMS Natijasi:
💡 Har bir to'liq SQL buyrug'i oxiriga nuqta-vergul ; qo'yish shart.

DDL SQL Mavzu #4

CREATE DATABASE va DROP DATABASE

Yangi ma'lumotlar bazasini yaratish uchun CREATE DATABASE, mavjud bazani barcha jadvallari bilan butunlay o'chirib tashlash uchun DROP DATABASE ishlatiladi.

  • Yaratish: CREATE DATABASE baza_nomi;.
  • Xatolik bermasdan yaratish: CREATE DATABASE IF NOT EXISTS dokon_db;.
  • Bazani tanlash: USE dokon_db;.
  • O'chirish: DROP DATABASE IF EXISTS test_db; (Ehtiyot bo'ling, qaytarib bo'lmaydi!).
SQL So'rovi 
-- Yangi baza yaratish va kodirovkasini UTF-8 qilish
CREATE DATABASE IF NOT EXISTS w3learn_db
CHARACTER SET utf8mb4 
COLLATE utf8mb4_unicode_ci;

-- Bazani faollashtirish
USE w3learn_db;

SHOW DATABASES;
🗄️ SQL RDBMS Natijasi:
🔒 DROP DATABASE buyrug'ini ishlab turgan (Production) loyihalarda hech qachon ehtiyotsizlik bilan ishlatmang!

DDL SQL Mavzu #5

CREATE TABLE — Yangi Jadval Yaratish

Jadval (Table) — bu qatorlar (Rows / Records) va ustunlar (Columns / Fields) dan iborat ma'lumotlar konteyneridir. Har bir ustunga uning nomi, ma'lumot turi va cheklovlari (Constraints) beriladi.

  • PRIMARY KEY: har bir qatorning takrorlanmas noyob kaliti (ID).
  • AUTO_INCREMENT (yoki SERIAL): ID raqami har safar avtomatik 1 ga oshadi.
  • NOT NULL: ustun bo'sh qolishi taqiqlanadi.
  • UNIQUE: qiymat takrorlanmasligi kerak (masalan, email).
  • DEFAULT: agar qiymat berilmasa avtomatik qo'yiladigan standart qiymat.
SQL So'rovi 
CREATE TABLE talabalar (
    id INT AUTO_INCREMENT PRIMARY KEY,
    ism VARCHAR(50) NOT NULL,
    familiya VARCHAR(50) NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    yosh INT CHECK (yosh >= 16),
    royxatdan_otgan_vaqt TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    faolmi BOOLEAN DEFAULT TRUE
);
🗄️ SQL RDBMS Natijasi:
💡 Har bir relyatsion jadvalda kamida bitta PRIMARY KEY ustuni bo'lishi relyatsion dizaynning 1-qoidasidir.

Tiplar SQL Mavzu #6

SQL Ma'lumot Turlari (Data Types)

SQL da ma'lumotlar aniq turlar bo'yicha saqlanadi. To'g'ri tip tanlash xotirani tejaydi va so'rovlar tezligini oshiradi.

  • Sonlar: INT, BIGINT, SMALLINT, DECIMAL(10,2) (pul uchun eng aniq), FLOAT.
  • Matnlar: VARCHAR(n) (o'zgaruvchan uzunlikdagi matn), CHAR(n) (qat'iy uzunlik), TEXT (katta matnlar).
  • Sana va Vaqt: DATE ('2026-11-23'), TIME, DATETIME, TIMESTAMP.
  • Mantiqiy: BOOLEAN (TRUE / FALSE).
SQL So'rovi 
-- Turli ma'lumot turlarini sinash
CREATE TABLE tovarlar (
    id INT PRIMARY KEY,
    nomi VARCHAR(100),
    tavsif TEXT,
    narxi DECIMAL(12, 2), -- 9,999,999,999.99 gacha aniq narx
    qoldiq_soni INT,
    ishlab_chiqarilgan_sana DATE
);
🗄️ SQL RDBMS Natijasi:
⚡ Hech qachon narxlar va pul summalarini FLOAT da saqlamang, chunki suzuvchi vergulda yaxlitlash xatolari yuz beradi. Doimo DECIMAL ishlating!

DDL SQL Mavzu #7

ALTER TABLE — Jadval Tuzilishini O'zgartirish

Mavjud jadvalga yangi ustun qo'shish, ustunni o'chirish yoki uning ma'lumot turini o'zgartirish uchun ALTER TABLE buyrug'i qo'llaniladi.

  • Yangi ustun qo'shish: ALTER TABLE jadval ADD telefon VARCHAR(20);.
  • Ustunni o'chirish: ALTER TABLE jadval DROP COLUMN telefon;.
  • Ustun turini o'zgartirish: ALTER TABLE jadval MODIFY COLUMN ism VARCHAR(100);.
SQL So'rovi 
-- Talabalar jadvaliga yangi ustun qo'shish
ALTER TABLE talabalar 
ADD COLUMN telefon VARCHAR(20) AFTER email;

-- Jadval strukturasini ko'rish
DESCRIBE talabalar;
🗄️ SQL RDBMS Natijasi:
💡 AFTER ustun_nomi orqali yangi ustun aynan qaysi ustundan keyin joylashishini belgilash mumkin.

DDL SQL Mavzu #8

DROP TABLE va TRUNCATE TABLE

Jadvalni butunlay yo'q qilish bilan undagi barcha qatorlarni tozalash o'rtasidagi farqni bilish juda muhimdir.

  • DROP TABLE: Jadvalning tuzilishini ham, barcha ma'lumotlarini ham butunlay yo'q qiladi.
  • TRUNCATE TABLE: Jadval qoladi, lekin ichidagi barcha qatorlar bir zumda o'chiriladi va AUTO_INCREMENT hisoblagich 1 ga qaytariladi.
  • TRUNCATE buyrug'i oddiy DELETE ga qaraganda 100 baravar tezroq ishlaydi.
SQL So'rovi 
-- Test jadvalini tozalash
TRUNCATE TABLE test_loglar;

-- Jadvalni butunlay o'chirish
DROP TABLE IF EXISTS eski_arxiv;
🗄️ SQL RDBMS Natijasi:
⚡ TRUNCATE jurnallarga yozmasdan xotirani to'g'ridan-to'g'ri bo'shatgani uchun tranzaksiyada bekor qilish (ROLLBACK) qiyin bo'lishi mumkin.

DML SQL Mavzu #9

INSERT INTO — Ma'lumotlarni Jadvalga Qo'shish

Jadvalga yangi qator (yozuv) qo'shish uchun INSERT INTO operatori ishlatiladi. Bir vaqtning o'zida bitta yoki yuzlab qatorlarni birdaniga kiritish mumkin (Bulk Insert).

  • Sintaksis: INSERT INTO jadval (ustun1, ustun2) VALUES (qiymat1, qiymat2);.
  • Agar barcha ustunlarga tartib bilan qiymat berilsa, ustun nomlarini yozmaslik ham mumkin.
  • Bir necha qatorni bitta so'rovda qo'shish vergul bilan ajratiladi.
SQL So'rovi 
-- Bir nechta talabani bitta so'rovda qo'shish
INSERT INTO talabalar (ism, familiya, email, yosh)
VALUES 
    ('Ali', 'Valiyev', 'ali@gmail.com', 20),
    ('Zuhra', 'Karimova', 'zuhra@mail.ru', 19),
    ('Bekzod', 'Ergashev', 'bekzod@w3learn.uz', 22);
🗄️ SQL RDBMS Natijasi:
💡 Bitta ko'p qatorli INSERT yozish har bir qator uchun alohida INSERT yuborishdan 50 baravar tezroq ishlaydi.

DQL SQL Mavzu #10

SELECT va SELECT DISTINCT — Ma'lumotlarni O'qish

SELECT — SQL tilida eng ko'p ishlatiladigan buyruq bo'lib, jadvallardan kerakli ustunlar va qatorlarni tanlab olish uchun xizmat qiladi.

  • Barcha ustunlarni olish: SELECT * FROM jadval;.
  • Aniq ustunlarni olish: SELECT ism, email FROM talabalar;.
  • Takrorlanmas noyob qiymatlarni olish: SELECT DISTINCT shahar FROM mijozlar;.
  • Hisob-kitoblar va taxalluslar: SELECT narx * 1.15 AS narx_ustama FROM tovarlar;.
SQL So'rovi 
-- Talabalar ro'yxatidan faqat ism va emailni olish
SELECT 
    id, 
    CONCAT(ism, ' ', familiya) AS toliq_ism, 
    email,
    yosh
FROM talabalar;
🗄️ SQL RDBMS Natijasi:
⚡ Produksiyada hech qachon SELECT * ishlatmang, faqat o'zingizga kerakli ustunlarni sanab o'ting. Bu tarmoq va xotira yuklamasini keskin kamaytiradi.

DQL SQL Mavzu #11

WHERE — Filtrlash Shartlari

Jadvaldan faqat ma'lum bir shartga to'g'ri keladigan qatorlarni saralab olish uchun WHERE kalit so'zi ishlatiladi.

  • Taqqoslash: =, != yoki <>, >, <, >=, <=.
  • Mantiqiy operatorlar: AND (ikkala shart ham to'g'ri bo'lishi shart), OR (kamida bittasi to'g'ri bo'lsa yetarli), NOT (inkor).
  • Matnlar doimo bir tirnoq '...' ichiga olinadi.
SQL So'rovi 
-- Yoshi 20 dan katta bo'lgan yoki Toshkentlik talabalarni topish
SELECT ism, familiya, yosh, email
FROM talabalar
WHERE yosh >= 20 AND email LIKE '%@gmail.com';
🗄️ SQL RDBMS Natijasi:
💡 WHERE sharti SELECT dan tashqari UPDATE va DELETE buyruqlarida ham eng asosiy xavfsizlik filtri hisoblanadi.

DML SQL Mavzu #12

UPDATE — Mavjud Ma'lumotlarni Yangilash

Jadvaldagi mavjud qatorlarning qiymatlarini o'zgartirish uchun UPDATE buyrug'i ishlatiladi.

  • Sintaksis: UPDATE jadval SET ustun1 = yangi_qiymat WHERE shart;.
  • Bir nechta ustunni yangilash: vergul bilan ajratiladi.
  • DIQQAT: Agar WHERE sharti yozilmasa, jadvaldagi BARCHA qatorlar o'zgarib ketadi!
SQL So'rovi 
-- Ali Valiyevning yoshini 21 ga oshirish
UPDATE talabalar
SET yosh = 21, telefon = '+998901234567'
WHERE id = 1;

-- Tekshirish:
SELECT id, ism, yosh, telefon FROM talabalar WHERE id = 1;
🗄️ SQL RDBMS Natijasi:
🔒 Har doim UPDATE yozishdan oldin xuddi shu WHERE sharti bilan SELECT qilib qaysi qatorlar o'zgarishini oldindan ko'rib oling!

DML SQL Mavzu #13

DELETE FROM — Ma'lumotlarni O'chirish

Jadvaldan keraksiz qatorlarni o'chirish uchun DELETE FROM ishlatiladi.

  • Sintaksis: DELETE FROM jadval WHERE shart;.
  • Bitta qatorni o'chirish: WHERE id = 5;.
  • Xavfsizlik: WHERE yozilmasa, butun jadval bo'shab qoladi.
SQL So'rovi 
-- Faol bo'lmagan talabalarni o'chirish
DELETE FROM talabalar
WHERE faolmi = FALSE;
🗄️ SQL RDBMS Natijasi:
⚡ Zamonaviy tizimlarda ko'pincha jismoniy o'chirish (Hard Delete) o'rniga, mantiqiy o'chirish (Soft Delete: is_deleted = TRUE) qo'llaniladi.

DQL SQL Mavzu #14

ORDER BY — Natijalarni Saralash (Tartiblash)

Natijalarni alifbo yoki raqamlar bo'yicha o'sish yoki kamayish tartibida chiqarish uchun ORDER BY ishlatiladi.

  • ASC (Ascending) — o'sish tartibida (A dan Z gacha, 1 dan 9 gacha) — sukut bo'yicha.
  • DESC (Descending) — kamayish tartibida (Z dan A gacha, 9 dan 1 gacha).
  • Bir nechta ustun bo'yicha saralash: ORDER BY shahar ASC, yosh DESC;.
SQL So'rovi 
-- Talabalarni yoshi bo'yicha kattasidan kichigiga saralash
SELECT ism, familiya, yosh 
FROM talabalar
ORDER BY yosh DESC;
🗄️ SQL RDBMS Natijasi:
💡 ORDER BY doimo WHERE dan keyin yoziladi.

DQL SQL Mavzu #15

LIMIT va OFFSET — Sahifalash (Pagination)

Jadvalda millionlab qatorlar bo'lganda, ularning barchasini birdaniga yuklab bo'lmaydi. LIMIT qatorlar sonini cheklaydi, OFFSET esa boshidan qanchasini tashlab o'tishni bildiradi.

  • Eng ko'p 5 tasini olish: LIMIT 5;.
  • 2-sahifa (har sahifada 10 tadan): LIMIT 10 OFFSET 10;.
  • Qisqartma sintaksis: LIMIT offset, count; (masalan LIMIT 20, 10).
SQL So'rovi 
-- Eng yoshi katta 2 nafar talaba
SELECT ism, yosh
FROM talabalar
ORDER BY yosh DESC
LIMIT 2 OFFSET 0;
🗄️ SQL RDBMS Natijasi:
⚡ Saytlardagi 'Keyingi sahifaga o'tish' (Pagination) mexanizmi aynan LIMIT va OFFSET asosida ishlaydi.

DQL SQL Mavzu #16

LIKE, IN va BETWEEN Operatorlari

Matnlar ichidan qidirish va oraliqlarni tekshirish uchun maxsus operatorlar ishlatiladi.

  • LIKE '%matn%': qidiruv. % — istalgancha belgi, _ — bitta belgi.
  • IN (qiymat1, qiymat2): bir nechta OR o'rniga qulay ro'yxat tekshiruvi.
  • BETWEEN a AND b: oraliqqa kirishini tekshirish (a va b ham kiradi).
SQL So'rovi 
-- 'Ali' bilan boshlanadigan ismlar
SELECT ism FROM talabalar WHERE ism LIKE 'Ali%';

-- Yoshi 18 dan 21 gacha bo'lganlar
SELECT ism, yosh FROM talabalar WHERE yosh BETWEEN 18 AND 21;

-- Aniq ID lar bo'yicha qidirish
SELECT ism FROM talabalar WHERE id IN (1, 3, 5, 7);
🗄️ SQL RDBMS Natijasi:
💡 Boshida % bo'lgan qidiruvlar (masalan LIKE '%ali') indekslardan foydalana olmaydi va sekinroq ishlaydi.

NULL SQL Mavzu #17

NULL Tekshirish — IS NULL va COALESCE

NULL — bu nol (0) yoki bo'sh matn ('') emas, balki qiymatning umuman mavjud emasligini bildiradi. Uni = NULL deb tekshirib bo'lmaydi!

  • To'g'ri tekshirish: WHERE telefon IS NULL; yoki WHERE telefon IS NOT NULL;.
  • COALESCE(telefon, 'Mavjud emas') — agar qiymat NULL bo'lsa, ikkinchi muqobil qiymatni chiqaradi.
  • IFNULL(ustun, muqobil) funksiyasi MySQL da ishlatiladi.
SQL So'rovi 
-- Telefoni yo'q talabalarni aniqlash va chiroyli chiqarish
SELECT 
    ism, 
    COALESCE(telefon, 'Raqam kiritilmagan') AS aloqa_telefoni
FROM talabalar;
🗄️ SQL RDBMS Natijasi:
⚡ NULL = NULL ifodasi SQL da har doim FALSE (aniqrog'i UNKNOWN) natija beradi, shuning uchun faqat IS NULL ishlatiladi.

Agregat SQL Mavzu #18

Agregat Funksiyalar — COUNT, SUM, AVG, MIN, MAX

Agregat funksiyalar butun bir ustun bo'yicha hisob-kitob qilib, yagona yakuniy qiymat qaytaradi.

  • COUNT(*) — qatorlar umumiy sonini hisoblaydi.
  • SUM(ustun) — barcha sonlarning yig'indisi.
  • AVG(ustun) — o'rtacha arifmetik qiymat.
  • MIN(ustun) va MAX(ustun) — eng kichik va eng katta qiymatlar.
SQL So'rovi 
-- Talabalar statistikasi
SELECT 
    COUNT(*) AS jami_talabalar,
    AVG(yosh) AS ortacha_yosh,
    MIN(yosh) AS eng_yosh,
    MAX(yosh) AS eng_katta
FROM talabalar;
🗄️ SQL RDBMS Natijasi:
💡 COUNT(ustun) hisoblaganda NULL bo'lgan qatorlarni sanamay tashlab ketadi, COUNT(*) esa barcha qatorlarni to'liq sanaydi.

Guruhlash SQL Mavzu #19

GROUP BY — Ma'lumotlarni Guruhlash

Ma'lumotlarni biror ustun bo'yicha guruhlab, har bir guruh uchun alohida agregat hisobotlar chiqarish uchun GROUP BY ishlatiladi.

  • Har bir shahar, har bir toifa yoki har bir oy bo'yicha statistikani ko'rish imkonini beradi.
  • SELECT da yozilgan agregatlanmagan barcha ustunlar albatta GROUP BY ro'yxatida bo'lishi shart.
SQL So'rovi 
-- Har bir yosh bo'yicha talabalar soni
SELECT 
    yosh, 
    COUNT(*) AS talabalar_soni
FROM talabalar
GROUP BY yosh
ORDER BY talabalar_soni DESC;
🗄️ SQL RDBMS Natijasi:
⚡ GROUP BY jadvallardan yillik, oylik tahliliy grafiklar va diagrammalar yasashda eng ko'p ishlatiladigan vositadir.
← Agregat Funksiyalar — COUNT, SUM, AVG, MIN, MAX 📖 SQL | 19 / 29 HAVING — Guruhlangan Natijalarni Filtrlash →
Guruhlash SQL Mavzu #20

HAVING — Guruhlangan Natijalarni Filtrlash

Ko'pchilik dasturchilar WHERE va HAVING ni adashtiradi: WHERE alohida qatorlarni guruhlashdan oldin filtrlaydi, HAVING esa GROUP BY bajarilgandan keyin agregat natijalarni filtrlaydi.

  • WHERE ichida agregat funksiyalarni (COUNT, AVG) ishlatib bo'lmaydi!
  • Agregat natijalarni filtrlash uchun faqat HAVING ishlatiladi: HAVING COUNT(*) > 5.
SQL So'rovi 
-- Talabalar soni 1 tadan ko'p bo'lgan yosh guruhlarini topish
SELECT 
    yosh, 
    COUNT(*) AS soni
FROM talabalar
GROUP BY yosh
HAVING COUNT(*) >= 1;
🗄️ SQL RDBMS Natijasi:
💡 Qoida: oddiy ustun bo'lsa -> WHERE, agregat funksiya (COUNT, SUM) bo'lsa -> HAVING.

JOIN SQL Mavzu #21

INNER JOIN — Jadvallarni Bog'lash (Kesishma)

INNER JOIN — ikkita jadvalni umumiy kalit (ID) orqali birlashtiradi va faqat ikkala jadvalda ham mavjud bo'lgan mos keluvchi qatorlarni qaytaradi.

  • Sintaksis: FROM jadvalA INNER JOIN jadvalB ON jadvalA.id = jadvalB.a_id;.
  • Mos kelmaydigan qatorlar tashlab yuboriladi.
  • Eng ko'p ishlatiladigan standart JOIN turi.
SQL So'rovi 
-- Foydalanuvchilar va ularning buyurtmalari
SELECT 
    f.ism, 
    b.id AS buyurtma_id, 
    b.summa
FROM foydalanuvchilar f
INNER JOIN buyurtmalar b ON f.id = b.user_id;
🗄️ SQL RDBMS Natijasi:
⚡ Agar buyurtmasi yo'q foydalanuvchi bo'lsa, u INNER JOIN natijasida umuman chiqmaydi.

JOIN SQL Mavzu #22

LEFT JOIN — Chap Jadvalni To'liq Saqlash

LEFT JOIN (LEFT OUTER JOIN) — chap tomondagi (FROM dagi) jadvalning BARCHA qatorlarini qaytaradi. O'ng jadvalda mos ma'lumot topilmasa, o'ng tomon ustunlariga NULL qo'yadi.

  • Hech qanday buyurtma bermagan yangi mijozlarni topish uchun ideal.
  • Chap jadvaldagi hech bir qator yo'qolib ketmaydi.
SQL So'rovi 
-- Barcha foydalanuvchilar (hatto buyurtmasi yo'qlari ham)
SELECT 
    f.ism, 
    b.id AS buyurtma_id,
    COALESCE(b.summa, 0) AS summa
FROM foydalanuvchilar f
LEFT JOIN buyurtmalar b ON f.id = b.user_id;
🗄️ SQL RDBMS Natijasi:
💡 'Hech narsa sotib olmagan mijozlar' ni topish: WHERE b.id IS NULL.

JOIN SQL Mavzu #23

RIGHT JOIN — O'ng Jadvalni To'liq Saqlash

RIGHT JOIN — LEFT JOIN ning teskarisi bo'lib, o'ng tomondagi jadvalning barcha qatorlarini to'liq saqlaydi va chap jadvaldan mos keluvchilarni birlashtiradi.

  • Amalda dasturchilar kamroq ishlatadi, chunki har qanday RIGHT JOIN ni jadvallar o'rnini almashtirib LEFT JOIN bilan yozish qulayroq.
  • Sintaksis: FROM jadvalA RIGHT JOIN jadvalB ON ....
SQL So'rovi 
SELECT 
    f.ism, 
    b.mahsulot_nomi
FROM foydalanuvchilar f
RIGHT JOIN buyurtmalar b ON f.id = b.user_id;
🗄️ SQL RDBMS Natijasi:
⚡ Kod tushunarli bo'lishi uchun har doim LEFT JOIN dan foydalanish eng yaxshi amaliyot sanaladi.

JOIN SQL Mavzu #24

FULL OUTER JOIN — Barcha Qatorlar Birlashmasi

FULL OUTER JOIN — chap va o'ng jadvallardagi barcha qatorlarni birlashtiradi. Mos kelmagan tomonlarga NULL qiymatlar joylashtiriladi.

  • PostgreSQL va Oracle da to'g'ridan-to'g'ri FULL OUTER JOIN qo'llab-quvvatlanadi.
  • MySQL da FULL JOIN mavjud emas, uning o'rniga LEFT JOIN va RIGHT JOIN natijalari UNION orqali birlashtiriladi.
SQL So'rovi 
-- PostgreSQL sintaksisi
SELECT 
    f.ism, 
    b.mahsulot
FROM foydalanuvchilar f
FULL OUTER JOIN buyurtmalar b ON f.id = b.user_id;
🗄️ SQL RDBMS Natijasi:
💡 Ikki jadval o'rtasidagi barcha nomuvofiqliklarni (har ikki tomondan) topish uchun FULL OUTER JOIN eng qulaydir.

Murakkab SQL Mavzu #25

Subquery — Ichki So'rovlar (Nested Queries)

Subquery — bu boshqa bir SQL so'rovi (SELECT, INSERT, UPDATE) ichida qavslar (...) ichiga yozilgan ichki so'rovdir.

  • O'rtacha qiymatdan katta bo'lganlarni topish: WHERE narx > (SELECT AVG(narx) FROM tovarlar).
  • IN yoki EXISTS operatorlari bilan birga qo'llaniladi.
  • Correlated Subquery: ichki so'rov tashqi so'rovning har bir qatori uchun alohida bajariladi.
SQL So'rovi 
-- O'rtacha yoshdan katta bo'lgan talabalarni topish
SELECT ism, yosh
FROM talabalar
WHERE yosh > (SELECT AVG(yosh) FROM talabalar);
🗄️ SQL RDBMS Natijasi:
⚡ Agar ichki so'rov juda ko'p qaytarilsa so'rov sekinlashishi mumkin, bunday holatda JOIN ga o'zgartirish tavsiya etiladi.

Unumdorlik SQL Mavzu #26

Indexes (Indekslar) — So'rovlarni 100x Tezlashtirish

Index (Indeks) — bu kitobning oxiridagi mundarija kabi ishlaydigan maxsus ma'lumotlar tuzilmasidir (odatda B-Tree). U ma'lumotlar bazasiga millionlab qatorlar ichidan kerakli ma'lumotni butun jadvalni qidirmasdan (Full Table Scan qilmasdan) bir zumda topish imkonini beradi.

  • Yaratish: CREATE INDEX idx_email ON talabalar(email);.
  • Birlashgan indeks (Composite index): CREATE INDEX idx_ism_fam ON talabalar(ism, familiya);.
  • Indekslar qidirishni (SELECT) keskin tezlashtiradi, lekin ma'lumot yozishni (INSERT/UPDATE) biroz sekinlashtiradi, chunki indeks daraxti qayta quriladi.
SQL So'rovi 
-- Email bo'yicha tezkor qidiruv indeksi yaratish
CREATE INDEX idx_talabalar_email ON talabalar(email);

-- So'rov qanday bajarilishini tekshirish (Execution Plan)
EXPLAIN SELECT * FROM talabalar WHERE email = 'ali@gmail.com';
🗄️ SQL RDBMS Natijasi:
🚀 Millionlab qatorli bazada to'g'ri qo'yilgan indeks so'rov bajarilish vaqtini 10 soniyadan 0.002 soniyagacha qisqartiradi!

Xavfsizlik SQL Mavzu #27

Tranzaksiyalar va ACID Tamoyillari

Tranzaksiya — bu 'hammasi yoki hech narsa' (All or Nothing) qoidasi bo'yicha bajariladigan amallar ketma-ketligidir. Klassik misol: bankda bir hisobdan pul yechilib, ikkinchisiga o'tkazilishi.

  • A (Atomicity): Barcha buyruqlar muvaffaqiyatli bajarilishi shart, bittasi xato bersa hammasi bekor bo'ladi.
  • C (Consistency): Baza qoidalari va balans buzilmasligi kerak.
  • I (Isolation): Bir vaqtning o'zida parallel bajarilayotgan tranzaksiyalar bir-biriga xalaqit bermaydi.
  • D (Durability): Muvaffaqiyatli saqlangan ma'lumot hatto server o'chib qolganda ham yo'qolmaydi.
  • Buyruqlar: START TRANSACTION; -> COMMIT; (tasdiqlash) yoki ROLLBACK; (bekor qilish).
SQL So'rovi 
-- Pul o'tkazish tranzaksiyasi
START TRANSACTION;

-- 1-amal: Alining hisobidan 100,000 so'm yechish
UPDATE hisoblar SET balans = balans - 100000 WHERE id = 1;

-- 2-amal: Valining hisobiga 100,000 so'm qo'shish
UPDATE hisoblar SET balans = balans + 100000 WHERE id = 2;

-- Agar ikkala amal ham muvaffaqiyatli bo'lsa:
COMMIT;

-- Agar biror xato chiqsa:
-- ROLLBACK;
🗄️ SQL RDBMS Natijasi:
🔒 Moliyaviy va to'lov tizimlarida tranzaksiyasiz pul o'tkazmalarini amalga oshirish qat'iyan man etiladi.

Ko'rinish SQL Mavzu #28

CREATE VIEW — Virtual Jadvallar

VIEW — bu saqlab qo'yilgan murakkab SQL so'rovi bo'lib, unga xuddi oddiy jadval kabi murojaat qilish mumkin. U o'zida alohida ma'lumot saqlamaydi, balki har gal so'ralganda asosiy jadvallardan dinamik yig'ib beradi.

  • Murakkab JOIN larni soddalashtiradi va kodni toza saqlaydi.
  • Xavfsizlik: xodimlarga maxfiy ustunlarni (masalan parollarni) ko'rsatmasdan faqat VIEW orqali ruxsat berish mumkin.
  • Yaratish: CREATE VIEW v_faol_talabalar AS SELECT ...;.
SQL So'rovi 
-- Faol talabalar uchun qulay ko'rinish (VIEW)
CREATE VIEW v_faol_talabalar AS
SELECT id, CONCAT(ism, ' ', familiya) AS ism_sharif, email
FROM talabalar
WHERE faolmi = TRUE;

-- Endi unga oddiy jadvaldek so'rov beramiz:
SELECT * FROM v_faol_talabalar;
🗄️ SQL RDBMS Natijasi:
💡 VIEW tufayli dasturchi yuzlab qatorli uzun JOIN larni qayta-qayta yozmasdan qisqa SELECT * FROM v_nomi deb chaqirishi mumkin.

Funksiyalar SQL Mavzu #29

SQL Standart Funksiyalari (Matn, Sana va Matematik)

SQL ma'lumotlarni saralash va formatlash uchun o'rnatilgan boy funksiyalar to'plamiga ega.

  • Matn funksiyalari: UPPER(), LOWER(), CONCAT(), LENGTH(), SUBSTRING(), TRIM().
  • Sana funksiyalari: NOW(), CURDATE(), DATEDIFF(), DATE_ADD(), YEAR().
  • Matematik: ROUND(narx, 2), CEIL(), FLOOR(), ABS(), MOD().
SQL So'rovi 
-- SQL dagi foydali funksiyalar
SELECT 
    UPPER('w3learn') AS katta_harf,
    LENGTH('O\'zbekiston') AS harflar_soni,
    ROUND(125.789, 2) AS yaxlitlangan,
