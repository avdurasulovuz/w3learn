Asosiy Django Mavzu #1

Django Nima? Kirish

Django — Python tilida yozilgan, yuqori darajadagi va bepul ochiq kodli veb-freymvork bo'lib, 'tezkor rivojlanish va toza, pragmatik dizayn' shioriga asoslanadi. U 'batteries-included' falsafasiga ega — ya'ni ma'lumotlar bazasi boshqaruvi, autentifikatsiya, admin-panel va xavfsizlik vositalari ichiga tayyor kiritilgan.

  • MVT (Model-View-Template) arxitekturasiga asoslangan.
  • Xavfsiz: SQL Injection, XSS, CSRF va Clickjacking kabi hujumlardan avtomatik himoyalaydi.
  • Instagram, Pinterest, Spotify, Disqus, Mozilla kabi gigant kompaniyalar Djangodan foydalanadi.
  • ORM (Object-Relational Mapping) orqali SQL yozmasdan ma'lumotlar bazasi bilan ishlash imkonini beradi.
Django / Python 
# Django versiyasini tekshirish va birinchi so'rov
import django

print("Django versiyasi:", django.get_version())
print("Falsafa: Batteries Included & Don't Repeat Yourself (DRY)")

O'rnatish Django Mavzu #2

Django ni O'rnatish va Virtual Environment

Django bilan ishlashda har doim alohida virtual muhit (virtualenv) yaratish tavsiya etiladi. Bu turli loyihalarning kutubxonalari bir-biri bilan to'qnashmasligini ta'minlaydi.

  • Virtual muhit yaratish: python -m venv venv.
  • Muhitni faollashtirish: Windows: venv\Scripts\activate, Linux/Mac: source venv/bin/activate.
  • Django o'rnatish: pip install django.
  • O'rnatilgan paketlarni saqlash: pip freeze > requirements.txt.
Django / Python 
# Terminal buyruqlari
# 1. Virtual muhit yaratish
python -m venv myenv

# 2. Muhitni faollashtirish (Windows)
myenv\Scripts\activate

# 3. Django o'rnatish
pip install django

# 4. Versiyani tekshirish
python -m django --version

Routing Django Mavzu #5

urls.py — Routing va Yo'naltirishlar

Foydalanuvchi brauzerga URL kiritganda, Django uni urls.py faylidagi namunalar bilan solishtiradi va mos keladigan View funksiyasiga uzatadi.

  • path('yo\'l/', view_funksiya, name='nom') sintaksisi ishlatiladi.
  • Parametrlarni qabul qilish: path('post/<int:id>/', views.detail).
  • Loyiha URLs fayliga ilovalarning URLs faylini include() yordamida ulash eng to'g'ri amaliyotdir.
  • Nomlangan URLlar (name='home') shablonlarda havolalarni dinamik generatsiya qilishga yordam beradi.
Django / Python 
# blog/urls.py
from django.urls import path
from . import views

urlpatterns = [
    path('', views.home, name='blog-home'),
    path('post/<int:post_id>/', views.post_detail, name='post-detail'),
    path('about/', views.about, name='blog-about'),
]

Views Django Mavzu #6

views.py — Biznes Mantiq va So'rovlarni Qayta Ishlash

View — bu HTTP so'rovini (HttpRequest) qabul qilib, ma'lumotlarni qayta ishlaydigan va natijada HTTP javobini (HttpResponse yoki JSON) qaytaradigan Python funksiyasi yoki klassi.

  • FBV (Function-Based Views) — sodda funksiyalar, o'rganish oson.
  • CBV (Class-Based Views) — klasslar, kodni qayta ishlatish va vorislik uchun qulay.
  • render(request, 'shablon.html', context) orqali HTML shablonga ma'lumot uzatiladi.
  • API yaratish uchun JsonResponse({'status': 'ok'}) ishlatiladi.
Django / Python 
# blog/views.py
from django.shortcuts import render, get_object_or_404
from django.http import HttpResponse

def home(request):
    maqolalar = [
        {"title": "Django darslari", "author": "Ali"},
        {"title": "Python asoslari", "author": "Vali"}
    ]
    context = {"posts": maqolalar, "page_title": "Bosh Sahifa"}
    return render(request, 'blog/home.html', context)

def post_detail(request, post_id):
    return HttpResponse(f"Siz {post_id}-raqamli maqolani o'qyapsiz.")

Templates Django Mavzu #7

Templates — Django DTL Shablon Tizimi

Django o'zining kuchli Django Template Language (DTL) tizimiga ega. Bu tizim HTML fayllar ichida o'zgaruvchilar, sikllar, shartlar va filtrlar bilan ishlashga imkon beradi.

  • O'zgaruvchilarni chiqarish: {{ o'zgaruvchi_nomi }}.
  • Teglar (sikllar, shartlar): {% for item in items %} ... {% endfor %}.
  • Filtrlar: {{ title|lower }} yoki {{ text|truncatewords:20 }}.
  • Shablon merosi (Template Inheritance): {% extends 'base.html' %} va {% block content %}.
Django / Python 
<!-- templates/blog/home.html -->
{% extends 'base.html' %}

{% block content %}
  <h1>{{ page_title }}</h1>
  
  {% if posts %}
    <ul>
    {% for post in posts %}
      <li>
        <strong>{{ post.title }}</strong> - Muallif: {{ post.author|upper }}
      </li>
    {% endfor %}
    </ul>
  {% else %}
    <p>Hozircha hech qanday maqola mavjud emas.</p>
  {% endif %}
{% endblock %}

Static Fayllar — CSS, JavaScript va Rasmlar

Veb-saytning tashqi ko'rinishi uchun mas'ul CSS fayllar, JS skriptlar va logotip rasmlari Django da static fayllar hisoblanadi. Ular maxsus teglar orqali yuklanadi.

Database Django Mavzu #9

models.py — Ma'lumotlar Bazasi Modeli

Django da har bir ma'lumotlar jadvali models.Model klassidan voris olgan Python klassi sifatida yoziladi. SQL jadvallarini qo'lda yaratish shart emas.

  • Maydon turlari: CharField, TextField, IntegerField, DateTimeField, BooleanField.
  • Aloqalar: ForeignKey (bir-ko'p), ManyToManyField (ko'p-ko'p), OneToOneField (bir-bir).
  • Klass ichida __str__(self) metodi ob'ektning inson tushunadigan nomini qaytaradi.
  • auto_now_add=True ob'ekt yaratilgan vaqtni avtomatik qayd etadi.
Django / Python 
# blog/models.py
from django.db import models
from django.contrib.auth.models import User

class Post(models.Model):
    title = models.CharField(max_length=200, verbose_name="Sarlavha")
    content = models.TextField(verbose_name="Maqola matni")
    created_at = models.DateTimeField(auto_now_add=True)
    author = models.ForeignKey(User, on_delete=models.CASCADE, related_name="posts")
    is_published = models.BooleanField(default=True)

    def __str__(self):
        return self.title

    class Meta:
        ordering = ['-created_at']
        verbose_name = "Maqola"
🖥️ Django Terminal / Server Natijasi:
⚡ on_delete=models.CASCADE muallif o'chirilganda unga tegishli barcha maqolalarni ham avtomatik o'chiradi.

Migratsiya Django Mavzu #10

Migratsiyalar — makemigrations va migrate

Migratsiya — bu models.py dagi o'zgarishlarni (yangi model, maydon qo'shish yoki o'chirish) haqiqiy ma'lumotlar bazasidagi SQL jadvallariga sinxronlash usulidir.

ORM Django Mavzu #11

Django ORM — So'rovlar (QuerySet)

Django ORM (Object-Relational Mapping) yordamida SQL so'rovlarini to'g'ridan-to'g'ri Python metodlari orqali yozasiz. Bu kodni xavfsiz va ixcham qiladi.

  • Barchasini olish: Post.objects.all().
  • Filtrlash: Post.objects.filter(is_published=True).
  • Yagona yozuvni olish: Post.objects.get(id=1).
  • Qidiruv maydonlari: __icontains, __gt, __startswith, __in.
  • Tartiblash va cheklash: Post.objects.order_by('-created_at')[:5].
Django / Python 
# Python interactive shell: python manage.py shell
from blog.models import Post

# Yangi post yaratish
post = Post.objects.create(title="Django ORM ajoyib", content="Matn...", author_id=1)

# Ma'lumotlarni qidirish
oxirgi_postlar = Post.objects.filter(is_published=True).order_by('-id')[:3]

# Qidiruv (icontains - katta-kichik harf farqsiz)
qidiruv = Post.objects.filter(title__icontains="django")

print("Topilganlar soni:", qidiruv.count())
🖥️ Django Terminal / Server Natijasi:
⚡ Django QuerySet-lari 'lazy' (dangasa) hisoblanadi: ular ma'lumotlar bazasiga faqat natija ekranga chiqarilganda yoki sikl ichida aylanganda murojaat qiladi.

Admin Django Mavzu #12

Django Admin Panel — Boshqaruv Tizimi

Django ning eng mashhur xususiyatlaridan biri — bu avtomatik tayyor ma'lumotlar bazasi boshqaruv paneli (Admin Panel). Dasturchi hech qanday HTML yozmasdan ma'lumotlarni qo'shish, tahrirlash va o'chirish imkoniga ega bo'ladi.

  • Superuser (bosh administrator) yaratish: python manage.py createsuperuser.
  • admin.py faylida modellarni ro'yxatdan o'tkazish: admin.site.register(Post).
  • Qulay interfeys: qidiruv satri (search_fields), filtrlar (list_filter) va ustunlar (list_display).
  • Brauzerda kirish: http://127.0.0.1:8000/admin/.
Django / Python 
# blog/admin.py
from django.contrib import admin
from .models import Post

@admin.register(Post)
class PostAdmin(admin.ModelAdmin):
    list_display = ('id', 'title', 'author', 'created_at', 'is_published')
    list_filter = ('is_published', 'created_at', 'author')
    search_fields = ('title', 'content')
    list_editable = ('is_published',)
    date_hierarchy = 'created_at'
🖥️ Django Terminal / Server Natijasi:
💡 list_editable orqali ro'yxat jadvalining o'zidayoq maydonlarni (masalan faollik statusini) bir marta bosish bilan o'zgartirishingiz mumkin.

ModelForm Django Mavzu #15

ModelForm — Model Asosida Tezkor Forma

Agar formangiz ma'lumotlar bazasi modelidagi maydonlarni to'ldirish uchun ishlatilsa, ModelForm eng yaxshi yechimdir. U modeldagi maydonlar asosida formani o'zi yaratadi va form.save() orqali to'g'ridan-to'g'ri bazaga saqlaydi.

  • forms.ModelForm dan voris olinadi.
  • Ichki Meta klassida model = Post va fields = ['title', 'content'] ko'rsatiladi.
  • form.save() metodi yangi ob'ekt yaratadi yoki mavjudini yangilaydi.
Django / Python 
# blog/forms.py
from django import forms
from .models import Post

class PostForm(forms.ModelForm):
    class Meta:
        model = Post
        fields = ['title', 'content', 'is_published']
        widgets = {
            'title': forms.TextInput(attrs={'class': 'form-control', 'placeholder': 'Sarlavhani kiriting'}),
            'content': forms.Textarea(attrs={'class': 'form-control', 'rows': 5}),
        }

⚡ commit=False orqali ma'lumotni bazaga saqlashdan oldin qo'shimcha maydonlarni (masalan joriy muallifni) biriktirish mumkin.

Validatsiya Django Mavzu #16

Validatsiya — Maxsus Qoidalar va Xatolar

Forma maydonlariga kiritilgan ma'lumotlarni maxsus mantiqiy qoidalar bo'yicha tekshirish uchun clean_<maydon_nomi>() yoki umumiy clean() metodlari yoziladi.

  • Noto'g'ri qiymat kiritilganda forms.ValidationError("Xatolik matni") chiqariladi.
  • Tozalangan ma'lumotlar cleaned_data lug'atidan olinadi.
  • Xatolik yuz berganda forma qayta yuklanadi va xato xabari qizil rangda ko'rsatiladi.
Django / Python 
# forms.py
from django import forms

class RegistratsiyaForm(forms.Form):
    username = forms.CharField(max_length=50)
    yosh = forms.IntegerField()

    def clean_yosh(self):
        yosh = self.cleaned_data.get('yosh')
        if yosh < 14:
            raise forms.ValidationError("Ro'yxatdan o'tish uchun yosh kamida 14 bo'lishi kerak!")
        return yosh

💡 Har qanday validatsiya metodining oxirida tekshirilgan qiymatni albatta return qilish shart.

Xavfsizlik Django Mavzu #17

CSRF Himoya — Cross-Site Request Forgery

CSRF (Cross-Site Request Forgery) — bu boshqa zararli sayt foydalanuvchining nomidan sizning saytingizga yashirin so'rov yuborish hujumidir. Django har bir POST formasini maxsus token bilan himoyalaydi.

  • Barcha POST formalari ichiga {% csrf_token %} tegi yozilishi shart.
  • Django har bir sessiya uchun yagona maxfiy token generatsiya qiladi va uni formadagi yashirin maydon bilan solishtiradi.
  • Agar token mos kelmasa yoki kiritilmasa, Django darhol 403 Forbidden xatosini qaytaradi.
Django / Python 
<!-- Har qanday POST formasida csrf_token yozilishi shart: -->
<form method="POST" action="/post/create/">
  {% csrf_token %}
  
  {{ form.as_p }}
  
  <button type="submit" class="btn btn-success">Saqlash</button>
</form>

Auth Django Mavzu #18

Django Authentication — Foydalanuvchilar Tizimi

Django o'zining tayyor django.contrib.auth paketiga ega. U foydalanuvchilar (User), parollarni xesh qilish (PBKDF2 SHA256), guruhlar (Group) va ruxsatlarni (Permission) to'liq boshqaradi.

  • Parollar hech qachon ochiq matn ko'rinishida saqlanmaydi, faqat kuchli kriptografik xesh qilinadi.
  • Foydalanuvchini tekshirish: authenticate(username=..., password=...).
  • Tizimga kiritish (sessiya boshlash): login(request, user).
  • Tizimdan chiqarish: logout(request).
Django / Python 
# Foydalanuvchini tekshirish va tizimga kiritish
from django.contrib.auth import authenticate, login, logout

def user_login_view(request):
    user = authenticate(username='ali', password='MaxfiyParol123!')
    if user is not None:
        login(request, user)
        return "Muvaffaqiyatli tizimga kirdingiz!"
    else:
        return "Login yoki parol noto'g'ri!"

# users/views.py
from django.shortcuts import render, redirect
from django.contrib.auth.forms import UserCreationForm
from django.contrib import messages

def register(request):
    if request.method == 'POST':
        form = UserCreationForm(request.POST)
        if form.is_valid():
            user = form.save()
            messages.success(request, f"{user.username}, hisobingiz muvaffaqiyatli yaratildi! Endi tizimga kirishingiz mumkin.")
            return redirect('login')
    else:
        form = UserCreationForm()
    return render(request, 'users/register.html', {'form': form})

DRF Serializers — Ma'lumotlarni JSON ga O'girish

DRF Django Mavzu #24

DRF ViewSets va Routers — Bir Lahzada To'liq CRUD

ModelViewSet barcha standart CRUD amallarni (list, create, retrieve, update, destroy) bitta klass ichida birlashtiradi. Router esa barcha URL marshrutlarini avtomatik hosil qiladi.

  • Bitta klass barcha 5 ta asosiy HTTP metodini (GET, POST, PUT, PATCH, DELETE) qamrab oladi.
  • routers.DefaultRouter() yordamida barcha URL manzillar avtomatik ulanadi.
  • Kodni 80% ga qisqartiradi.
Django / Python 
# blog/views.py va urls.py
from rest_framework import viewsets, permissions
from .models import Post
from .serializers import PostSerializer
from rest_framework.routers import DefaultRouter
from django.urls import path, include

class PostViewSet(viewsets.ModelViewSet):
    queryset = Post.objects.filter(is_published=True)
    serializer_class = PostSerializer
    permission_classes = [permissions.IsAuthenticatedOrReadOnly]

# Routing:
router = DefaultRouter()
router.register(r'posts', PostViewSet, basename='post')

urlpatterns = [
    path('api/', include(router.urls)),
]

Middleware Django Mavzu #26

Django Middleware — So'rovlar Filtratori

Middleware — bu har bir HTTP so'rovi View ga yetib borishidan oldin va javob brauzerga qaytishidan oldin oraliq tekshiruvlarni bajaruvchi filtr tizimidir.

  • Django xavfsizlik, sessiya, CSRF va autentifikatsiyani aynan Middleware orqali boshqaradi.
  • Maxsus (Custom) middleware orqali har bir so'rovning bajarilish vaqtini o'lchash yoki IP bo'yicha cheklash mumkin.
Django / Python 
# core/middleware.py
import time

class RequestTimerMiddleware:
    def __init__(self, get_response):
        self.get_response = get_response

    def __call__(self, request):
        start_time = time.time()
        
        # View bajariladi:
        response = self.get_response(request)
        
        duration = round((time.time() - start_time) * 1000, 2)
        response['X-Page-Duration-Ms'] = str(duration)
        print(f"[{request.method}] {request.path} bajarildi: {duration}ms")
        
        return response

Signals Django Mavzu #27

Django Signals — Hodisalarni Kuzatish

Signals — bu loyihaning bir qismida biron hodisa yuz berganda (masalan, yangi foydalanuvchi ro'yxatdan o'tganda) boshqa qismini avtomatik xabardor qilish mexanizmidir (Observer pattern).

  • Eng mashhur signallar: post_save (saqlangandan so'ng), pre_delete (o'chirilishdan oldin).
  • Klassik misol: Foydalanuvchi ro'yxatdan o'tishi bilan unga avtomatik ravishda bo'sh Profile yaratish.
  • Signallarni ushlash uchun @receiver dekoratori ishlatiladi.
Django / Python 
# users/signals.py
from django.db.models.signals import post_save
from django.contrib.auth.models import User
from django.dispatch import receiver
from .models import Profile

@receiver(post_save, sender=User)
def create_user_profile(sender, instance, created, **kwargs):
    if created:
        Profile.objects.create(user=instance)
        print(f"Foydalanuvchi {instance.username} uchun avtomatik Profile yaratildi!")

Cache Django Mavzu #29

Django Caching — Saytni Tezlashtirish

Kesh — bu tez-tez so'raladigan ma'lumotlar yoki tayyor HTML sahifalarni tezkor xotirada (RAM) saqlab turish orqali ma'lumotlar bazasiga bo'ladigan yuklamani 95% gacha kamaytirish usulidir.

  • Django kesh mexanizmlari: Redis, Memcached, Database yoki Local Memory.
  • Sahifani to'liq keshlash: @cache_page(60 * 15) (15 daqiqa).
  • Shablon qismlarini keshlash: {% cache 500 sidebar %} ... {% endcache %}.
  • Past darajadagi API: cache.set('key', value, timeout) va cache.get('key').
Django / Python 
# Past darajali Kesh API
from django.core.cache import cache

def get_stats():
    stats = cache.get('sayt_statistikasi')
    if not stats:
        print("Ma'lumotlar bazasidan hisoblanmoqda...")
        stats = {"users_count": 15420, "posts_count": 890}
        cache.set('sayt_statistikasi', stats, timeout=300) # 5 daqiqa
    else:
        print("Keshdan olindi (RAM tezligi ⚡)!")
    return stats
