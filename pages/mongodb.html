MongoDB Nima?

⏱ 8 daqiqa 🟡 O'rta 👁 6,340 marta ko'rilgan

MongoDB — NoSQL ma'lumotlar bazasi bo'lib, ma'lumotlarni JSON-ga o'xshash hujjatlar (BSON) shaklida saqlaydi. Jadval o'rniga kolleksiyalar, qator o'rniga hujjatlar ishlatiladi.

MongoDB moslashuvchan sxema tuzilmasiga ega — har bir hujjat har xil maydonlarga ega bo'lishi mumkin. Bu tez prototyping va o'zgaruvchan ma'lumot tuzilmalari uchun ideal.

💡 Eslatma: MongoDB da "database → collection → document" ierarxiyasi SQL dagi "database → table → row" ga to'g'ri keladi.

CRUD — Ma'lumot qo'shish

MongoDB Shell 
// Ma'lumotlar bazasini tanlash
use w3learn_db

// Bitta hujjat qo'shish
db.foydalanuvchilar.insertOne({
  ism: "Ali Karimov",
  yosh: 25,
  shahar: "Toshkent",
  ko'nikmalar: ["JavaScript", "React", "Node.js"],
  royxatdan_otgan: new Date()
})

// Ko'p hujjat qo'shish
db.foydalanuvchilar.insertMany([
  { ism: "Zulfiya Rahimova", yosh: 22, shahar: "Samarqand" },
  { ism: "Kamol Usmonov", yosh: 30, shahar: "Buxoro" },
  { ism: "Sarvar Toshmatov", yosh: 28, shahar: "Namangan" }
])

CRUD — Ma'lumot olish

MongoDB Shell 
// Barcha hujjatlarni olish
db.foydalanuvchilar.find()

// Shart bilan qidirish
db.foydalanuvchilar.find({ shahar: "Toshkent" })

// Murakkab shartlar
db.foydalanuvchilar.find({
  yosh: { $gte: 25 },      // 25 va undan katta
  shahar: { $in: ["Toshkent", "Samarqand"] }
})

// Bitta hujjat olish
db.foydalanuvchilar.findOne({ ism: "Ali Karimov" })

// Sort, Limit, Skip
db.foydalanuvchilar
  .find()
  .sort({ yosh: -1 })   // yoshga ko'ra kamayish tartibida
  .limit(5)              // faqat 5 ta
  .skip(10)              // 10 tasini o'tkazib yuborish

Mongoose bilan ishlash (Node.js)

JavaScript (Mongoose) 
// npm install mongoose
const mongoose = require('mongoose');

// Ulanish
mongoose.connect('mongodb://localhost:27017/w3learn_db');

// Schema (tuzilma) aniqlash
const FoydalanuvchiSchema = new mongoose.Schema({
  ism: { type: String, required: true, trim: true },
  email: { type: String, required: true, unique: true },
  yosh: { type: Number, min: 0, max: 120 },
  ko_nikmalar: [String],
  yaratildi: { type: Date, default: Date.now }
});

// Model yaratish
const Foydalanuvchi = mongoose.model('Foydalanuvchi', FoydalanuvchiSchema);

// CRUD amallar
async function misollar() {
  // Yaratish
  const yangi = await Foydalanuvchi.create({
    ism: 'Ali', email: 'ali@test.com', yosh: 25
  });

  // O'qish
  const barchasi = await Foydalanuvchi.find({ yosh: { $gte: 20 } });

  // Yangilash
  await Foydalanuvchi.updateOne({ email: 'ali@test.com' }, { yosh: 26 });

  // O'chirish
  await Foydalanuvchi.deleteOne({ email: 'ali@test.com' });
}
