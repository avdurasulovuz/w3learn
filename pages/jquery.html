jQuery Nima?

⏱ 6 daqiqa 🟢 Boshlang'ich 👁 7,340 marta ko'rilgan

jQuery — DOM boshqaruvi, hodisalar va AJAX ni osonlashtiruvchi JavaScript kutubxona. "Write less, do more" — shiorida ishlaydi.

💡 Eslatma: Zamonaviy loyihalarda React/Vue afzalroq, ammo jQuery hali ko'plab saytlarda ishlatiladi.

Asosiy Sintaksis

HTML + jQuery 
<script src="https://code.jquery.com/jquery-3.7.0.min.js"></script>

<p id="matn">Boshlang'ich matn</p>
<button id="btn1">Matnni o'zgartir</button>
<button id="btn2">Yashir/Ko'rsat</button>
<button id="btn3">Rang o'zgartir</button>

<script>
$(document).ready(function() {

  // Matnni o'zgartirish
  $("#btn1").click(function() {
    $("#matn").text("jQuery bilan o'zgardi! ✅");
  });

  // Yashirish / Ko'rsatish
  $("#btn2").click(function() {
    $("#matn").toggle(400);
  });

  // CSS o'zgartirish
  $("#btn3").click(function() {
    $("#matn").css({
      "color": "#04AA6D",
      "font-weight": "bold",
      "font-size": "20px"
    });
  });

});
</script>
📺 Natija:

AJAX bilan ma'lumot olish

jQuery AJAX 
// $.get() — GET so'rov
$.get("https://jsonplaceholder.typicode.com/posts/1", function(data) {
  console.log("Sarlavha:", data.title);
});

// $.ajax() — to'liq nazorat
$.ajax({
  url: "https://api.example.com/foydalanuvchilar",
  method: "POST",
  contentType: "application/json",
  data: JSON.stringify({ ism: "Ali", email: "ali@test.com" }),
  success: function(javob) {
    console.log("Muvaffaqiyat:", javob);
    $("#natija").html("<p>Muvaffaqiyatli yuborildi!</p>");
  },
  error: function(xhr) {
    console.error("Xato:", xhr.status);
  }
});
