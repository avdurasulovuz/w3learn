Git Nima?

⏱ 7 daqiqa 🟢 Boshlang'ich 👁 11,200 marta ko'rilgan

Git — tarqatilgan versiya boshqaruv tizimi (VCS). Dasturchilar jamoasi birgalikda ishlashga, kodni tarixini saqlashga va o'zgarishlarni kuzatishga imkon beradi.

GitHub — Git repozitoriyalarini internet orqali saqlash va ulashish platformasi. Butun dunyo dasturchilari GitHub dan foydalanadi.

💡 Eslatma: Git — vosita (tool), GitHub — platforma (service). Ikkalasi bir narsa emas.

Birinchi Repozitoriy

Terminal (Bash) 
# Git versiyasini tekshirish
git --version

# Foydalanuvchini sozlash (bir martabalik)
git config --global user.name "Ismingiz"
git config --global user.email "email@example.com"

# Yangi repozitoriy yaratish
mkdir mening-loyiham
cd mening-loyiham
git init

# Fayl yaratish va qo'shish
echo "# Mening Loyiham" > README.md
git add README.md
git add .              # barcha fayllarni qo'shish

# Birinchi commit
git commit -m "Birinchi commit — README qo'shildi"

# Holat ko'rish
git status
git log --oneline

Branch bilan ishlash

Terminal (Bash) 
# Barcha branchlarni ko'rish
git branch

# Yangi branch yaratish
git branch yangi-funksiya

# Branch ga o'tish
git checkout yangi-funksiya
# Yoki yangi usul:
git switch yangi-funksiya

# Yaratish + o'tish (bir buyruqda)
git checkout -b boshqa-branch

# O'zgarishlar kiritib commit qilish
# ... fayllarni tahrirlash ...
git add .
git commit -m "Yangi funksiya qo'shildi"

# main ga qaytib merge qilish
git switch main
git merge yangi-funksiya

# Branch ni o'chirish
git branch -d yangi-funksiya

GitHub ga yuklash

Terminal (Bash) 
# GitHub repozitoriyasini ulash
git remote add origin https://github.com/username/repo-nomi.git

# Remote ni tekshirish
git remote -v

# Birinchi push
git push -u origin main

# Keyingi pushlar (qisqacha)
git push

# Remote dan olish (pull = fetch + merge)
git pull origin main

# Repozitoriyani nusxalash (clone)
git clone https://github.com/username/repo-nomi.git

# Oxirgi commit ni bekor qilish (fayllar saqlanadi)
git reset --soft HEAD~1

# Stash — vaqtincha saqlash
git stash
git stash pop
