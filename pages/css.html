Asosiy CSS Mavzu #1

CSS Nima?

CSS (Cascading Style Sheets) — bu veb-sahifalarning tashqi ko'rinishi, dizayni, ranglari va joylashuvini belgilovchi uslublar tilidir. HTML sahifaning skeletini yaratsa, CSS unga chiroyli kiyim kiygizadi.

  • HTML kontent va ma'lumotlar uchun javobgar, CSS esa ularni chiroyli qilib ko'rsatish uchun.
  • Bitta CSS fayli orqali minglab sahifalarning dizaynini bir zumda o'zgartirish mumkin.
  • Turli qurilmalar (telefon, planshet, monitor) uchun alohida moslashuvchan ko'rinish yaratadi.
CSS & HTML Live Preview 
<!DOCTYPE html>
<html>
<head>
<style>
  body { font-family: sans-serif; background: #0f172a; color: #fff; padding: 20px; }
  h1 { color: #04AA6D; border-bottom: 2px solid #04AA6D; padding-bottom: 8px; }
  p { font-size: 15px; color: #94a3b8; }
</style>
</head>
<body>
  <h1>Salom, CSS!</h1>
  <p>CSS yordamida sahifamiz zamonaviy ko'rinishga ega bo'ldi.</p>
</body>
</html>
📺 Jonli Natija:
💡 'Cascading' (kaskadli) so'zi stillarning iyerarxiya bo'yicha yuqoridan pastga qarab meros bo'lib o'tishini bildiradi.

Qoidalar CSS Mavzu #2

CSS Sintaksisi

CSS qoidasi ikkita asosiy qismdan iborat: Selektor (Selector) va E'lon bloki (Declaration block).

  • Selektor: qaysi HTML elementiga stil berilishini ko'rsatadi (masalan: h1, .card).
  • Xususiyat (Property): nimani o'zgartirmoqchisiz (masalan: color, font-size).
  • Qiymat (Value): qanday qiymat bermoqchisiz (masalan: red, 24px).
  • Har bir e'lon nuqtali vergul (;) bilan tugashi shart!
CSS & HTML Live Preview 
<style>
  /* Selektor { xususiyat: qiymat; } */
  .demo-text {
    color: #38bdf8;
    font-size: 18px;
    font-weight: bold;
    text-align: center;
  }
</style>
<p class="demo-text">CSS Sintaksisi juda sodda va o'qishga oson!</p>
📺 Jonli Natija:
⚠️ Nuqtali vergulni tushirib qoldirish CSSdagi eng ko'p uchraydigan xatodir. Har bir satr oxiriga ; qo'yishni unutmang.

Integratsiya CSS Mavzu #3

CSS ni HTML ga Ulash Usullari

CSS stillarini HTML hujjatiga qo'llashning uchta xil usuli mavjud: Tashqi, Ichki va Qator ichi.

  • External CSS (Tashqi): <link rel="stylesheet" href="style.css?v=20261123_4"> — eng to'g'ri va professional usul.
  • Internal CSS (Ichki): <head> ichida <style> tegi yordamida yoziladi.
  • Inline CSS (Qator ichi): Element ichida style="color:red;" tarzida yoziladi (kamroq ishlatish tavsiya etiladi).
CSS & HTML Live Preview 
<!-- Ichki va Qator ichi CSS namunasi -->
<style>
  .box-internal { background: #1e293b; padding: 12px; border-radius: 6px; }
</style>

<div class="box-internal">
  <span style="color: #04AA6D; font-weight: bold;">Inline yashil matn</span>
  va ichki stilli konteyner.
</div>
📺 Jonli Natija:
🚀 Tashqi CSS fayllari brauzer xotirasiga (cache) saqlanib qoladi va sayt keyingi safar ancha tez yuklanadi.

Selektorlar CSS Mavzu #4

CSS Selektorlar Umumiy Sharhi

Selektorlar orqali siz sahifadagi kerakli elementlarni nishonga olasiz. Ular oddiy, kombinatsiyalangan va atribut selektorlariga bo'linadi.

  • Oddiy selektorlar: nom (tag), sinf (class) va id bo'yicha.
  • Kombinatorlar: avlod selektori (probel), to'g'ridan-to'g'ri bola (>), yonma-yon qo'shni (+).
  • Atribut selektori: input[type="text"] orqali ma'lum atributga ega elementlar tanlanadi.
CSS & HTML Live Preview 
<style>
  div > p { color: #f59e0b; } /* Faqat to'g'ridan-to'g'ri bola p */
  input[type="submit"] { background: #04AA6D; color: white; border: none; padding: 6px 14px; border-radius: 4px; cursor: pointer; }
</style>
<div>
  <p>To'g'ridan-to'g'ri bola paragraf (sariq rangda).</p>
</div>
<input type="submit" value="Atribut Selektorli Tugma">
📺 Jonli Natija:
💡 Selektor qanchalik aniq bo'lsa, brauzer uni shunchalik tez topadi va stillarni qo'llaydi.

Selektorlar CSS Mavzu #5

Element Selektori (Teg bo'yicha)

Element selektori ko'rsatilgan teg nomiga ega bo'lgan barcha HTML elementlarini tanlaydi.

  • Masalan, p { color: white; } sahifadagi BARCHA paragraflarga ta'sir qiladi.
  • Global qoidalar, asosiy shrift yoki sarlavhalar rangini bir xil qilish uchun juda qulay.
  • Spetsifikligi (kuchi) eng past bo'lgan selektor turi hisoblanadi.
CSS & HTML Live Preview 
<style>
  h3 { color: #38bdf8; margin: 0; }
  em { color: #04AA6D; font-style: normal; font-weight: bold; }
</style>
<h3>Bu h3 tegi</h3>
<p>Element selektori orqali <em>ushbu em so'z</em> yashil rangga kirdi.</p>
📺 Jonli Natija:
📌 Barcha teglarga birdaniga ta'sir o'tkazgani uchun ehtiyotkorlik bilan ishlatilishi kerak.

Selektorlar CSS Mavzu #6

Class Selektori (.sinf)

Class selektori muayyan class atributiga ega bo'lgan barcha elementlarni tanlaydi. CSS da nomidan oldin nuqta (.) qo'yiladi.

  • Eng ko'p qo'llaniladigan va qayta ishlatish (reusable) uchun ideal bo'lgan selektor.
  • Bitta sahifada ko'p marotaba qo'llanishi mumkin.
  • Elementga bir nechta sinf berish mumkin: class="btn primary large".
CSS & HTML Live Preview 
<style>
  .btn { padding: 8px 16px; border: none; border-radius: 6px; font-weight: bold; cursor: pointer; }
  .btn-green { background: #04AA6D; color: white; }
  .btn-outline { background: transparent; border: 1px solid #04AA6D; color: #04AA6D; }
</style>
<button class="btn btn-green">Asosiy Tugma</button>
<button class="btn btn-outline">Chegarali Tugma</button>
📺 Jonli Natija:
⚡ Professional frontend arxitekturasida (masalan, BEM usulida) barcha stillar class selektorlari asosida yoziladi.

Selektorlar CSS Mavzu #7

ID Selektori (#identifikator)

ID selektori berilgan id ga ega bo'lgan faqat bitta elementni tanlaydi. CSS da panjara (#) belgisi bilan boshlanadi.

  • ID sahifada yagona bo'lishi shart.
  • Spetsifikligi (ustunligi) class selektoridan ancha yuqori.
  • Odatda saytning asosiy navigatsiyasi, qidiruv paneli yoki yagona forma bloklari uchun ishlatiladi.
CSS & HTML Live Preview 
<style>
  #asosiy-header {
    background: linear-gradient(90deg, #1e293b, #0f172a);
    padding: 15px;
    border-left: 4px solid #04AA6D;
    color: white;
  }
</style>
<div id="asosiy-header">
  Bu blok unikal #asosiy-header orqali bezatildi.
</div>
📺 Jonli Natija:
⚠️ ID selektorini haddan tashqari ko'p ishlatmang, chunki uning kuchini oddiy classlar bilan yengish (override qilish) qiyin.

Selektorlar CSS Mavzu #8

Guruh Selektori (Grouping)

Agar bir nechta elementlar bir xil stillarga ega bo'lsa, ularni vergul bilan ajratib bitta qoidaga guruhlash mumkin.

  • Kodni qisqartiradi va takrorlanishni (DRY — Don't Repeat Yourself) oldini oladi.
  • Masalan: h1, h2, h3 { font-family: 'Poppins', sans-serif; }.
CSS & HTML Live Preview 
<style>
  h4, h5, .maxsus-matn {
    color: #e2e8f0;
    text-transform: uppercase;
    letter-spacing: 1px;
    margin: 4px 0;
  }
</style>
<h4>Sarlavha 4</h4>
<h5>Sarlavha 5</h5>
<p class="maxsus-matn">Maxsus matn (barchasi bitta qoidada guruhlangan)</p>
📺 Jonli Natija:
💡 Kodni optimallashtirish va fayl hajmini kamaytirish uchun guruhlash juda qo'l keladi.

Selektorlar CSS Mavzu #9

Universal Selektor (*)

Universal selektor (yulduzcha *) HTML sahifasidagi MUTLAQO BARCHA elementlarni tanlaydi.

  • Brauzerning standart noqulay padding va marginlarini tozalash (CSS Reset) uchun qo'llaniladi.
  • * { box-sizing: border-box; } — har bir zamonaviy loyihaning boshida yozilishi shart bo'lgan oltin qoidadir.
CSS & HTML Live Preview 
<style>
  * {
    box-sizing: border-box;
  }
</style>
<p style="color:#94a3b8; font-size:14px;">
  Universal selektor sahifadagi hamma elementlarni birdek qamrab oladi.
</p>

Holatlar CSS Mavzu #10

Pseudo-sinflar (:hover, :focus, :active)

Pseudo-sinflar elementning maxsus holatini (masalan, sichqoncha ustiga borganda, bosilganda yoki forma faollashganda) stil berish uchun ishlatiladi.

  • :hover — foydalanuvchi sichqoncha kursorni element ustiga olib borganda.
  • :active — sichqoncha tugmasi bosib turilgan vaqtda.
  • :focus — input kiritish maydoni faollashganda.
  • :nth-child(n) — ketma-ket elementlarning juft/toq (even/odd) tartibdagilarini tanlash.
CSS & HTML Live Preview 
<style>
  .anim-btn {
    background: #1e293b;
    color: #38bdf8;
    border: 1px solid #38bdf8;
    padding: 8px 16px;
    border-radius: 6px;
    cursor: pointer;
    transition: 0.3s;
  }
  .anim-btn:hover {
    background: #38bdf8;
    color: #0f172a;
    transform: translateY(-2px);
  }
  .anim-btn:active {
    transform: translateY(1px);
  }
</style>
<button class="anim-btn">Ustiga sichqonchani olib keling (:hover)</button>
📺 Jonli Natija:
✨ :hover effekti veb-saytni jonli va interaktiv ko'rsatishning eng oddiy usulidir.

Dekoratsiya CSS Mavzu #11

Pseudo-elementlar (::before, ::after)

Pseudo-elementlar HTML ga ortiqcha teg qo'shmasdan, elementning ma'lum bir qismiga yoki uning oldi/orqasiga yangi kontent kiritish imkonini beradi.

  • ::before — element kontentidan oldin narsa qo'shadi.
  • ::after — element kontentidan keyin narsa qo'shadi.
  • content: "" — ushbu xususiyatsiz before va after ishlamaydi!
  • ::selection — foydalanuvchi matnni sichqoncha bilan belgilab olgandagi foni va rangini o'zgartiradi.
CSS & HTML Live Preview 
<style>
  .quote::before {
    content: "« ";
    color: #04AA6D;
    font-size: 20px;
    font-weight: bold;
  }
  .quote::after {
    content: " »";
    color: #04AA6D;
    font-size: 20px;
    font-weight: bold;
  }
</style>
<p class="quote" style="color:#cbd5e1; font-style:italic;">Dasturlash — bu kelajak tili</p>
📺 Jonli Natija:
🎨 Dizaynerlar ikonkalar, dekorativ chiziqlar va yorug'lik effektlarini yasashda ::before va ::after dan juda ko'p foydalanadilar.

Ranglar CSS Mavzu #12

CSS Ranglar va Rang Tizimlari

CSS da ranglar bir necha xil formatda ifodalanadi: HEX, RGB, RGBA, HSL va Zamonaviy OKLCH.

  • HEX: #04AA6D — 6 ta belgili o'n oltilik tizim.
  • RGB / RGBA: rgba(4, 170, 109, 0.8) — 80% shaffoflikdagi yashil rang.
  • HSL: Hue (tus), Saturation (to'yinganlik), Lightness (yorug'lik).
CSS & HTML Live Preview 
<div style="display:flex; gap:10px; flex-wrap:wrap; color:white; font-size:12px; font-weight:bold;">
  <div style="background:#04AA6D; padding:12px; border-radius:6px;">HEX: #04AA6D</div>
  <div style="background:rgb(59, 130, 246); padding:12px; border-radius:6px;">RGB(59,130,246)</div>
  <div style="background:rgba(239, 68, 68, 0.7); padding:12px; border-radius:6px;">RGBA Shaffof Qizil</div>
  <div style="background:hsl(280, 80%, 50%); padding:12px; border-radius:6px;">HSL Binafsha</div>
</div>
📺 Jonli Natija:
💡 Glassmorphism (shaffof shisha effekti) yaratish uchun har doim RGBA ranglardan foydalaniladi.

Dizayn CSS Mavzu #13

CSS Fon (Background)

Elementning orqa foniga bir xil rang, rasm yoki gradient berish uchun background xususiyatlar to'plami ishlatiladi.

  • background-color: fon rangi.
  • background-image: url('rasm.jpg') — fon uchun tasvir.
  • background-size: cover; — rasmni butun blok bo'yicha proporsional cho'zish.
  • background-position: center; — rasmni markazga tekislash.
  • Gradients: linear-gradient(yo'nalish, rang1, rang2) — silliq rang o'tishi.
CSS & HTML Live Preview 
<div style="background: linear-gradient(135deg, #04AA6D 0%, #0284c7 100%); padding: 20px; border-radius: 8px; color: white; text-align: center;">
  <h3 style="margin:0 0 6px 0;">Zamonaviy Chiziqli Gradient</h3>
  <p style="margin:0; font-size:14px; opacity:0.9;">linear-gradient(135deg, #04AA6D, #0284c7)</p>
</div>
📺 Jonli Natija:
✨ Gradientlar oddiy tekis rangdan ko'ra 10 barobar jozibadorroq va zamonaviyroq ko'rinadi.

Dizayn CSS Mavzu #14

CSS Chegara (Border va Border-Radius)

Element atrofidagi chegara chiziqlari va uning burchaklarini yumaloqlash qoidalari.

  • border: qalinlik tur rang; (masalan: border: 2px solid #04AA6D;).
  • Turlari: solid (tekis), dashed (chiziqchali), dotted (nuqtali).
  • border-radius: 12px; — burchaklarni zamonaviy qilib yumaloqlaydi.
  • border-radius: 50%; — kvadrat shaklni mukammal doiraga aylantiradi.
CSS & HTML Live Preview 
<div style="display:flex; gap:12px; align-items:center;">
  <div style="border: 2px dashed #38bdf8; padding: 10px; border-radius: 8px; color:#cbd5e1;">Dashed chegara</div>
  <div style="width: 50px; height: 50px; background: #04AA6D; border-radius: 50%; display:flex; align-items:center; justify-content:center; color:white; font-weight:bold;">50%</div>
</div>
📺 Jonli Natija:
📌 Tugma va kartalarning burchaklarini 8px-12px gacha yumaloqlash interfeysni yumshoq va do'stona qiladi.

Matn CSS Mavzu #15

CSS Matn Stillari (Typography)

Matnlarning o'qilishi oson bo'lishi va chiroyli joylashishi uchun maxsus matn xususiyatlari qo'llaniladi.

  • text-align: center | left | right | justify; — matnni tekislash.
  • text-decoration: none | underline | line-through; — tagiga chizish yoki olib tashlash (havolalar uchun).
  • line-height: 1.6; — qatorlar orasidagi masofa (ideal o'qish uchun 1.5 - 1.7 tavsiya etiladi).
  • letter-spacing: 1px; — harflar orasidagi masofa.
  • text-transform: uppercase | lowercase | capitalize; — harflar registrini o'zgartirish.
CSS & HTML Live Preview 
<p style="line-height: 1.8; letter-spacing: 0.5px; color: #cbd5e1; text-align: justify;">
  To'g'ri sozlangan <strong>line-height</strong> va <strong>letter-spacing</strong> sahifadagi uzun matnlarning o'qilishini osonlashtiradi va foydalanuvchi ko'zini toliqtirmaydi.
</p>
📺 Jonli Natija:
💡 Havolalarning (link) tagidagi zerikarli chiziqni yo'qotish uchun text-decoration: none; yoziladi.

Matn CSS Mavzu #16

CSS Shriftlar (Fonts)

Saytning shaxsiyati uning shriftiga bog'liq. CSS da shriftlar oilasi, hajmi va qalinligi boshqariladi.

  • font-family: shrift turi (masalan: 'Inter', Arial, sans-serif).
  • font-size: shrift hajmi (px, rem, em).
  • font-weight: shrift qalinligi (100 dan 900 gacha, masalan: 400 normal, 700 bold).
  • Google Fonts: minglab bepul va sifatli shriftlarni ulash imkoniyati.
CSS & HTML Live Preview 
<p style="font-family: 'Courier New', monospace; font-size: 15px; color: #04AA6D;">
  Courier New — dasturchilar uchun monospace (monokenglikdagi) shrift.
</p>
<p style="font-family: 'Segoe UI', Tahoma, sans-serif; font-size: 16px; font-weight: 300; color: #e2e8f0;">
  Segoe UI — nafis va yengil sans-serif shrifti.
</p>
📺 Jonli Natija:
⚡ Doimo o'lchov birligi sifatida rem dan foydalaning (masalan, 1rem = 16px), bu saytni har qanday ekranga moslashtiradi.

Interaktiv CSS Mavzu #17

CSS Havola Stillari

Havolalar (<a>) 4 xil holatga ega bo'lib, har bir holat uchun alohida dizayn berish mumkin.

  • a:link — hali ochilmagan oddiy havola.
  • a:visited — foydalanuvchi avval bosib ko'rgan havola.
  • a:hover — sichqoncha ustiga borgandagi ko'rinish.
  • a:active — aynan bosilgan lahzadagi ko'rinish.
CSS & HTML Live Preview 
<style>
  .custom-link {
    color: #38bdf8;
    text-decoration: none;
    font-weight: bold;
    border-bottom: 2px solid transparent;
    transition: 0.3s;
  }
  .custom-link:hover {
    color: #04AA6D;
    border-bottom-color: #04AA6D;
  }
</style>
<p><a href="#" class="custom-link">Sichqonchani havola ustiga olib keling ↗</a></p>
📺 Jonli Natija:
📌 Pseudo-sinflar tartibi qat'iy bo'lishi shart: Link, Visited, Hover, Active (eslab qolish uchun: LVHA qoidasi).

Struktura CSS Mavzu #18

CSS Ro'yxat Stillari

Ro'yxat markerlari (nuqtalar, raqamlar) ni o'zgartirish yoki butunlay olib tashlash.

  • list-style-type: none; — nuqta va raqamlarni olib tashlaydi (menyu yasashda eng birinchi qadam).
  • list-style-type: square | circle | upper-roman; — belgi shaklini o'zgartirish.
  • list-style-image: url('marker.png'); — o'z rasmingizni marker sifatida ishlatish.
CSS & HTML Live Preview 
<style>
  .clean-menu {
    list-style: none;
    padding: 0;
    margin: 0;
    display: flex;
    gap: 15px;
  }
  .clean-menu li a {
    color: #04AA6D;
    text-decoration: none;
    font-weight: bold;
  }
</style>
<ul class="clean-menu">
  <li><a href="#">Bosh sahifa</a></li>
  <li><a href="#">Darslar</a></li>
  <li><a href="#">Aloqa</a></li>
</ul>
📺 Jonli Natija:
💡 Gorizontal navigatsiya menyusini yasash uchun ro'yxatga list-style: none; display: flex; berishning o'zi kifoya.

Struktura CSS Mavzu #19

CSS Jadval Stillari

Jadvallarni zamonaviy, chiroyli va o'qishga qulay ko'rinishga keltirish.

  • border-collapse: collapse; — qo'shaloq qalin chegaralarni bitta ingichka chiziqqa aylantiradi.
  • tr:nth-child(even) — zebra effekti (qatorlarni navbatma-navbat och va to'q fonga bo'yash).
  • tr:hover — sichqoncha ustiga kelgan qatorni ajratib ko'rsatish.
CSS & HTML Live Preview

CSS Display Xususiyati

Element sahifada o'zini qanday tutishi va boshqa elementlar bilan qanday joylashishini belgilovchi eng muhim xususiyat.

CSS Position (Joylashuv)

Elementni sahifaning istalgan nuqtasiga aniq joylashtirish mexanizmi.

CSS Flexbox (Moslashuvchan Quti)

Mobil CSS Mavzu #32

Media Queries (@media)

Media Queries — ekranning o'lchami (kengligi) ga qarab ma'lum bir CSS qoidalarini ishga tushirish mexanizmi.

  • Sintaksis: @media (max-width: 768px) { ... } — ekran 768px dan kichik bo'lganda ishlaydi.
  • Breakpoints (Chegaralar): mobil (480px), planshet (768px), noutbuk (1024px), desktop (1200px).
  • Katta ekranda 3 ta ustun bo'lgan kartalarni telefonda 1 ta ustunga aylantirish uchun xizmat qiladi.
CSS & HTML Live Preview 
<style>
  .responsive-box {
    background: #04AA6D;
    color: white;
    padding: 15px;
    border-radius: 6px;
    text-align: center;
  }
  @media (max-width: 600px) {
    .responsive-box {
      background: #ef4444; /* Kichik ekranda qizil bo'ladi */
    }
  }
</style>
<div class="responsive-box">
  Katta ekranda yashil, ekran torayganda qizilga aylanadi!
</div>
