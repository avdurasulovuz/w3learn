Vue.js Nima?

⏱ 8 daqiqa 🟡 O'rta 👁 5,890 marta ko'rilgan

Vue.js — Evan You tomonidan yaratilgan progressiv JavaScript framework. Vue React dan oddiyroq va o'rganish uchun qulay bo'lib, kichik loyihalardan tortib yirik dasturlargacha ishlatiladi.

Vue 3 Composition API va Options API ikkalasini ham qo'llab-quvvatlaydi. Zamonaviy loyihalarda Composition API tavsiya etiladi.

v-model — Ikki tomonlama bog'lash

Vue 3 (SFC) 
<template>
  <div>
    <h2>Salom, {{ ism }}!</h2>
    <input v-model="ism" placeholder="Ismingizni kiriting" />

    <!-- v-if / v-else -->
    <p v-if="ism.length > 0">Sizning ismingiz: {{ ism }}</p>
    <p v-else>Iltimos, ismingizni kiriting.</p>
  </div>
</template>

<script setup>
import { ref } from 'vue'

const ism = ref('')
</script>

v-for — Ro'yxat chiqarish

Vue 3 (SFC) 
<template>
  <div>
    <h3>Vazifalar ro'yxati ({{ bajarilmagan }} ta qoldi)</h3>
    <input v-model="yangiVazifa" @keyup.enter="qoshish" placeholder="Yangi vazifa..." />
    <button @click="qoshish">Qo'shish</button>

    <ul>
      <li v-for="(vazifa, i) in vazifalar" :key="i">
        <input type="checkbox" v-model="vazifa.bajarildi" />
        <span :style="{ textDecoration: vazifa.bajarildi ? 'line-through' : 'none' }">
          {{ vazifa.matn }}
        </span>
      </li>
    </ul>
  </div>
</template>

<script setup>
import { ref, computed } from 'vue'

const vazifalar = ref([
  { matn: 'HTML o\'rganish', bajarildi: true },
  { matn: 'CSS o\'rganish', bajarildi: true },
  { matn: 'Vue.js o\'rganish', bajarildi: false },
])
const yangiVazifa = ref('')

const bajarilmagan = computed(() =>
  vazifalar.value.filter(v => !v.bajarildi).length
)

function qoshish() {
  if (yangiVazifa.value.trim()) {
    vazifalar.value.push({ matn: yangiVazifa.value, bajarildi: false })
    yangiVazifa.value = ''
  }
}
</script>
