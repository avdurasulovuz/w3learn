# W3Learn — O'zbekcha Dasturlash Platformasi 🇺🇿

W3Learn — W3Schools andozasidagi mukammal, interaktiv va ko'p tilli (O'zbek, Rus, Ingliz) dasturlash o'quv platformasi.

## 🚀 Texnologiyalar va Kurslar (23+)

### 🎨 Frontend
- **HTML5** — Veb sahifalar asosi va semantikasi
- **CSS3** — Flexbox, Grid, zamonaviy dizayn va animatsiyalar
- **JavaScript (ES6+)** — DOM, asinxron dasturlash va eventlar
- **React.js** — Zamonaviy komponentli arxitektura va hooklar
- **Vue.js** — Reaktivlik va Composition API
- **Bootstrap** — Tezkor moslashuvchan (responsive) interfeys
- **TypeScript** — Statik tiplar va interfeyslar
- **jQuery** — DOM manipulyatsiyasi va animatsiya

### ⚙️ Backend
- **Python** — Asoslar, OOP va zamonaviy kutubxonalar
- **Node.js & Express** — Server arxitekturasi va REST API
- **PHP** — Dinamik veb tizimlar va backend
- **Java** — Obyektga yo'naltirilgan dasturlash va Spring
- **Django** — Katta hajmli veb ilovalar karkasi
- **C++** — Tizimli dasturlash va samaradorlik
- **C#** — .NET platformasi va dasturlash

### 🗄️ Ma'lumotlar Bazasi
- **SQL** — Relyatsion ma'lumotlar bazasi va so'rovlar
- **PostgreSQL** — Kengaytirilgan SQL va murakkab indekslar
- **MongoDB** — Hujjatsimon NoSQL ma'lumotlar bazasi
- **Redis** — Tezkor xotira (In-memory) va keshlash

### 🚀 DevOps & Vositalar
- **Git & GitHub** — Versiyalar boshqaruvi va jamoaviy ishlash
- **Docker** — Konteynerlashtirish va mikroservislar
- **Linux** — Terminal, buyruqlar va server boshqaruvi
- **REST API** — Klient-server arxitekturasi va JWT autentifikatsiya

## ✨ Asosiy Imkoniyatlar
1. ⌨️ **Live Kod Muharriri (Playground):** Brauzerda real-vaqtli HTML/CSS/JS muharriri va konsoli.
2. 🏆 **Sertifikat Generatori:** Kursni tugatgan o'quvchilar uchun rasmiy sertifikat va PDF/chop etish.
3. 🔐 **Admin Panel:** Kurslar, darslar va statistikani boshqarish paneli.
4. 🧠 **Interaktiv Quiz:** Har bir dars oxirida bilimni mustahkamlash uchun testlar.
5. 🌙 **Dark/Light Mode:** Ko'zga qulay dizayn va ranglar.
6. 📊 **Progress Tracker:** O'tilgan darslar hisoboti (localStorage).
