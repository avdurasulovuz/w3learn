Asosiy jQuery Mavzu #1

jQuery Nima?

jQuery — dunyodagi eng mashhur va qulay JavaScript kutubxonasi. U 'Write less, do more' (Kamroq yoz, ko'proq ish qil) shiori ostida 2006-yilda John Resig tomonidan yaratilgan. U HTML DOM bilan ishlash, hodisalarni boshqarish, CSS animatsiyalar va AJAX so'rovlarini ancha soddalashtiradi.

  • DOM elementlarini CSS selektorlariga o'xshash qilib tanlash ($('p'), $('#id')).
  • Barcha brauzerlar (Chrome, Firefox, Safari, Edge) o'rtasidagi nomutanosibliklarni hal qiladi.
  • Animatsiyalar (fadeIn, slideDown, animate) bir qator kod bilan ishga tushadi.
  • Katta hajmdagi JavaScript kodlarini 2-3 barobar qisqartiradi.
HTML + jQuery Jonli Kod 
<!DOCTYPE html>
<html>
<head>
  <script src="https://code.jquery.com/jquery-3.7.0.min.js"></script>
</head>
<body style="font-family:sans-serif; padding:15px; background:#0f172a; color:#f8fafc;">
  <h2>jQuery Boshlang'ich Darsi</h2>
  <p id="testMatn">Ushbu matn jQuery yordamida o'zgaradi.</p>
  <button id="ozgartirBtn" style="background:#0769ad; color:white; border:none; padding:8px 16px; border-radius:6px; cursor:pointer;">
    Matnni o'zgartirish
  </button>
  <script>
    $(document).ready(function(){
      $("#ozgartirBtn").click(function(){
        $("#testMatn").text("🎉 Tabriklaymiz! Siz jQuery ni muvaffaqiyatli ishlatdingiz.").css("color", "#00d4a0");
      });
    });
  </script>
</body>
</html>
📺 Jonli Natija:
💡 jQuery sintaksisining asosi: $(selektor).harakat() ko'rinishida yoziladi.

O'rnatish jQuery Mavzu #2

jQuery ni O'rnatish va Ulash

jQuery ni veb-sahifaga ulashning 2 ta asosiy usuli bor: CDN (Content Delivery Network — masalan, Google, Cloudflare yoki rasmiy jQuery CDN) orqali yoki faylini yuklab olib papkaga joylash.

  • Eng qulay usul — rasmiy CDN: <script src="https://code.jquery.com/jquery-3.7.0.min.js"></script>
  • Google CDN orqali: ajax.googleapis.com/ajax/libs/jquery/...
  • Faylni yuklab olib mahalliy ulash: <script src="js/jquery.min.js"></script>
  • jQuery ni doimo o'z kodingiz yozilgan skriptlardan OLDIN ulash shart.
HTML + jQuery Jonli Kod 
<!DOCTYPE html>
<html>
<head>
  <!-- Rasmiy jQuery CDN orqali ulash -->
  <script src="https://code.jquery.com/jquery-3.7.0.min.js"></script>
</head>
<body style="font-family:sans-serif; padding:15px; background:#0f172a; color:#f8fafc;">
  <h3>jQuery Versiyasini Tekshirish</h3>
  <p id="verLabel">Yuklanmoqda...</p>
  <script>
    $(function(){
      $("#verLabel").html("✅ jQuery muvaffaqiyatli ulandi! Versiya: <strong>" + $.fn.jquery + "</strong>");
    });
  </script>
</body>
</html>
📺 Jonli Natija:
⚡ $(function(){ ... }) yozuvi $(document).ready(function(){ ... }) ning qisqa ko'rinishidir.

Asoslar jQuery Mavzu #3

Asosiy Sintaksis va $(document).ready()

jQuery sintaksisi maxsus HTML elementlarini tanlash va ular ustida qandaydir amal bajarish uchun ishlab chiqilgan. $(document).ready() hodisasi sahifaning barcha HTML teglari to'liq yuklangandan keyin kod ishga tushishini ta'minlaydi.

  • Asosiy formula: $(selector).action()
  • $ belgisi jQuery kutubxonasiga murojaat qilish belgisidir.
  • (selector) — qidirilayotgan HTML element (teg, klass, id).
  • .action() — tanlangan element ustida bajariladigan amal (click, hide, val va h.k.).
HTML + jQuery Jonli Kod 
<!DOCTYPE html>
<html>
<head>
  <script src="https://code.jquery.com/jquery-3.7.0.min.js"></script>
</head>
<body style="font-family:sans-serif; padding:15px; background:#0f172a; color:#f8fafc;">
  <p class="demo-p">Birinchi paragraf</p>
  <p class="demo-p">Ikkinchi paragraf</p>
  <button id="runBtn" style="background:#04AA6D; color:white; border:none; padding:8px 16px; border-radius:6px; cursor:pointer;">
    Hammasini yashirish
  </button>
  <script>
    $(document).ready(function(){
      $("#runBtn").click(function(){
        $("p.demo-p").hide(500);
      });
    });
  </script>
</body>
</html>
📺 Jonli Natija:
📌 ready() hodisasidan foydalanmasangiz, element yuklanmasdan turib skript uni topa olmasligi mumkin.

Selektorlar jQuery Mavzu #4

Element Selektor (Tag Selector)

HTML teglari nomi bo'yicha elementlarni tanlash imkonini beradi. Masalan, barcha <p>, <button> yoki <h1> elementlariga bir vaqtning o'zida ta'sir ko'rsatish mumkin.

  • $('p') — sahifadagi barcha paragraflarni tanlaydi.
  • $('div') — barcha div bloklarini tanlaydi.
  • $('h1, h2, h3') — bir nechta elementlarni vergul bilan guruhlash mumkin.
  • $('table tr') — jadval ichidagi barcha qatorlarni tanlaydi.
HTML + jQuery Jonli Kod 
<!DOCTYPE html>
<html>
<head>
  <script src="https://code.jquery.com/jquery-3.7.0.min.js"></script>
</head>
<body style="font-family:sans-serif; padding:15px; background:#0f172a; color:#f8fafc;">
  <h2>Sarlavha 1</h2>
  <h2>Sarlavha 2</h2>
  <p>Oddiy matn</p>
  <button onclick="$('h2').css('color', '#38bdf8');" style="background:#0284c7; color:white; border:none; padding:8px 14px; border-radius:6px; cursor:pointer;">
    Barcha H2 lar rangini o'zgartirish
  </button>
</body>
</html>
📺 Jonli Natija:
💡 JavaScript dagi document.querySelectorAll('h2') ga teng, lekin ancha qisqa va qulay.

Selektorlar jQuery Mavzu #5

ID Selektor (#id)

Sahifadagi yagona maxsus elementni uning id atributi bo'yicha topish uchun ishlatiladi. CSS dagi kabi # panjara belgisi bilan yoziladi.

  • $('#meningId') — ID si 'meningId' bo'lgan yagona elementni tanlaydi.
  • HTML qoidasiga ko'ra ID bir sahifada takrorlanmasligi kerak.
  • JavaScript dagi document.getElementById('meningId') ga teng.
  • Eng tez va aniq selektor hisoblanadi.

Selektorlar jQuery Mavzu #6

Class Selektor (.class)

Bir xil class atributiga ega bo'lgan bir guruh elementlarni bir vaqtning o'zida tanlash uchun nuqta . belgisi ishlatiladi.

  • $('.card') — 'card' klassiga ega bo'lgan barcha elementlarni tanlaydi.
  • $('p.intro') — faqat 'intro' klassiga ega bo'lgan <p> teglari.
  • Bir nechta klasslar bilan: $('.btn.active').
  • JavaScript dagi document.getElementsByClassName() ga teng.

Selektorlar jQuery Mavzu #7

Filter Selektorlari (:first, :last, :even, :odd)

jQuery qo'shimcha maxsus filtr selektorlariga ega. Ular yordamida ro'yxatdagi birinchi, oxirgi, juft yoki toq elementlarni bemalol ajratib olish mumkin.

  • :first — ro'yxatning birinchi elementi.
  • :last — ro'yxatning eng oxirgi elementi.
  • :even — juft indeksli elementlar (0, 2, 4...).
  • :odd — toq indeksli elementlar (1, 3, 5...).
  • :eq(indeks) — aniq ko'rsatilgan indeksdagi element.

<html>

  </ul>
  <button onclick="$('#darslar li:first').css('color', '#04AA6D'); $('#darslar li:last').css('color', '#ef4444');" style="background:#0769ad; color:white; border:none; padding:8px 14px; border-radius:6px; cursor:pointer;">
    Birinchi va oxirgisini belgilash
  </button>

</html>

📌 Indekslash 0 dan boshlanadi, shuning uchun :first aslida :eq(0) bilan bir xil.

DOM jQuery Mavzu #8

html() va text() Metodlari

Elementlarning ichki kontentini o'qish va yangilash uchun html() va text() metodlari xizmat qiladi. Ularning asosiy farqi HTML teglari bilan ishlashidadir.

  • text() — faqat matnni o'qiydi yoki yozadi (HTML teglari xavfsiz tarzda matnga aylanadi).
  • html() — elementning HTML kodini to'liq qaytaradi yoki yangi HTML teglar qo'shadi.
  • Parametrsiz chaqirilsa — qiymatni o'qiydi (getter).
  • Parametr berilsa — qiymatni yangilaydi (setter).

DOM jQuery Mavzu #9

val() Metodi (Forma Qiymatlari)

Input, textarea, select kabi forma elementlarining qiymatini (value) olish va o'zgartirish uchun val() metodi ishlatiladi.

  • $('input').val() — kiritilgan qiymatni o'qib beradi.
  • $('input').val('yangi qiymat') — inputga yangi qiymat yozadi.
  • Select elementida tanlangan option qiymatini qaytaradi.
  • Checkbox va radio tugmalarida ham qiymatni boshqaradi.

DOM jQuery Mavzu #10

attr() va prop() Metodlari

HTML elementlarining atributlarini (href, src, title, alt, id, class) boshqarish uchun attr() va prop() metodlaridan foydalaniladi.

  • $('a').attr('href') — havola manzilini o'qiydi.
  • $('img').attr('src', 'yangi.jpg') — rasm manzilini o'zgartiradi.
  • prop('checked', true) — boolean xossalar (checked, disabled) uchun ishlatiladi.
  • removeAttr('disabled') — atributni butunlay olib tashlaydi.

DOM jQuery Mavzu #11

css() Metodi (Stillarni Boshqarish)

JavaScript orqali elementlarning CSS stillarini bevosita o'zgartirish yoki joriy qiymatini bilib olish uchun css() metodi xizmat qiladi.

  • Bitta stil berish: $('p').css('color', 'red').
  • Bir nechta stillarni ob'ekt orqali berish: $('p').css({'color':'red', 'font-size':'20px'}).
  • Stil qiymatini o'qish: var rang = $('p').css('color').
  • Pikselli qiymatlar avtomatik ravishda qo'shiladi.

DOM jQuery Mavzu #12

addClass, removeClass va toggleClass

CSS klasslarini elementga qo'shish, olib tashlash yoki almashtirish uchun maxsus qulay metodlar mavjud. Bu usul bevosita style atributini o'zgartirishdan ko'ra toza kod yozish imkonini beradi.

  • addClass('faol') — yangi klass qo'shadi.
  • removeClass('faol') — ko'rsatilgan klassni o'chiradi.
  • toggleClass('faol') — agar klass bo'lsa o'chiradi, yo'q bo'lsa qo'shadi.
  • hasClass('faol') — elementda ushbu klass bor-yo'qligini tekshiradi (true/false).

</html>
📺 Jonli Natija:
💡 Bir qator kod bilan bir vaqtning o'zida bir nechta klass qo'shish mumkin: addClass('klass1 klass2').

DOM jQuery Mavzu #13

append, prepend, after va before

Sahifadagi mavjud elementlar ichiga yoki atrofiga yangi HTML elementlarni dinamik ravishda qo'shish uchun ishlatiladi.

  • append() — elementning eng oxiriga yangi kontent qo'shadi.
  • prepend() — elementning eng boshiga yangi kontent qo'shadi.
  • after() — elementning tashqarisiga, undan keyin qo'shadi.
  • before() — elementning tashqarisiga, undan oldin qo'shadi.

DOM jQuery Mavzu #14

remove() va empty() Metodlari

Keraksiz elementlarni DOM daraxtidan o'chirib tashlash uchun remove() va empty() metodlari qo'llaniladi.

  • remove() — tanlangan elementni va uning barcha ichki elementlarini butunlay o'chiradi.
  • empty() — elementning o'zini qoldirib, faqat ichidagi barcha bolalarini (ichki kontentini) tozalaydi.
  • $('p').remove('.eski') — faqat maxsus klassga ega elementlarni filtrlash mumkin.
  • O'chirilgan elementlar xotiradan tozalanadi.

AJAX jQuery Mavzu #28

$.getJSON() Metodi (JSON Ma'lumotlar)

Serverdan to'g'ridan-to'g'ri JSON formatidagi ma'lumotlarni yuklab olish va ularni avtomatik tarzda JavaScript ob'ektiga aylantirish uchun ixtisoslashgan metod.

  • Javobni qo'lda JSON.parse() qilish shart emas — avtomatik ob'ekt bo'lib keladi.
  • Tashqi ochiq API lardan (ob-havo, valyuta, xabarlar) ma'lumot olishda juda tezkor.
  • Sintaksis: $.getJSON(url, data, callback).
  • JSONP formatini ham qo'llab-quvvatlaydi.
HTML + jQuery Jonli Kod 
<!DOCTYPE html>
<html>
<head>
  <script src="https://code.jquery.com/jquery-3.7.0.min.js"></script>
</head>
<body style="font-family:sans-serif; padding:15px; background:#0f172a; color:#f8fafc;">
  <button id="todoBtn" style="background:#0769ad; color:white; border:none; padding:8px 16px; border-radius:6px; cursor:pointer;">
    Vazifalar ro'yxatini yuklash (JSON)
  </button>
  <ul id="todoRoyxat" style="margin-top:12px; line-height:1.7;"></ul>
  <script>
    $('#todoBtn').click(function(){
      $('#todoRoyxat').empty();
      $.getJSON('https://jsonplaceholder.typicode.com/todos?_limit=3', function(data){
        $.each(data, function(i, item){
          $('#todoRoyxat').append('<li>' + (item.completed ? '✅ ' : '⏳ ') + item.title + '</li>');
        });
      });
    });
  </script>
</body>
</html>

💡 $.each(massiv, function(index, value){ ... }) metodi JSON ro'yxatlarini aylanish uchun eng qulay vosita.
