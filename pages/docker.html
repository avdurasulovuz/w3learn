Docker Nima?

⏱ 10 daqiqa 🟡 O'rta 👁 14,800 marta ko'rilgan

Docker — ilovalarni konteynerlar ichida ishga tushirish imkonini beruvchi platforma. Konteyner — ilovangiz va uning barcha bog'liqliklari (libraries, configs) birgalikda joylashgan izolyatsiyalangan muhit.

Docker bilan "menda ishladi, serverda ishlamadi" muammosi yo'qoladi — chunki muhit hamma joyda bir xil bo'ladi.

💡 VM vs Docker: Virtual Mashina butun OS ni o'z ichiga oladi (GB). Docker esa faqat ilovani va uning bog'liqliklarini saqlaydi (MB). Docker ancha yengil va tez.

Docker O'rnatish

bash 
# Ubuntu ga o'rnatish
sudo apt update
sudo apt install docker.io -y

# Xizmatni ishga tushirish
sudo systemctl start docker
sudo systemctl enable docker

# Foydalanuvchiga ruxsat berish (sudo siz)
sudo usermod -aG docker $USER
newgrp docker

# Tekshirish
docker --version
# Docker version 24.x.x

docker run hello-world
# Hello from Docker! — muvaffaqiyatli!

Asosiy Atamalar

  • 🖼️ Image — ilovaning "qolipi" (blueprint). O'zgarmas.
  • 📦 Container — Image dan yaratilgan ishlaydigan nusxa.
  • 📄 Dockerfile — Image yaratish uchun ko'rsatmalar fayli.
  • 🌐 Registry — Image lar saqlanadigan omborxona (Docker Hub).
  • 🔗 Volume — konteyner o'chirilsa ham qoladigan doimiy xotira.
  • 🕸️ Network — konteynerlar o'rtasidagi aloqa tarmog'i.

docker run — Konteyner Ishga Tushirish

bash 
# Oddiy ishga tushirish
docker run nginx

# Fon rejimida (-d = detached)
docker run -d nginx

# Port ulash (host:konteyner)
docker run -d -p 8080:80 nginx
# Brauzerda: http://localhost:8080

# Nom berish
docker run -d --name myweb -p 8080:80 nginx

# Muhit o'zgaruvchilari (-e)
docker run -d \
  --name mydb \
  -e POSTGRES_PASSWORD=secret \
  -e POSTGRES_DB=myapp \
  -p 5432:5432 \
  postgres

# Interaktiv rejim (-it)
docker run -it ubuntu bash

Konteynerlarni Boshqarish

bash 
# Ishlaydigan konteynerlar
docker ps

# Barcha konteynerlar (to'xtatilganlar ham)
docker ps -a

# Konteynerni to'xtatish
docker stop myweb

# Konteynerni o'chirish
docker rm myweb

# Bir vaqtda to'xtatish va o'chirish
docker rm -f myweb

# Konteyner ichiga kirish
docker exec -it myweb bash

# Loglarni ko'rish
docker logs myweb
docker logs -f myweb   # real-vaqtli

# Konteyner haqida ma'lumot
docker inspect myweb

Dockerfile Yozish

Dockerfile — o'z Image ingizni yaratish uchun ko'rsatmalar to'plami:

dockerfile 
# Node.js ilovasi uchun Dockerfile

# Asosiy image (FROM)
FROM node:18-alpine

# Ish papkasi (WORKDIR)
WORKDIR /app

# Fayllarni nusxalash (COPY)
COPY package*.json ./

# Buyruq bajarish (RUN)
RUN npm install --production

# Qolgan fayllarni nusxalash
COPY . .

# Port ochish (EXPOSE)
EXPOSE 3000

# Muhit o'zgaruvchisi
ENV NODE_ENV=production

# Ishga tushirish buyrug'i (CMD)
CMD ["node", "server.js"]

docker build

bash 
# Image yaratish (-t = tag/nom)
docker build -t myapp:1.0 .

# Dockerfile boshqa joyda bo'lsa
docker build -t myapp -f ./docker/Dockerfile .

# Yaratilgan imagelarni ko'rish
docker images

# Image ni ishga tushirish
docker run -d -p 3000:3000 myapp:1.0

# Image ni o'chirish
docker rmi myapp:1.0

Volumes

Volume — konteyner o'chirilganda ham ma'lumotlar saqlanib qoladi:

bash 
# Volume yaratish
docker volume create mydata

# Volume bilan konteyner ishga tushirish
docker run -d \
  --name mydb \
  -v mydata:/var/lib/postgresql/data \
  postgres

# Bind mount (lokal papkani ulash)
docker run -d \
  -v $(pwd)/html:/usr/share/nginx/html \
  -p 8080:80 \
  nginx

# Barcha volumelarni ko'rish
docker volume ls

# Volume ni o'chirish
docker volume rm mydata

Docker Compose

Docker Compose — bir nechta konteynerlarni birgalikda boshqarish vositasi:

yaml 
# docker-compose.yml
version: '3.8'

services:
  # Web ilovasi
  web:
    build: .
    ports:
      - "3000:3000"
    environment:
      - NODE_ENV=production
      - DATABASE_URL=postgres://user:pass@db:5432/myapp
    depends_on:
      - db
      - redis
    volumes:
      - .:/app

  # PostgreSQL
  db:
    image: postgres:15
    environment:
      POSTGRES_USER: user
      POSTGRES_PASSWORD: pass
      POSTGRES_DB: myapp
    volumes:
      - pgdata:/var/lib/postgresql/data

  # Redis
  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"

volumes:
  pgdata:

Compose Buyruqlari

bash 
# Barcha xizmatlarni ishga tushirish
docker compose up -d

# Loglarni ko'rish
docker compose logs -f

# Xizmat holatini ko'rish
docker compose ps

# Xizmatni qayta ishga tushirish
docker compose restart web

# Barcha xizmatlarni to'xtatish
docker compose down

# To'xtatish + volume lar o'chirish
docker compose down -v

# Faqat bitta xizmat
docker compose up -d db

Best Practices

  • ✅ Alpine asosli imagelardan foydalaning — kichikroq hajm
  • ✅ .dockerignore fayl yarating — node_modules, .git ni chiqarib tashlang
  • ✅ Multi-stage build — build va runtime imageni ajrating
  • ✅ Bir konteyner — bir xizmat printsipiga rioya qiling
  • ✅ Sirlarni (parollarni) muhit o'zgaruvchilari orqali uzating
  • ✅ Doimiy ma'lumotlar uchun Volume ishlatng, konteyner ichiga emas
  • ✅ Layer cachingdan foydalanish uchun COPY package.json ni avval qiling
