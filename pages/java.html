Asosiy Java Mavzu #1

Java Nima?

Java — 1995-yilda Sun Microsystems (hozirda Oracle) tomonidan James Gosling boshchiligida yaratilgan dunyodagi eng kuchli, xavfsiz va platformadan mustaqil obyektga yo'naltirilgan dasturlash tilidir. U 'WORA' (Write Once, Run Anywhere — Bir marta yoz, istalgan joyda ishlat) shiori bilan mashhur.

  • Platforma mustaqilligi: kod baytkodga (Bytecode) aylanadi va istalgan JVM (Java Virtual Machine) da bir xil ishlaydi.
  • Qat'iy tiplashtirilgan (Statically typed) va to'liq OOP tamoyillariga asoslangan.
  • Dunyo bo'ylab 3 milliarddan ortiq qurilmalarda ishlaydi (Android, bank tizimlari, kosmik va korporativ ilovalar).
  • Katta kompaniyalar (Google, Amazon, Netflix, Uber) backend va bulut arxitekturasida yetakchi.
Java Kodi 
public class Main {
    public static void main(String[] args) {
        System.out.println("Salom, Java Dunyosi! ☕");
        System.out.println("Java bilan kuchli va xavfsiz dasturlar yarating.");
        
        int x = 25;
        int y = 75;
        System.out.println("Natija: " + (x + y));
    }
}
🖥️ JVM Chiqish Natijasi:
💡 Java faylining nomi undagi public class nomi bilan bir xil bo'lishi shart (masalan, Main.java).

O'rnatish Java Mavzu #2

JDK ni O'rnatish va Sozlash

Java da dasturlash uchun JDK (Java Development Kit) kerak bo'ladi. U o'z ichiga kompilyator (javac), standart kutubxonalar va JVM ni oladi.

  • Oracle JDK yoki ochiq manbali OpenJDK (masalan, Temurin/Adoptium) tavsiya etiladi.
  • Terminalda tekshirish: java -version va javac -version.
  • Muhit o'zgaruvchisi (Environment Variable): JAVA_HOME to'g'ri o'rnatilishi lozim.
  • Eng qulay IDE vositalari: IntelliJ IDEA (tavsiya etiladi), Eclipse yoki VS Code.
Java Kodi 
# Terminalda tekshirish:
# $ java -version
# openjdk version "21.0.2" 2024-01-16 LTS

# Kompilyatsiya qilish:
# $ javac Main.java  -> Main.class (baytkod) yaratadi

# Ishga tushirish:
# $ java Main
🖥️ JVM Chiqish Natijasi:
⚡ Java 21 LTS hozirgi kunda eng barqaror va zamonaviy qo'llab-quvvatlanuvchi versiya hisoblanadi.

Birinchi Dastur (Hello World Strukturasi)

Asoslar Java Mavzu #4

O'zgaruvchilar va Primitiv Turlar

Java qat'iy tiplashtirilgan til bo'lgani sababli, har bir o'zgaruvchining turi oldindan aniq belgilanishi shart. Java da 8 ta primitiv tur mavjud.

  • Butun sonlar: byte (1 bayt), short (2 bayt), int (4 bayt — eng ko'p ishlatiladigani), long (8 bayt, 'L' bilan).
  • Haqiqiy sonlar: float (4 bayt, 'f' bilan), double (8 bayt).
  • Belgi va mantiq: char ('A' — bitta belgi), boolean (true/false).
  • Java 10 dan boshlab mahalliy o'zgaruvchilarda var kalit so'zi bilan avto-aniqlash mumkin.
Java Kodi 
public class Turlar {
    public static void main(String[] args) {
        int yosh = 24;
        double narx = 99.95;
        char belgi = 'J';
        boolean talabami = true;
        long aholi = 8000000000L;

        // var bilan (Java 10+)
        var ism = "Quvondiq";

        System.out.println("Ism: " + ism);
        System.out.println("Yosh: " + yosh + ", Narx: " + narx);
        System.out.println("Belgi: " + belgi + ", Holat: " + talabami);
    }
}
🖥️ JVM Chiqish Natijasi:
💡 O'zgarmas qiymat (konstanta) yaratish uchun final so'zi qo'yiladi: final double PI = 3.14159;.

Asoslar Java Mavzu #5

Operatorlar (Arifmetik, Mantiqiy, Bitwise)

Matematik hisoblar va mantiqiy xulosalar chiqarish uchun qo'llaniladigan operatorlar to'plami.

  • Arifmetik: +, -, *, /, % (qoldiq).
  • Inkrement/Dekrement: x++, ++x, x--.
  • Taqqoslovchi: ==, !=, >, <, >=, <=.
  • Mantiqiy: && (VA), || (YOKI), ! (INKOR).
Java Kodi 
public class OperatorTest {
    public static void main(String[] args) {
        int a = 19;
        int b = 4;

        System.out.println("Bo'lish (butun): " + (a / b));
        System.out.println("Qoldiq: " + (a % b));

        boolean shart = (a > 10) && (b < 5);
        System.out.println("Mantiqiy shart to'g'rimi? " + shart);
    }
}
🖥️ JVM Chiqish Natijasi:
📌 Butun sonni butun songa bo'lganda (19 / 4), kasr qismi tashlab yuborilib 4 chiqadi. Kasr olish uchun (double) a / b deb yoziladi.

Asoslar Java Mavzu #6

Shartlar (if, else, switch-case)

Dasturning turli shartlar asosida turli yo'nalishda davom etishini ta'minlovchi konstruksiyalar. Java 14+ da yangi qulay Switch Expression kiritilgan.

  • if (shart) { ... } else if (boshqaShart) { ... } else { ... }
  • Klassik switch-case: switch(qiymat) { case 1: ... break; }
  • Zamonaviy Switch Expression: case 1 -> "Natija"; (break shart emas!).
  • Ternar operator: String status = (ball >= 60) ? "O'tdi" : "Yiqildi";
Java Kodi 
public class ShartTest {
    public static void main(String[] args) {
        int faslRaqami = 2;

        // Zamonaviy Switch Expression (Java 14+)
        String faslNomi = switch (faslRaqami) {
            case 1 -> "Bahor";
            case 2 -> "Yoz";
            case 3 -> "Kuz";
            case 4 -> "Qish";
            default -> "Noma'lum fasl";
        };

        System.out.println("Tanlangan fasl: " + faslNomi);
    }
}
🖥️ JVM Chiqish Natijasi:
💡 Yangi case -> sintaksisida o'z-o'zidan break bo'ladi va pastga tushib ketish (fall-through) xatolari yuz bermaydi.

Asoslar Java Mavzu #7

Sikllar (for, while, do-while, for-each)

Amallarni bir necha bor takrorlash uchun sikllardan foydalaniladi.

  • Standart: for (int i = 0; i < n; i++)
  • Kengaytirilgan (For-Each): for (String element : to'plam)
  • while (shart) — oldindan tekshiruvchi sikl.
  • do { ... } while (shart); — kamida 1 marta bajarilishi kafolatlangan sikl.
Java Kodi 
public class SiklTest {
    public static void main(String[] args) {
        String[] tillar = {"Java", "Python", "Kotlin", "Go"};

        System.out.println("For-each orqali aylanish:");
        for (String til : tillar) {
            System.out.println(" • " + til);
        }
    }
}
🖥️ JVM Chiqish Natijasi:
📌 To'plam elementlarini o'zgartirish shart bo'lmasa, doimo indeksli for o'rniga for-each afzal hisoblanadi.

Asoslar Java Mavzu #8

Massivlar (Arrays)

Massiv — bir xil turdagi ma'lumotlarni qat'iy belgilangan o'lchamda saqlovchi obyekt. Java da massiv o'lchami yaratilgach o'zgarmaydi.

  • E'lon qilish: int[] sonlar = new int[5]; yoki int[] sonlar = {10, 20, 30};
  • Uzunlik: sonlar.length (qavssiz maydon).
  • Ko'p o'lchovli massivlar: int[][] matritsa = new int[3][3];
  • java.util.Arrays yordamchi klassi: Arrays.sort(), Arrays.toString().
Java Kodi 
import java.util.Arrays;

public class MassivTest {
    public static void main(String[] args) {
        int[] ballar = {88, 95, 72, 100, 64};

        // Saralash
        Arrays.sort(ballar);

        System.out.println("Saralangan massiv: " + Arrays.toString(ballar));
        System.out.println("Eng past ball: " + ballar[0]);
        System.out.println("Eng yuqori ball: " + ballar[ballar.length - 1]);
    }
}
🖥️ JVM Chiqish Natijasi:
💡 Agar dinamik o'zgaruvchan o'lchamli ro'yxat kerak bo'lsa, massiv o'rniga ArrayList ishlatiladi.

Asoslar Java Mavzu #9

String va StringBuilder

Java da String o'zgarmas (immutable) hisoblanadi. Agar satrni tsikl ichida ko'p marta o'zgartirish kerak bo'lsa, xotirani tejash uchun StringBuilder dan foydalanish shart.

  • Taqqoslash: satrlarni hech qachon == bilan taqqoslamang! Doim str1.equals(str2) ishlating.
  • Asosiy metodlar: length(), charAt(), substring(), contains(), toUpperCase().
  • StringBuilder — tezkor va o'zgaruvchan satr konstruktori (append()).
  • String Pool — bir xil matnlar uchun xotirada bitta joy ajratiladi.
Java Kodi 
public class StringTest {
    public static void main(String[] args) {
        String s1 = "Java";
        String s2 = new String("Java");

        System.out.println("equals bilan: " + s1.equals(s2)); // true
        System.out.println("== bilan: " + (s1 == s2));         // false!

        // StringBuilder namunasi
        StringBuilder sb = new StringBuilder();
        sb.append("W3Learn ").append("Java ").append(2026);
        System.out.println("Qurilgan satr: " + sb.toString());
    }
}
🖥️ JVM Chiqish Natijasi:
⚠️ == ikkita satrning xotiradagi manzilini tekshiradi, equals() esa matnning o'zini solishtiradi.

OOP Java Mavzu #10

OOP — Klasslar va Obyektlar

Java toza obyektga yo'naltirilgan dasturlash tilidir. Har qanday funksionallik klasslar (shablon) va obyektlar (nusxalar) orqali amalga oshiriladi.

  • Klass e'lon qilish: public class Talaba { ... }
  • Maydonlar (Fields) — obyektning holati (ism, yosh).
  • Metodlar (Methods) — obyektning harakatlari (oqish, imtihonTopshirish).
  • Nusxa olish: Talaba t = new Talaba();
Java Kodi 
class Mashina {
    String model;
    int tezlik;

    void gazniBos(int miqdor) {
        tezlik += miqdor;
        System.out.println(model + " tezligi: " + tezlik + " km/s");
    }
}

public class Main {
    public static void main(String[] args) {
        Mashina m = new Mashina();
        m.model = "Malibu 2";
        m.tezlik = 0;

        m.gazniBos(80);
    }
}
🖥️ JVM Chiqish Natijasi:
💡 Obyektlar Heap xotirada, ularning ko'rsatkichlari (references) esa Stack xotirada saqlanadi.

OOP Java Mavzu #11

Konstruktorlar va this Kalit So'zi

Konstruktor — obyekt yaratilayotgan (new) paytda avtomatik ishga tushadigan va maydonlarga boshlang'ich qiymat beruvchi maxsus blokdir. Uning nomi klass nomi bilan aynan bir xil bo'ladi va qaytish turi yozilmaydi.

  • Standart konstruktor (Default Constructor) — agar o'zingiz yozmasangiz, Java avtomatik bo'sh konstruktor beradi.
  • Parametrli konstruktor — qiymatlarni darhol yuklash imkonini beradi.
  • Konstruktor Overloading — bir nechta turli parametrli konstruktorlar yozish.
  • this — joriy obyekt maydonini funksiya parametrlaridan ajratish uchun ishlatiladi.
Java Kodi 
class Kitob {
    String nom;
    String muallif;
    int narx;

    // Konstruktor
    public Kitob(String nom, String muallif, int narx) {
        this.nom = nom;
        this.muallif = muallif;
        this.narx = narx;
    }

    void info() {
        System.out.println("'" + nom + "' (" + muallif + ") - " + narx + " so'm");
    }
}

public class Main {
    public static void main(String[] args) {
        Kitob k = new Kitob("Dunyoning Ishlari", "O'tkir Hoshimov", 35000);
        k.info();
    }
}
🖥️ JVM Chiqish Natijasi:
📌 this(...) orqali bitta konstruktor ichidan boshqa konstruktorni chaqirish mumkin.

OOP Java Mavzu #12

Merosxo'rlik (Inheritance) va super

Merosxo'rlik — bir klass (bola klass) boshqa klassdagi (ota klass) barcha ochiq maydon va metodlarni extends so'zi orqali o'zlashtirib olishidir.

  • Sintaksis: class Menecer extends Xodim { ... }
  • super — ota klass konstruktori yoki metodini chaqirish.
  • Java da ko'p ota klassdan meros olish (Multiple Inheritance) taqiqlangan, faqat bitta klassdan meros olinadi.
  • Barcha Java klasslarining eng oliy ota klassi — java.lang.Object dir.
Java Kodi 
class Xodim {
    String ism;
    double maosh;

    public Xodim(String ism, double maosh) {
        this.ism = ism;
        this.maosh = maosh;
    }

    void ishla() {
        System.out.println(ism + " vazifasini bajarmoqda.");
    }
}

class Dasturchi extends Xodim {
    String til;

    public Dasturchi(String ism, double maosh, String til) {
        super(ism, maosh); // Ota konstruktorini chaqirish
        this.til = til;
    }

    @Override
    void ishla() {
        System.out.println(ism + " " + til + " tilida yangi loyiha kodlamoqda!");
    }
}

public class Main {
    public static void main(String[] args) {
        Dasturchi dev = new Dasturchi("Bobur", 2500, "Java/Spring");
        dev.ishla();
    }
}
🖥️ JVM Chiqish Natijasi:
💡 @Override annotatsiyasi ota klass metodini to'g'ri qayta yozayotganingizni tekshirib turadi.

OOP Java Mavzu #13

Polimorfizm (Polymorphism)

Polimorfizm ('ko'p shakllilik') — bitta umumiy interfeys yoki ota klass orqali turli xil obyektlarni boshqarish imkoniyatidir. Ikki xil bo'ladi: Compile-time (Overloading) va Runtime (Overriding).

  • Method Overloading — bir xil nomli, lekin har xil parametrli metodlar.
  • Method Overriding — ota klass metodining bola klassda yangi xatti-harakatga ega bo'lishi.
  • Dinamik bog'lanish: Hayvon h = new Kuchuk(); h.ovozBer();
  • Kodni o'ta moslashuvchan va kengaytirish oson qiladi.
Java Kodi 
class Shakl {
    void chiz() { System.out.println("Noma'lum shakl chizilmoqda."); }
}

class Doira extends Shakl {
    @Override
    void chiz() { System.out.println("⭕ Doira chizildi."); }
}

class Tortburchak extends Shakl {
    @Override
    void chiz() { System.out.println("⬛ To'rtburchak chizildi."); }
}

public class Main {
    public static void main(String[] args) {
        Shakl s1 = new Doira();
        Shakl s2 = new Tortburchak();

        s1.chiz();
        s2.chiz();
    }
}
🖥️ JVM Chiqish Natijasi:
📌 Ota klass ko'rsatkichi (reference) orqali bola klass obyektini boshqarish polimorfizmning eng yorqin namunasidir.

OOP Java Mavzu #14

Inkapsulyatsiya (Getters & Setters)

Inkapsulyatsiya — obyekt ma'lumotlarini (maydonlarini) to'g'ridan-to'g'ri tashqaridan o'zgartirishdan himoyalash va ularga faqat maxsus getter va setter metodlari orqali ruxsat berish tamoyilidir.

  • Maydonlar doimo private qilib yopiladi.
  • O'qish uchun: public getIsm().
  • O'zgartirish uchun: public setIsm(String ism) — ichida tekshiruv (validatsiya) qo'yish mumkin.
  • Obyekt holatining buzilishi va noto'g'ri qiymatlar kiritilishini (masalan, manfiy yosh) oldini oladi.
Java Kodi 
class BankHisobi {
    private double balans;

    public BankHisobi(double boshlangich) {
        this.balans = boshlangich;
    }

    public double getBalans() {
        return balans;
    }

    public void pulQosh(double summa) {
        if (summa > 0) {
            balans += summa;
            System.out.println("✅ " + summa + " so'm qo'shildi.");
        } else {
            System.out.println("❌ Noto'g'ri summa!");
        }
    }
}

public class Main {
    public static void main(String[] args) {
        BankHisobi hisob = new BankHisobi(100000);
        hisob.pulQosh(50000);
        System.out.println("Joriy balans: " + hisob.getBalans() + " so'm");
    }
}
🖥️ JVM Chiqish Natijasi:
💡 Zamonaviy Java da oddiy ma'lumot saqlovchi klasslar uchun record turi kiritilgan (u avtomatik getterlarni beradi).

OOP Java Mavzu #15

Abstraktsiya va Abstrakt Klasslar

Abstraktsiya — ichki murakkab detallarni yashirib, foydalanuvchiga faqat muhim va zarur funksionallikni ko'rsatishdir. abstract kalit so'zi bilan yaratiladi.

  • abstract class — o'zidan to'g'ridan-to'g'ri new qilib obyekt olib bo'lmaydi.
  • Abstrakt metodlar tanasiz (kod blokisiz) bo'ladi va bolalari ularni yozishi shart.
  • Shu bilan birga oddiy (to'liq yozilgan) metodlarni ham saqlay oladi.
  • Umumiy shablon yaratishda juda qo'l keladi.
Java Kodi 
abstract class Xabarchi {
    abstract void yubor(String kimga, String matn); // Tanasi yo'q

    void logYoz(String matn) { // Oddiy metod
        System.out.println("Log: " + matn);
    }
}

class TelegramBot extends Xabarchi {
    @Override
    void yubor(String kimga, String matn) {
        System.out.println("📱 Telegram orqali @" + kimga + " ga: " + matn);
    }
}

public class Main {
    public static void main(String[] args) {
        Xabarchi bot = new TelegramBot();
        bot.yubor("avdurasulov", "Java darsi tayyor!");
    }
}
🖥️ JVM Chiqish Natijasi:
📌 Agar barcha metodlar tanasiz bo'lishi kerak bo'lsa, abstrakt klass o'rniga Interface afzalroqdir.

OOP Java Mavzu #16

Interface (Interfeyslar)

Interface — to'liq abstrakt shartnoma. Klasslar uni implements kalit so'zi orqali amalga oshiradi. Java da klass bir vaqtning o'zida bir nechta interfeyslarni qabul qilishi mumkin.

  • Ko'p merosxo'rlik muammosini hal qiladi (Multiple Inheritance).
  • Interfeysdagi barcha o'zgaruvchilar avtomatik public static final (konstanta) bo'ladi.
  • Barcha metodlar avtomatik public abstract hisoblanadi.
  • Java 8 dan boshlab default va static metodlar kiritilgan.
Java Kodi 
interface Haydovchi {
    void hayda();
}

interface Suzuvchi {
    void suz();
}

// Ikkala interfeysni ham qabul qiladi
class AmfibiyaMashina implements Haydovchi, Suzuvchi {
    public void hayda() { System.out.println("🚗 Quruqlikda yurmoqda."); }
    public void suz() { System.out.println("🚤 Suvda suzmoqda."); }
}

public class Main {
    public static void main(String[] args) {
        AmfibiyaMashina amf = new AmfibiyaMashina();
        amf.hayda();
        amf.suz();
    }
}
🖥️ JVM Chiqish Natijasi:
💡 Java da eng mashhur interfeyslar: Comparable, Runnable, Serializable.

Collections Java Mavzu #17

ArrayList (Dinamik Massiv)

ArrayList — oddiy massivdan farqli ravishda, element qo'shilgan sari o'z hajmini avtomatik kattalashtirib boruvchi dinamik ro'yxatdir.

  • Import: import java.util.ArrayList;
  • Qo'shish: list.add('Element'), list.add(indeks, 'Element').
  • Olish va o'zgartirish: list.get(0), list.set(0, 'Yangi').
  • O'chirish: list.remove(0) yoki list.clear().
  • Elementlar soni: list.size().
Java Kodi 
import java.util.ArrayList;

public class ListTest {
    public static void main(String[] args) {
        ArrayList<String> shaxarlar = new ArrayList<>();

        shaxarlar.add("Toshkent");
        shaxarlar.add("Samarqand");
        shaxarlar.add("Buxoro");

        shaxarlar.remove("Buxoro");

            System.out.println(" 📍 " + sh);
        }

HashMap (Kalit-Qiymat To'plami)

HashMap — ma'lumotlarni kalit va qiymat (Key-Value) juftligi ko'rinishida saqlovchi juda tezkor to'plam. Kalitlar unikal bo'lishi shart.

  • Borligini tekshirish: map.containsKey('UZ').

Java Kodi 
import java.util.HashMap;

public class MapTest {
    public static void main(String[] args) {

Generics (Umumiy Turlar <T>)

Generics — klasslar, interfeyslar va metodlarni ma'lum bir turga bog'lamasdan, universal qilib yozish imkonini beradi. Kompilyatsiya vaqtida xatolarni aniqlab, Type Safety ni ta'minlaydi.

  • Tur parametri: <T> (Type), <E> (Element), <K, V> (Key, Value).
  • Kastingdan (Type Casting) qutqaradi: (String) list.get(0) yozish shart bo'lmaydi.
  • Cheklangan turlar: <T extends Number> — faqat raqamli turlarga ruxsat berish.
  • Kompilyatsiyadan so'ng Type Erasure mexanizmi orqali barcha umumiy turlar tozalanadi.
Java Kodi 
// Universal quti klassi
class Quti<T> {
    private T buyum;

    public void sol(T buyum) { this.buyum = buyum; }
    public T ol() { return buyum; }
}

public class Main {
    public static void main(String[] args) {
        Quti<String> matnQutisi = new Quti<>();
        matnQutisi.sol("Qimmatbaho kitob");
        System.out.println("Qutida: " + matnQutisi.ol());

        Quti<Integer> sonQutisi = new Quti<>();
        sonQutisi.sol(777);
        System.out.println("Raqam: " + sonQutisi.ol());
    }
}

Streams API (Ma'lumotlar Oqimi)

Java 8 da kiritilgan Streams API to'plamlar ustida deklarativ (SQL kabi) amallar bajarish: filtrlash, o'zgartirish, saralash va guruhlashni juda qisqa kod bilan amalga oshiradi.

  • filter() — shart bo'yicha saralaydi.
  • map() — har bir elementni o'zgartiradi.
  • sorted() — tartiblaydi.
  • collect(Collectors.toList()) — natijani qayta ro'yxatga jamlaydi.
  • Parallel Stream: parallelStream() ko'p yadroli protsessordan to'liq foydalanadi.
Java Kodi 
import java.util.List;
import java.util.stream.Collectors;

public class StreamTest {
    public static void main(String[] args) {
        List<String> ismlar = List.of("Ali", "Zarina", "Anvar", "Bobur", "Asal");

        // 'A' harfi bilan boshlanuvchilarni katta harfda olish
        List<String> aIsmlar = ismlar.stream()
                .filter(ism -> ism.startsWith("A"))
                .map(String::toUpperCase)
                .sorted()
                .collect(Collectors.toList());

        System.out.println("Natija: " + aIsmlar);
    }
}

Lambda Ifodalar va Funksional Interfeyslar

Lambda ifodasi — bu nomsiz, ixcham funksiya bo'lib, uni boshqa metodlarga argument sifatida uzatish mumkin. Sintaksis: (parametrlar) -> { ifoda }.

  • Faqat bitta abstrakt metodga ega bo'lgan FunctionalInterface bilan ishlaydi.
  • Mashhur standart interfeyslar: Predicate (tekshiruvchi), Function (o'zgartiruvchi), Consumer (bajaruvchi).
  • Metod havolasi (Method Reference): System.out::println.
Java Kodi 
import java.util.List;

public class LambdaTest {
    public static void main(String[] args) {
        List<Integer> sonlar = List.of(1, 2, 3, 4, 5);

        // Lambda orqali har birini chop etish
        sonlar.forEach(n -> System.out.print((n * 10) + " "));
        System.out.println();
    }
}

Ilg'or Java Mavzu #24

Istisnolar bilan Ishlash (Exceptions: try-catch-finally)

Dastur ishlash vaqtida kutilmagan xatoliklar (masalan, 0 ga bo'lish, fayl topilmaslik) yuz berganda dastur to'xtab qolmasligi uchun istisnolar (Exceptions) ushlanadi.

  • try — xato berishi mumkin bo'lgan xavfli kod bloki.
  • catch (Exception e) — xatolik yuz berganda uni qayta ishlash.
  • finally — xato bo'lsa ham, bo'lmasa ham har doim bajariladigan blok (resurslarni yopish uchun).
  • Checked (kompilyator talab qiladigan) va Unchecked (Runtime) istisnolar mavjud.
  • Shaxsiy xato klasslarini yaratish: class MeningXato extends Exception.
Java Kodi 
public class XatoTest {
    public static void main(String[] args) {
        try {
            int a = 10;
            int b = 0;
            int natija = a / b; // 0 ga bo'lish xatosi
            System.out.println("Natija: " + natija);
        } catch (ArithmeticException e) {
            System.out.println("⚠️ Xatolik ushlandi: Sonni nolga bo'lib bo'lmaydi!");
        } finally {
            System.out.println("🔒 'finally' bloki har doim bajariladi.");
        }
    }
}
🖥️ JVM Chiqish Natijasi:
💡 Fayllar va ulanishlarni avtomatik yopish uchun zamonaviy try-with-resources sintaksisi ishlatiladi.

Ko'p Oqimlilik (Multithreading)

Multithreading — bitta dastur ichida bir nechta vazifalarni parallel va bir vaqtning o'zida bajarish imkoniyatidir. Zamonaviy ko'p yadroli protsessorlar quvvatidan 100% foydalanish uchun zarur.

  • Oqim yaratish: Thread klassidan meros olish yoki Runnable interfeysini amalga oshirish.
  • Boshlash: thread.start() — bu yangi oqim ochadi (to'g'ridan-to'g'ri run() chaqirilmaydi!).
  • Sinxronizatsiya: synchronized kalit so'zi poyga holatini (Race Condition) oldini oladi.
  • Java 21 Virtual Threads (Project Loom) — millionlab yengil oqimlarni bir vaqtda ishlatish imkonini beradi.
Java Kodi 
class Oqim extends Thread {
    private String nom;
    public Oqim(String nom) { this.nom = nom; }

    public void run() {
        System.out.println("🚀 Oqim boshlandi: " + nom);
    }
}

public class Main {
    public static void main(String[] args) {
        Oqim t1 = new Oqim("Yuklash-1");
        Oqim t2 = new Oqim("Yuklash-2");

        t1.start();
        t2.start();
    }
}

📌 Thread.sleep(1000) oqimni ko'rsatilgan millisekundga vaqtincha to'xtatib turadi.
