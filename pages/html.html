HTML Nima?

⏱ 5 daqiqa 🟢 Boshlang'ich 👁 15,420 marta ko'rilgan

HTML (HyperText Markup Language) — web sahifalar yaratish uchun standart belgilash tili. HTML sahifaning tuzilmasini belgilaydi. Brauzer HTML kodini o'qib, uni vizual ko'rinishga aylantiradi.

HTML teglar (tags) orqali ishlaydi. Teglar qavs ichida yoziladi va odatda juft bo'ladi: ochiluvchi teg va yopiluvchi teg.

💡 Eslatma: HTML — dasturlash tili emas, belgilash tilidir. U sahifaning tuzilmasini belgilaydi, mantiqini emas.

HTML Tuzilmasi

Har bir HTML fayli quyidagi asosiy tuzilmaga ega:

HTML 
<!DOCTYPE html>
<html>
  <head>
    <title>Mening sahifam</title>
  </head>
  <body>
    <h1>Salom, Dunyo!</h1>
    <p>Bu mening birinchi HTML sahifam.</p>
  </body>
</html>

HTML Elementlari

HTML elementi — ochiluvchi teg, mazmun va yopiluvchi tegdan iborat:

HTML 
<h1>Sarlavha 1</h1>
<h2>Sarlavha 2</h2>
<h3>Sarlavha 3</h3>
<p>Bu oddiy <strong>qalin</strong> va <em>qiya</em> matni.</p>
<hr>
<p>Ikkinchi paragraf.</p>

HTML Havolalar

HTML 
<!-- Oddiy havola -->
<a href="https://www.google.com">Google</a>

<!-- Yangi tabda ochish -->
<a href="https://www.google.com" target="_blank">
  Google (yangi tabda)
</a>

<!-- Tugma ko'rinishida -->
<a href="#" style="background:#04AA6D;color:#fff;padding:8px 16px;
   border-radius:4px;text-decoration:none;">
  Tugma ko'rinishidagi havola
</a>
