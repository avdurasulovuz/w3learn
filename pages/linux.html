Linux Nima?

⏱ 10 daqiqa 🟢 Boshlang'ich 👁 18,600 marta ko'rilgan

Linux — ochiq manbali (open-source) operatsion tizim yadrosi (kernel). Linus Torvalds tomonidan 1991-yilda yaratilgan.

Dunyo serverlarining 90% dan ortig'i Linux da ishlaydi. Android ham Linux yadrosi asosida qurilgan. Dasturchi sifatida Linux ni bilish zarur.

💡 Nima uchun Linux? Bepul, xavfsiz, tez, moslashuvchan va deyarli barcha serverlar Linux da ishlaydi.

Linux Fayl Tizimi

Linux da hamma narsa fayl. Asosiy papkalar:

bash 
/           # Ildiz (root) papkasi
/home/      # Foydalanuvchi papkalari (/home/ali)
/root/      # Root foydalanuvchi uy papkasi
/etc/       # Konfiguratsiya fayllar
/var/       # O'zgaruvchan ma'lumotlar (loglar, DB)
/tmp/       # Vaqtinchalik fayllar
/usr/       # Dasturlar va kutubxonalar
/bin/       # Asosiy buyruqlar (ls, cp, mv)
/sbin/      # Tizim buyruqlari (sudo, fdisk)
/opt/       # Uchinchi tomon dasturlar
/proc/      # Jarayonlar haqida virtual fayllar
/dev/       # Qurilma fayllari

ls — Papka Tarkibini Ko'rish

bash 
# Hozirgi papka tarkibi
ls

# Batafsil ko'rsatish (-l)
ls -l

# Yashirin fayllar ham (-a)
ls -la

# Hajmni o'qilishi qulay formatda (-h)
ls -lh

# Ma'lum papkani ko'rish
ls /var/log

# Tartiblash — hajmi bo'yicha
ls -lhS

# Vaqti bo'yicha (yangi birinchi)
ls -lt

cd / pwd / mkdir

bash 
# Papkaga kirish
cd /var/log
cd projects/myapp

# Oldingi papkaga qaytish
cd ..

# Uy papkasiga qaytish
cd ~
cd

# Oldingi joyga qaytish
cd -

# Hozirgi joylashuvni ko'rish
pwd
# /home/ali/projects

# Papka yaratish
mkdir myproject

# Ichma-ich papkalar yaratish (-p)
mkdir -p projects/web/assets/css

# Papkani o'chirish (bo'sh)
rmdir mydir

Fayl Yaratish va Nusxalash

bash 
# Bo'sh fayl yaratish
touch index.html
touch file1.txt file2.txt

# Faylni nusxalash
cp index.html backup.html

# Papkani nusxalash (-r = recursive)
cp -r myproject myproject_backup

# Faylni ko'chirish / qayta nomlash
mv oldname.txt newname.txt
mv file.txt /var/www/html/

# Faylni o'chirish
rm file.txt

# Papkani o'chirish (-r)
rm -r myproject

# Majburan o'chirish (-f = force)
rm -rf old_project

# Faylni ko'rish
cat file.txt

# Sahifa-sahifa ko'rish
less bigfile.log
# q — chiqish, Space — keyingi sahifa

grep — Matn Qidirish

bash 
# Fayldan matn qidirish
grep "error" app.log

# Katta-kichik harfga e'tiborsiz (-i)
grep -i "error" app.log

# Qator raqamlari bilan (-n)
grep -n "ERROR" app.log

# Papka ichida rekursiv (-r)
grep -r "TODO" ./src/

# Faqat fayl nomini ko'rsatish (-l)
grep -rl "password" ./config/

# Naqsh bilan (regex)
grep -E "^[0-9]{4}" data.txt

# Inversiya — mos kelmaydigan qatorlar (-v)
grep -v "DEBUG" app.log

# Pipe bilan birga
ps aux | grep nginx
cat access.log | grep "404"

Ruxsatlar: chmod

Linux da har bir faylning ruxsatlari (permissions) bor:

bash 
# Ruxsatlarni ko'rish
ls -l
# -rwxr-xr-- 1 ali users 1234 Nov 1 file.sh
#  rwx = owner: o'qish+yozish+bajarish
#  r-x = group: o'qish+bajarish
#  r-- = others: faqat o'qish

# Ruxsat berish (chmod)
chmod 755 script.sh
# 7 = rwx (owner), 5 = r-x (group), 5 = r-x (others)

# Hamma bajarishi uchun
chmod +x script.sh

# Faqat owner yozishi uchun
chmod 644 config.txt

# Rekursiv (papka va tarkibi)
chmod -R 755 /var/www/html

# Ruxsatlar jadvali:
# 4 = r (read)
# 2 = w (write)
# 1 = x (execute)
# 7 = rwx, 6 = rw-, 5 = r-x, 4 = r--

SSH — Masofaviy Ulanish

bash 
# SSH kalit juftligi yaratish
ssh-keygen -t rsa -b 4096 -C "email@example.com"

# Kalitni serverga yuklash
ssh-copy-id user@server_ip

# Serverga ulanish
ssh ali@192.168.1.100

# Port ko'rsatib ulanish
ssh -p 2222 ali@example.com

# Fayl yuklash (scp)
scp local_file.txt ali@server:/home/ali/

# Papka yuklash (-r)
scp -r ./myproject ali@server:/var/www/

# Serverdan fayl olish
scp ali@server:/etc/nginx/nginx.conf ./

# SSH config fayl (~/.ssh/config)
# Host myserver
#   HostName 192.168.1.100
#   User ali
#   Port 22
#   IdentityFile ~/.ssh/id_rsa

Bash Skript Yozish

bash 
#!/bin/bash
# Birinchi satr — shebang (qaysi interpreter)

# O'zgaruvchi
NAME="Ali"
echo "Salom, $NAME!"

# Foydalanuvchi kiritishi
read -p "Ismingizni kiriting: " USER_NAME
echo "Xush kelibsiz, $USER_NAME!"

# Shart (if-else)
AGE=20
if [ $AGE -ge 18 ]; then
  echo "Voyaga yetgan"
else
  echo "Voyaga yetmagan"
fi

# Tsikl (for)
for i in 1 2 3 4 5; do
  echo "Raqam: $i"
done

# Fayl mavjudligini tekshirish
FILE="/etc/nginx/nginx.conf"
if [ -f "$FILE" ]; then
  echo "Fayl mavjud"
else
  echo "Fayl topilmadi"
fi

# Funksiya
greet() {
  echo "Salom, $1!"
}
greet "Vali"

Cron — Avtomatik Vazifalar

bash 
# Cron jadvalini ko'rish/tahrirlash
crontab -e

# Format: daqiqa soat kun oy hafta_kuni buyruq
# *  *  *  *  *  /path/to/command
# │  │  │  │  └─ hafta kuni (0=yakshanba, 6=shanba)
# │  │  │  └──── oy (1-12)
# │  │  └─────── kun (1-31)
# │  └────────── soat (0-23)
# └───────────── daqiqa (0-59)

# Misollar:
# Har daqiqada
* * * * * /home/ali/script.sh

# Har soatda (soat boshi)
0 * * * * /home/ali/cleanup.sh

# Har kuni ertalab 6:00 da
0 6 * * * /home/ali/backup.sh

# Har dushanba kuni 9:00 da
0 9 * * 1 /home/ali/weekly.sh

# Cron loglarini ko'rish
grep CRON /var/log/syslog

Paket Menejeri

bash 
# Ubuntu / Debian — apt
sudo apt update              # Ro'yxatni yangilash
sudo apt upgrade             # Dasturlarni yangilash
sudo apt install nginx       # O'rnatish
sudo apt remove nginx        # O'chirish
sudo apt autoremove          # Keraksizlarni tozalash
apt search nodejs            # Qidirish

# CentOS / RHEL — yum / dnf
sudo dnf install nginx
sudo dnf remove nginx
sudo dnf update

# Snap paketlar (barcha distributivlar)
sudo snap install code       # VS Code

# Dastur versiyasini bilish
nginx -v
node --version
python3 --version
