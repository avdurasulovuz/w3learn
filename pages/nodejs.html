Asosiy Node.js Mavzu #1

Node.js Nima?

Node.js — bu Google Chrome V8 dvigateli ustiga qurilgan, ochiq manbali, server tomonida JavaScript kodlarini ishga tushiruvchi dasturlash muhitidir (Runtime Environment). U Ryan Dahl tomonidan 2009-yilda yaratilgan.

  • JavaScriptni faqat brauzerda emas, balki kuchli backend serverlarda ishlatish imkonini berdi.
  • Asinxron va Event-Driven arxitektura: bitta oqimda (Single-threaded) millionlab so'rovlarni o'ta tez qayta ishlaydi.
  • Bloklanmaydigan I/O (Non-blocking I/O) modeli tufayli yuklama yuqori bo'lgan tarmoq ilovalari uchun ideal.
  • Netflix, Uber, PayPal, LinkedIn kabi gigantlar backend qismini aynan Node.js ga o'tkazgan.
Node.js Server Kodi 
// Oddiy Node.js dasturi
const os = require('os');

console.log("Salom, Node.js Backend Dunyosi! 🟢");
console.log("Operatsion tizim:", os.platform());
console.log("CPU yadrolari soni:", os.cpus().length);
console.log("Xotira (RAM):", Math.round(os.totalmem() / (1024 ** 3)) + " GB");
🖥️ Server Terminal Natijasi:
💡 Node.js dasturlash tili emas, balki JavaScript kodini serverda bajaruvchi muhit (runtime) dir.

O'rnatish Node.js Mavzu #2

Node.js ni O'rnatish va Sozlash

Node.js ni o'rnatish rasmiy nodejs.org saytidan amalga oshiriladi. Saytda ikkita versiya taklif etiladi: LTS (Long Term Support — uzoq muddatli barqaror qo'llab-quvvatlanuvchi) va Current (eng yangi tajribaviy imkoniyatlar).

  • Ishlab chiqarish (Production) va o'rganish uchun doimo LTS versiya tavsiya etiladi.
  • O'rnatilganini tekshirish uchun terminalda: node -v
  • Paketlar menejeri npm avtomatik tarzda Node.js bilan birga o'rnatiladi.
  • Kodni qayta ishga tushirmasdan yangilab turish uchun node --watch app.js yoki nodemon ishlatiladi.
Node.js Server Kodi 
# Terminalda tekshirish:
# $ node -v
# v20.11.0

# $ npm -v
# 10.2.4

# Faylni ishga tushirish:
# $ node server.js
🖥️ Server Terminal Natijasi:
📌 Node.js 18-versiyasidan boshlab node --watch app.js buyrug'i orqali kod o'zgarganda server avtomatik qayta yonadi.

NPM — Paketlar Menejeri

Asoslar Node.js Mavzu #4

Modullar Tizimi (CommonJS va ES Modules)

Node.js da kodlar alohida fayllarga (modullarga) bo'linadi. Node.js da ikkita asosiy modul tizimi mavjud: klassik CommonJS (require / module.exports) va zamonaviy ES Modules (import / export).

  • CommonJS: const express = require('express'); va module.exports = { ... };
  • ES Modules ishlatish uchun package.json ga "type": "module" qo'shiladi.
  • Shaxsiy modul yaratish orqali loyihani qismlarga ajratish mumkin.
  • O'rnatilgan modullar (fs, path, http) qo'shimcha o'rnatishni talab qilmaydi.
Node.js Server Kodi 
// hisoblagich.js (Shaxsiy modul)
function qosh(a, b) { return a + b; }
function kopaytir(a, b) { return a * b; }

module.exports = { qosh, kopaytir };

// app.js (Modulni ulash)
const { qosh, kopaytir } = require('./hisoblagich');

console.log("Qo'shish:", qosh(15, 25));
console.log("Ko'paytirish:", kopaytir(4, 5));
🖥️ Server Terminal Natijasi:
📌 ./ bilan boshlangan yo'llar shaxsiy fayllarni, belgisiz yo'llar esa node_modules ni anglatadi.

Modullar Node.js Mavzu #5

fs — Fayl Tizimi Moduli

fs (File System) moduli serverdagi fayllarni o'qish, yozish, tahrirlash va o'chirish imkonini beradi. U ham sinxron (bloklovchi), ham asinxron (bloklamaydigan) metodlarga ega.

  • Asinxron o'qish: fs.readFile('fayl.txt', 'utf8', (err, data) => { ... })
  • Faylga yozish: fs.writeFile() (ustidan yozadi), fs.appendFile() (oxiriga qo'shadi).
  • Zamonaviy Promise usuli: const fs = require('fs/promises');
  • Katta fayllar bilan ishlashda doimo asinxron yoki Streams usulidan foydalanish lozim.
Node.js Server Kodi 
const fs = require('fs/promises');

async function faylBilanIshlash() {
  // 1. Faylga yozish
  await fs.writeFile('salom.txt', 'W3Learn Node.js darsiga xush kelibsiz!');
  
  // 2. Fayldan o'qish
  const malumot = await fs.readFile('salom.txt', 'utf8');
  console.log("Fayl ichidagi matn:", malumot);
  
  // 3. Oxiriga qo'shish
  await fs.appendFile('salom.txt', '\nServer vaqti: ' + new Date().toLocaleTimeString());
}

faylBilanIshlash();
🖥️ Server Terminal Natijasi:
⚡ fs.readFileSync() kabi sinxron metodlar serverni boshqa so'rovlar uchun to'xtatib qo'yishi mumkin, ehtiyot bo'ling!

Modullar Node.js Mavzu #6

path Moduli

path moduli turli xil operatsion tizimlarda (Windows'da \ va Linux/Mac'da /) fayl va kataloglar manzillarini xatosiz va xavfsiz birlashtirish uchun xizmat qiladi.

  • path.join(__dirname, 'papka', 'fayl.html') — platformaga mos to'g'ri manzil yasaydi.
  • path.resolve() — mutlaq (absolute) manzilni qaytaradi.
  • path.extname('rasm.png') — fayl kengaytmasini oladi (.png).
  • __dirname — joriy papkaning to'liq manzili.
Node.js Server Kodi 
const path = require('path');

const faylManzili = '/foydalanuvchilar/admin/hujjatlar/hisobot.pdf';

console.log("Fayl nomi:", path.basename(faylManzili));
console.log("Papkasi:", path.dirname(faylManzili));
console.log("Kengaytmasi:", path.extname(faylManzili));

// Xavfsiz birlashtirish
const toliqManzil = path.join(__dirname, 'public', 'images', 'logo.png');
console.log("Xavfsiz manzil:", toliqManzil);
🖥️ Server Terminal Natijasi:
💡 Hech qachon manzillarni 'papka/' + fayl deb qo'lda yozmang — doim path.join() ishlating.

http Moduli (Sof Veb Server)

Node.js tarkibidagi http moduli tashqi kutubxonalarsiz ham mustaqil HTTP veb server yaratish imkonini beradi.

  • http.createServer((req, res) => { ... }) — server ob'ektini yaratadi.
  • req (Request) — mijozdan kelgan so'rov (URL, metod, headers).
  • res (Response) — mijozga qaytariladigan javob (status kod, HTML/JSON).
  • server.listen(port) — ko'rsatilgan portni tinglashni boshlaydi.
Node.js Server Kodi 
const http = require('http');

const server = http.createServer((req, res) => {
  res.writeHead(200, { 'Content-Type': 'application/json' });
  res.end(JSON.stringify({
    status: 'success',
    xabar: 'Salom, HTTP server ishlamoqda!',
    vaqt: new Date().toISOString()
  }));
});

const PORT = 3000;
console.log(`Server http://localhost:${PORT} da ishga tushdi 🚀`);
🖥️ Server Terminal Natijasi:
📌 Haqiqiy yirik loyihalarda sof http moduli o'rniga Express.js yoki Nest.js ishlatiladi.

os Moduli (Tizim Ma'lumotlari)

os (Operating System) moduli server ishlayotgan kompyuter apparat ta'minoti va operatsion tizim haqidagi barcha texnik ma'lumotlarni taqdim etadi.

  • os.cpus() — protsessor yadrolari va chastotasi.
  • os.freemem() va os.totalmem() — bo'sh va jami xotira.
  • os.uptime() — kompyuter necha soniyadan beri o'chmasdan ishlayotgani.
  • Server monitoring tizimlari va yuklamani taqsimlashda qo'llaniladi.
Node.js Server Kodi 
const os = require('os');

console.log("Arxitektura:", os.arch());
console.log("Foydalanuvchi:", os.userInfo().username);
console.log("Bo'sh xotira:", (os.freemem() / (1024 * 1024)).toFixed(0) + " MB");
console.log("Tizim ishlash vaqti:", (os.uptime() / 3600).toFixed(1) + " soat");
🖥️ Server Terminal Natijasi:
💡 Cluster moduli orqali har bir CPU yadrosiga alohida Node.js jarayoni ochishda os.cpus().length ishlatiladi.

Modullar Node.js Mavzu #9

EventEmitter (Hodisalar bilan Ishlash)

Node.js arxitekturasi asosan hodisalarga asoslangan. EventEmitter klassi orqali o'z shaxsiy hodisalaringizni yaratish (emit) va ularni tinglash (listen) mumkin.

  • emitter.on('hodisa', callback) — hodisani tinglaydi.
  • emitter.emit('hodisa', ma'lumot) — hodisani ishga tushiradi.
  • Bir marta ishlaydigan hodisa: emitter.once().
  • Chat tizimlari, to'lov xabarnomalari va loggerlar aynan shu tamoyilda quriladi.
Node.js Server Kodi 
const EventEmitter = require('events');
const buyurtmaHodisa = new EventEmitter();

// 1. Hodisani tinglash
buyurtmaHodisa.on('yangi_buyurtma', (id, summa) => {
  console.log(`📦 Yangi buyurtma #${id} qabul qilindi. Summa: ${summa} so'm.`);
});

buyurtmaHodisa.on('yangi_buyurtma', (id) => {
  console.log(`✉️ Mijozga #${id} raqamli SMS yuborildi.`);
});

// 2. Hodisani chaqirish
buyurtmaHodisa.emit('yangi_buyurtma', 1042, 350000);
🖥️ Server Terminal Natijasi:
📌 Node.js dagi barcha oqimlar (Streams) va HTTP so'rovlari aslida EventEmitter vorislari hisoblanadi.

Stream (Oqimlar bilan Katta Fayllarni Qayta Ishlash)

Stream — ulkan ma'lumotlar oqimini (masalan, 10 GB li video yoki log fayl) xotirani to'ldirmasdan, bo'laklab (chunks) o'qish va uzatish mexanizmidir.

  • Video streaming (YouTube, Netflix kabi) xuddi shu prinsipda ishlaydi.

Express.js — Backend Freymvork

Express Node.js Mavzu #12

Routing (Marshrutlash)

Mijoz turli xil URL manzillarga (masalan, /foydalanuvchilar yoki /mahsulotlar) murojaat qilganda ularga mos kodni ishga tushirish Routing deyiladi.

  • Asosiy metodlar: app.get(), app.post(), app.put(), app.delete().
  • Dinamik parametrlar: /foydalanuvchi/:id -> req.params.id orqali olinadi.
  • Query parametrlar: /qidiruv?q=telefon -> req.query.q orqali olinadi.
  • express.Router() yordamida yo'llarni alohida fayllarga ajratish mumkin.
Node.js Server Kodi 
const express = require('express');
const app = express();

// Dinamik parametr (:id)
app.get('/foydalanuvchi/:id', (req, res) => {
  const userId = req.params.id;
  res.json({ id: userId, ism: "Foydalanuvchi #" + userId });
});

// Query parametr (?tartib=yangi)
app.get('/mahsulotlar', (req, res) => {
  const tartib = req.query.tartib || 'barchasi';
  res.json({ filter: tartib, jami: 25 });
});

console.log("Routing muvaffaqiyatli sozlandi!");
🖥️ Server Terminal Natijasi:
💡 Har bir modul uchun alohida routes/user.routes.js fayllar ochish loyihani toza saqlaydi.

Express Node.js Mavzu #13

Middleware (Oraliq Dasturlar)

Middleware — so'rov (request) kelib tushishi bilan yakuniy javob (response) qaytarilishi orasida ishlaydigan funksiyalardir. Ular log yozish, autentifikatsiya tekshirish va ma'lumotlarni tekshirishda ishlatiladi.

  • Har bir middleware (req, res, next) parametrlarini qabul qiladi.
  • Keyingi bosqichga o'tish uchun albatta next() chaqirilishi shart.
  • app.use(express.json()) — kelgan JSON tanasini (req.body) o'qib beruvchi standart middleware.
  • Xatoliklarni ushlovchi maxsus middleware: (err, req, res, next).
Node.js Server Kodi 
const express = require('express');
const app = express();

// Shaxsiy Logger Middleware
const vaqtLogger = (req, res, next) => {
  console.log(`[${new Date().toLocaleTimeString()}] ${req.method} ${req.url}`);
  next(); // Keyingi funksiyaga o'tish
};

app.use(vaqtLogger);
app.use(express.json()); // JSON body ni parslash

app.get('/status', (req, res) => {
  res.send('Hammasi yaxshi ishlamoqda');
});

console.log("Middleware tizimi faol!");
🖥️ Server Terminal Natijasi:
⚠️ Agar middleware ichida next() chaqirilmasa yoki javob qaytarilmasa, so'rov javobsiz osilib qoladi.

Statik Fayllarni Tarqatish (Images, CSS, JS)

Saytning rasmlari, CSS stillari va brauzer JavaScript fayllarini foydalanuvchilarga to'g'ridan-to'g'ri ko'rsatish uchun Express da express.static ishlatiladi.

Template Engine (EJS, Pug)

Template Engine — server tomonida dinamik HTML sahifalar hosil qilib, foydalanuvchiga yuborish vositasi. Eng ommabop shablonlashtiruvchi — EJS (Embedded JavaScript).

  • O'rnatish: npm install ejs.
  • Sozlash: app.set('view engine', 'ejs');.
  • Dinamik o'zgaruvchilarni chiqarish: <%= ism %>.
  • Shartlar va tsikllar: <% if (...) { %>.
  • Sahifani yuborish: res.render('index', { ism: 'Ali' }).
Node.js Server Kodi 
// Express sozlamasi
const express = require('express');
const app = express();

app.set('view engine', 'ejs');

app.get('/profil', (req, res) => {
  // views/profil.ejs fayliga ma'lumot uzatish
  const foydalanuvchi = { ism: "Bobur", ball: 95 };
  console.log("EJS shabloni ma'lumotlar bilan render bo'ldi!");
});

console.log("EJS Template Engine muvaffaqiyatli ulandi!");
🖥️ Server Terminal Natijasi:
📌 <%= %> xavfsiz matn chiqaradi, <%- %> esa xom HTML kodini chiqaradi.

REST API Node.js Mavzu #16

REST API Asoslari va Arxitekturasi

REST (Representational State Transfer) — mijoz (Frontend) va server (Backend) o'rtasida ma'lumot almashishning eng mashhur xalqaro arxitektura qoidalari to'plami. U odatda JSON formatida ishlaydi.

  • Resurslar ot so'zlar bilan nomlanadi (masalan, /api/users, fe'llar ishlatilmaydi).
  • Stateless (Holatsiz): har bir so'rov o'zida to'liq ma'lumotni saqlashi kerak.
  • Standart HTTP status kodlari: 200 (OK), 201 (Yaratildi), 400 (Noto'g'ri so'rov), 404 (Topilmadi), 500 (Server xatosi).
  • CRUD amallari HTTP metodlari bilan to'liq mos keladi.

// REST API standart yo'llari:

// PUT    /api/kitoblar/:id   -> Kitobni to'liq yangilash
// DELETE /api/kitoblar/:id   -> Kitobni o'chirish

REST API Node.js Mavzu #17

GET va POST So'rovlarini Yaratish

GET ma'lumotlarni serverdan o'qib olish, POST esa yangi ma'lumotni serverga yuborib, bazaga qo'shish uchun ishlatiladi.

  • GET so'rovlarida ma'lumotlar URL manzilda ketadi (hech qachon parol yuborilmaydi!).
  • POST so'rovlarida ma'lumotlar req.body ichida xavfsiz tarzda uzatiladi.
  • Yangi ma'lumot yaratilganda res.status(201) qaytarish standart hisoblanadi.
  • app.use(express.json()) bo'lmasa, req.body qiymati undefined bo'lib qoladi.
Node.js Server Kodi 
const express = require('express');
const app = express();
app.use(express.json());

let darslar = [{ id: 1, nom: "Node.js" }];

// GET - Olish
app.get('/api/darslar', (req, res) => {
  res.status(200).json(darslar);
});

// POST - Qo'shish
app.post('/api/darslar', (req, res) => {

PUT, PATCH va DELETE So'rovlari

Mavjud ma'lumotni o'zgartirish uchun PUT (to'liq yangilash) yoki PATCH (qisman yangilash), o'chirish uchun esa DELETE metodlari xizmat qiladi.

  • PUT: resursning barcha maydonlarini yangilaydi.
  • PATCH: faqat o'zgargan maydonni (masalan, faqat narxini) yangilaydi.
  • DELETE: ko'rsatilgan ID dagi elementni bazadan o'chiradi.
  • Muvaffaqiyatli o'chirilgach res.json({ xabar: "O'chirildi" }) qaytariladi.
Node.js Server Kodi 
const express = require('express');
const app = express();
app.use(express.json());

let kitoblar = [{ id: 1, nom: "O'tkan Kunlar", narx: 40000 }];

// PATCH - narxini yangilash
app.patch('/api/kitoblar/:id', (req, res) => {
  const id = parseInt(req.params.id);
  const kitob = kitoblar.find(k => k.id === id);
  if (!kitob) return res.status(404).json({ xato: "Kitob topilmadi" });
  
  if (req.body.narx) kitob.narx = req.body.narx;
  res.json({ status: "Yangilandi", kitob });
});

// DELETE - o'chirish
app.delete('/api/kitoblar/:id', (req, res) => {
  const id = parseInt(req.params.id);
  kitoblar = kitoblar.filter(k => k.id !== id);
  res.json({ xabar: "Kitob muvaffaqiyatli o'chirildi" });
});

console.log("PUT, PATCH va DELETE amallari sozlandi!");
🖥️ Server Terminal Natijasi:
💡 Amalda butunlay o'chirib tashlash o'rniga, bazada isDeleted: true belgisini qo'yish (Soft Delete) keng qo'llaniladi.

JWT (JSON Web Token) Autentifikatsiya

JWT — foydalanuvchi tizimga kirganini tasdiqlovchi shifrlangan raqamli kalit (token). Zamonaviy SPA (React, Vue) va mobil ilovalarda sessiya o'rniga aynan JWT ishlatiladi.

  • O'rnatish: npm install jsonwebtoken.
  • Uch qismdan iborat: Header, Payload (ma'lumot), Signature (imzo).
  • Token yaratish: jwt.sign({ userId }, maxfiyKalit, { expiresIn: '1d' }).
  • Tokenni tekshirish: jwt.verify(token, maxfiyKalit).
Node.js Server Kodi 
const jwt = require('jsonwebtoken');
const MAXFIY_KALIT = "mening_o'ta_maxfiy_kalitim_2026";

// 1. Foydalanuvchiga token berish
const token = jwt.sign(
  { id: 101, username: "ali_developer", rol: "admin" },
  MAXFIY_KALIT,
  { expiresIn: '2h' } // 2 soat amal qiladi
);

console.log("Yaratilgan JWT token:\n", token.substring(0, 45) + "...");

// 2. Tokenni tekshirish
try {
  const ochilgan = jwt.verify(token, MAXFIY_KALIT);
  console.log("Token tasdiqlandi! Foydalanuvchi:", ochilgan.username);
} catch (err) {
  console.log("Token yaroqsiz!");
}

Foydalanuvchilarning parollarini ma'lumotlar bazasida ochiq (matn) holida saqlash qat'iyan man etiladi! Buning uchun bcrypt orqali qaytarib bo'lmas shifrlash (Hashing va Salt) qo'llaniladi.
