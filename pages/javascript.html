Asosiy JS Mavzu #1

JavaScript Nima?

JavaScript — dunyodagi eng ommabop va dinamik dasturlash tili. U veb-sahifalarga 'jon' kiritadi: tugmalarni bosganda ishlaydigan qilish, animatsiyalar, server bilan ma'lumot almashish (AJAX), o'yinlar va to'liq interaktiv ilovalar yaratish imkonini beradi.

  • HTML — saytning skeleti, CSS — uning tashqi kiyimi, JavaScript esa uning miyasi va harakatlaridir.
  • Brauzerlar ichida (Chrome V8 dvigateli) to'g'ridan-to'g'ri hech qanday qo'shimcha o'rnatishlarsiz ishlaydi.
  • Bugungi kunda Node.js orqali nafaqat brauzerda, balki kuchli Backend serverlarda ham ishlatiladi.

Integratsiya JS Mavzu #2

JavaScriptni HTMLga Qo'shish Usullari

JavaScript kodini sahifaga ulashning 3 xil usuli mavjud: Ichki (Internal), Tashqi (External) va Qator ichi (Inline).

  • Tashqi (External - Eng yaxshi usul): <script src="app.js"></script> — odatda </body> yopilishidan oldin qo'yiladi.
  • Ichki (Internal): <script> // JS kod </script> teglari orasida yoziladi.
  • Inline: HTML tegi ichida onclick="alert('Salom')" kabi hodisalar orqali chaqiriladi.
JavaScript & HTML Live Run 
<!-- Tashqi va ichki skript namunasi -->
<script>
  function salomBer() {
    alert('Salom! Bu ichki script orqali ishga tushdi.');
  }
</script>
<button onclick="salomBer()" style="background:#3b82f6; color:white; border:none; padding:8px 14px; border-radius:4px; cursor:pointer;">
  Skriptni Ishlatish
</button>
📺 Jonli Natija:
⚡ Nega <script> faylini sahifa oxiriga qo'yishadi? Chunki brauzer avval barcha HTML elementlarni yuklab oladi, shundan so'ng JS ularni bemalol topa oladi.

Asoslar JS Mavzu #4

O'zgaruvchilar: var / let / const

O'zgaruvchi — bu kompyuter xotirasidagi ma'lumotlarni saqlash uchun mo'ljallangan maxsus 'quti' dir.

  • const: (Konstanta) — qiymati keyinchalik O'ZGARMAS o'zgaruvchilar uchun. Har doim dastlab const ishlatish tavsiya qilinadi.
  • let: qiymati keyin o'zgarishi mumkin bo'lgan o'zgaruvchilar uchun (masalan: hisoblagich, ball).
  • var: eski uslub (ES6 dan oldingi). Funksiya doirasiga (function-scoped) ega va zamonaviy kodda ishlatilmaydi.
JavaScript & HTML Live Run

  const saytNomi = "W3Learn";

  foydalanuvchiBall = foydalanuvchiBall + 25; // O'zgardi: 125
</script>

Ma'lumotlar JS Mavzu #5

Ma'lumot Turlari (Data Types)

JavaScriptda barcha ma'lumotlar ikkita katta toifaga bo'linadi: Primitive (Oddiy) va Non-primitive / Reference (Murakkab).

  • String: matnli ma'lumotlar: 'Salom' yoki "Dunyo".
  • Number: butun va kasr sonlar: 42, 3.14.
  • Boolean: mantiqiy qiymat: faqat true (rost) yoki false (yolg'on).
  • Undefined: e'lon qilingan lekin qiymati berilmagan o'zgaruvchi.
  • Null: qasddan bo'sh qoldirilgan qiymat.
  • Object: murakkab ma'lumot tuzilmalari (massivlar, obyektlar, funksiyalar).

Xususiyatlar JS Mavzu #6

Type Coercion (Turlarni O'zgartirish)

JavaScript zaif tiplangan (dynamically typed) til bo'lib, ba'zida turlarni avtomatik tarzda o'zi o'zgartirib yuboradi.

  • '5' + 2 = '52' — qo'shishda matn ko'rinsa, son ham matnga aylanib ulanadi (konkatenatsiya).
  • '5' - 2 = 3 — ayirish, ko'paytirish va bo'lishda esa matn songa aylanadi!
  • Qo'lda aniq o'zgartirish: Number('100'), String(50), Boolean(1).

Mantiq JS Mavzu #7

JavaScript Operatorlari

Qiymatlar ustida matematik amallar bajarish va ularni taqqoslash vositalari.

  • Arifmetik: +, -, *, /, % (qoldiqli bo'lish), ** (darajaga ko'tarish).
  • Taqqoslovchi: == (faqat qiymat), === (qat'iy: ham qiymat, ham turini tekshiradi).
  • Mantiqiy: && (VA - ikkalasi ham rost bo'lishi shart), || (YOKI - bittasi rost bo'lsa yetarli), ! (INKOR).
JavaScript & HTML Live Run

  // 5 == '5' -> true (chunki turlar tenglashtiriladi)
  // 5 === '5' -> false (chunki biri son, biri matn!)
</script>

Mantiq JS Mavzu #8

Shartli Operatorlar: if / else

Dasturda ma'lum bir shart bajarilgandagina ma'lum bir kod qismini ishga tushirish qarorlarini qabul qiladi.

  • if (shart) { ... } — shart rost (true) bo'lsa ishlaydi.
  • else if (yangi_shart) { ... } — birinchi shart xato bo'lsa, ikkinchisini tekshiradi.
  • else { ... } — hech qaysi shart bajarilmaganda ishlaydigan zaxira qism.
  • Ternary Operator (Qisqa if): shart ? rost : yolg'on.

Mantiq JS Mavzu #9

Switch / Case Operatori

Bitta o'zgaruvchining qiymatini ko'p sonli variantlar (keyslar) bilan taqqoslash kerak bo'lganda switch dan foydalanish if/else dan ko'ra ancha tartibli bo'ladi.

  • case qiymat: — mos keladigan holat.
  • break; — tekshirishni to'xtatib switch blokidan chiqish (agar qo'yilmasa, keyingi barcha keyslar ham ishlab ketadi).
  • default: — hech qaysi variant mos kelmasa ishlaydigan standart blok.
JavaScript & HTML Live Run 
<script>
  const haftaKuni = 1;
  let kunNomi;
  switch (haftaKuni) {
    case 1: kunNomi = 'Dushanba'; break;
    case 2: kunNomi = 'Seshanba'; break;
    default: kunNomi = 'Boshqa kun';
  }
</script>
<p style="color:#04AA6D; font-weight:bold;">Switch ko'p variantli menyularda juda qulay.</p>
📺 Jonli Natija:
⚠️ Har bir case oxiriga break; qo'yishni unutmang, aks holda dastur boshqa keyslarga ham o'tib ketadi.

Tsikllar JS Mavzu #10

For Tsikli (Sikllar)

Bir xil amalni ma'lum bir sondagi marta takror va takror bajarish uchun tsikllar ishlatiladi.

  • for (boshlanish; shart; qadam) { ... }
  • Massivlar bilan ishlash uchun: for...of (qiymatlar bo'yicha).
  • Obyektlar bilan ishlash uchun: for...in (kalitlar bo'yicha).

Tsikllar JS Mavzu #11

While va Do...While Tsikllari

Qadamlar soni oldindan noma'lum bo'lib, ma'lum bir shart qanoatlantirilguncha aylanishi kerak bo'lgan holatlarda ishlatiladi.

  • while (shart) — avval shartni tekshiradi, keyin kodni ishlatadi.
  • do { ... } while (shart) — kamida 1 marta kodni albatta ishga tushiradi, keyin shartni tekshiradi.
JavaScript & HTML Live Run

    console.log('While aylanmoqda: ' + hisob);

Tsikllar JS Mavzu #12

Break va Continue Operatorlari

Sikllarning ishlash jarayonini nazorat qilish va ularni muddatidan oldin to'xtatish yoki ma'lum bir qadamni tashlab ketish imkoniyati.

  • break: tsiklni butunlay to'xtatadi va undan chiqib ketadi.
  • continue: joriy qadamni shu joyida tashlab o'tib, darhol keyingi qadamga sakraydi.
JavaScript & HTML Live Run 
<script>
  // 3-raqamni tashlab ketadi, 7-raqamda butunlay to'xtaydi
  for (let i = 1; i <= 10; i++) {
    if (i === 3) continue;
    if (i === 7) break;
    // console.log(i); // 1, 2, 4, 5, 6
  }
</script>
<p style="color:#38bdf8;">break qidiruv natijasi topilganda siklni behuda davom ettirmaslik uchun ideal.</p>
📺 Jonli Natija:
⚡ Ro'yxatdan kerakli element topilgan zahoti break qilsangiz, kompyuter xotirasi va vaqti tejaladi.

Arxitektura JS Mavzu #16

Scope (Ko'rinish Sohasi)

Scope o'zgaruvchining kodning qaysi qismida ko'rinishi va undan foydalanish mumkinligini belgilaydi.

  • Global Scope: har qanday funksiyadan tashqarida e'lon qilingan o'zgaruvchi. Butun dastur bo'ylab ko'rinadi.
  • Function Scope: faqat o'sha funksiya ichida mavjud bo'lgan o'zgaruvchi.
  • Block Scope: jingalak qavslar {} ichidagi o'zgaruvchi (faqat let va const uchun amal qiladi).
JavaScript & HTML Live Run 
<script>
  let global = 'Men hamma joyda ko'rinaman';

    let lokal = 'Men faqat funksiya ichidaman';
  }
</script>
<p style="color:#cbd5e1;">Global o'zgaruvchilarni iloji boricha kamroq ishlatish yaxshi odatdir.</p>

🔒 let va const blok sohasiga ega, eski var esa blokdan tashqariga chiqib ketishi mumkin.

Ilg'or JS Mavzu #17

Closure (Yopiq Muhit)

Closure — bu ichki funksiyaning o'zini o'rab turgan tashqi funksiyaning o'zgaruvchilarini hatto tashqi funksiya ishlab bo'lganidan keyin ham eslab qolish qobiliyatidir.

  • Ma'lumotlarni yopiq (private) saqlash va inkapsulyatsiya qilish uchun ishlatiladi.
  • Hisoblagichlar (counter), zavod funksiyalari aynan closure ustiga quriladi.
JavaScript & HTML Live Run 
<script>
  function hisoblagichYarat() {
    let son = 0;
    return function() {
      son++;
      return son;
    };
  }
  const hisobla = hisoblagichYarat();
</script>
<button onclick="alert('Joriy son: ' + hisobla())" style="background:#04AA6D; color:white; border:none; padding:8px 14px; border-radius:4px; cursor:pointer;">
  Closure Hisoblagichni Bosish
</button>

Massivlar JS Mavzu #19

Massivlar (Arrays) Asoslari

Massiv — bu bir nechta qiymatlarni bitta o'zgaruvchi ichida tartiblangan ro'yxat ko'rinishida saqlash vositasidir.

  • Massivlar to'rtburchak qavsda yoziladi: const mevalar = ['Olma', 'Anor', 'Boran'];

Modullar JS Mavzu #40

ES6 Modullar (import va export)

Katta dasturlarni bitta ulkan faylda emas, kichik-kichik mustaqil fayllarga (modullarga) bo'lib dasturlash usuli.

  • export const funksiya = ... — fayldan tashqariga chiqarish.
  • import { funksiya } from './fayl.js' — boshqa fayldan chaqirib olish.
  • HTML da ulash uchun: <script type="module" src="app.js"></script>.

  // hisob.js faylida:<br>
  export const qosh = (a, b) => a + b;<br><br>
  // main.js?v=20261123_5 faylida:<br>
  import { qosh } from './hisob.js';

ES2020 JS Mavzu #41

Optional Chaining (?.)

Chuqur ichma-ich joylashgan ob'ekt xususiyatlarini xavfsiz o'qish imkoniyati (xato berib dastur to'xtab qolmaydi).

  • Agar qidirilayotgan xususiyat mavjud bo'lmasa, dastur 'Cannot read property of undefined' xatosi bermaydi, balki undefined qaytaradi.
  • Sintaksis: user?.address?.city.
  • Funksiyalarni tekshirishda ham ishlaydi: myFunc?.().
JavaScript & HTML Live Run 
<script>
  const profile = { ism: 'Temur' };
  // Xavfsiz o'qish:
  const shahar = profile?.manzil?.shahar; // undefined qaytadi, xato bo'lmaydi!
</script>

ES2020 JS Mavzu #42

Nullish Coalescing (??)

Faqatgina qiymat null yoki undefined bo'lgandagina zaxira (standart) qiymatni qabul qiluvchi mantiqiy operator.

  • Eski || operatoridan farqi: 0, false yoki bo'sh matn "" larni qonuniy qiymat deb biladi va ularni o'chirmaydi.
  • Masalan: const ball = userBall ?? 50; (agar userBall 0 bo'lsa, 0 qoladi, 50 bo'lib ketmaydi!).
JavaScript & HTML Live Run 
<script>
  let tezlik = 0;
  let natijaOR = tezlik || 60; // 60 bo'ladi (noto'g'ri!)
  let natijaNullish = tezlik ?? 60; // 0 bo'ladi (to'g'ri!)
</script>
<p style="color:#04AA6D; font-family:monospace;">0 ?? 100 = 0 | null ?? 100 = 100</p>
📺 Jonli Natija:
💡 Sozlamalar va hisoblagichlarda 0 yoki bo'sh matnni haqiqiy qiymat sifatida saqlab qolish uchun har doim ?? dan foydalaning.
