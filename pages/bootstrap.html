Asosiy Bootstrap Mavzu #1

Bootstrap 5 Nima?

Bootstrap 5 — Twitter (hozir Meta) tomonidan yaratilgan, dunyodagi eng mashhur CSS framework. U tayyor klasslar va komponentlar yordamida tez, chiroyli va barcha qurilmalarga moslashadigan (responsive) veb-saytlar yaratish imkonini beradi.

  • jQuery ga bog'liq emas — sof JavaScript da ishlaydi.
  • 12 ustunli Grid tizimi orqali har qanday tartibni (layout) qulay yaratish mumkin.
  • Tugmalar, kartalar, formalar, modallar kabi 20+ tayyor komponent mavjud.
  • Utility klasslar (m-3, p-2, text-center) yordamida CSS yozmasdan dizayn qilish mumkin.
HTML (Bootstrap 5) 
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
<div class="container mt-3">
  <div class="alert alert-success">
    <h4 class="alert-heading">Tabriklaymiz!</h4>
    <p>Siz Bootstrap 5 o'rganishni boshladingiz. Bu framework yordamida professional saytlar yaratishingiz mumkin.</p>
  </div>
  <button class="btn btn-primary me-2">Primary</button>
  <button class="btn btn-success me-2">Success</button>
  <button class="btn btn-danger">Danger</button>
</div>
📺 Jonli Natija:
💡 Bootstrap 5 jQuery ni talab qilmaydi — bu avvalgi versiyalardan eng katta farqi.

O'rnatish Bootstrap Mavzu #2

CDN va NPM orqali O'rnatish

Bootstrap ni loyihaga qo'shishning ikki asosiy usuli mavjud: CDN (Content Delivery Network) orqali tashqi havola sifatida ulash yoki NPM orqali mahalliy o'rnatish. CDN usuli eng tez va sodda — faqat bitta link tegi kifoya.

  • CDN orqali: <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
  • NPM orqali: npm install bootstrap buyrug'i bilan o'rnatiladi.
  • JS komponentlar (Modal, Dropdown) uchun JS bundle ham kerak: bootstrap.bundle.min.js
  • Offline ishlash kerak bo'lsa NPM, tez boshlash uchun CDN tavsiya etiladi.
HTML (Bootstrap 5) 
<!-- CDN orqali Bootstrap ulash -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js"></script>

<div class="container mt-3">
  <h3>Bootstrap muvaffaqiyatli ulandi! ✅</h3>
  <p class="text-muted">Endi barcha Bootstrap klasslaridan foydalanishingiz mumkin.</p>
  <span class="badge bg-success">CDN</span>
  <span class="badge bg-info">v5.3.0</span>
</div>
📺 Jonli Natija:
⚡ CDN fayllar butun dunyo serverlarida keshlanadi, shuning uchun sahifangiz tezroq yuklanadi.

Responsive Bootstrap Mavzu #3

Breakpoints (Ekran O'lchamlari)

Bootstrap ning responsive (moslashuvchan) tizimi breakpoints ga asoslangan. Breakpoint — bu ekran kengligi o'zgarganida dizaynni moslashtirish uchun belgilangan chegara nuqtalar.

  • xs: 0-575px (telefon)
  • sm: ≥576px (katta telefon)
  • md: ≥768px (planshet)
  • lg: ≥992px (noutbuk)
  • xl: ≥1200px, xxl: ≥1400px (katta ekranlar)
HTML (Bootstrap 5) 
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
<div class="container mt-3">
  <h5>Ekran o'lchamiga qarab rang o'zgaradi:</h5>
  <div class="d-block d-sm-none bg-danger text-white p-3 rounded">📱 XS — Telefon (< 576px)</div>
  <div class="d-none d-sm-block d-md-none bg-warning text-dark p-3 rounded">📱 SM — Katta telefon</div>
  <div class="d-none d-md-block d-lg-none bg-info text-white p-3 rounded">📲 MD — Planshet</div>
  <div class="d-none d-lg-block bg-success text-white p-3 rounded">💻 LG+ — Noutbuk/Desktop</div>
</div>
📺 Jonli Natija:
📌 Breakpointlar Mobile-First tamoyiliga asoslangan — avval kichik ekran uchun yoziladi, keyin kattaroqlarga moslashtiriladi.

Layout Bootstrap Mavzu #4

Container (Konteyner)

Container — Bootstrap ning asosiy o'rash (wrapper) elementi. U ichidagi kontentni markazlashtiradi va ikki chetdan padding qo'yadi. Uch xil container mavjud: .container, .container-fluid va .container-{breakpoint}.

  • .container — har bir breakpointda belgilangan max-width ga ega.
  • .container-fluid — har doim ekranning 100% kengligini egallaydi.
  • .container-md — faqat md breakpointdan boshlab chegaralanadi.
  • Grid tizimi albatta container ichida bo'lishi kerak.
HTML (Bootstrap 5) 
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
<div class="container bg-light p-3 mb-2 border rounded">
  <strong>.container</strong> — Markazlashtirilgan, max-width chegarali
</div>
<div class="container-fluid bg-info text-white p-3 rounded">
  <strong>.container-fluid</strong> — 100% kenglik, to'liq ekran
</div>
📺 Jonli Natija:
💡 Deyarli har bir Bootstrap sahifa .container ichida boshlanadi.

Layout Bootstrap Mavzu #5

Grid Tizimi (12 Ustunli)

Bootstrap ning Grid tizimi Flexbox ga asoslangan bo'lib, sahifani 12 ta teng ustunga bo'ladi. .row qator, .col-* esa ustunlarni belgilaydi. Bu tizim responsive saytlar yaratishning eng muhim asosi.

  • Jami 12 ustun — ularni istalgancha birlashtirishingiz mumkin (col-6 + col-6 = 12).
  • .col — teng kenglikda, .col-auto — kontent kengligida.
  • Breakpointlar bilan: .col-md-4 (planshetda 4 ustun, telefonda 12).
  • Ichma-ich (nested) gridlar ham qo'llab-quvvatlanadi.
HTML (Bootstrap 5) 
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
<div class="container mt-3">
  <div class="row mb-2">
    <div class="col-4 bg-primary text-white p-3 border">col-4</div>
    <div class="col-4 bg-success text-white p-3 border">col-4</div>
    <div class="col-4 bg-danger text-white p-3 border">col-4</div>
  </div>
  <div class="row mb-2">
    <div class="col-md-8 bg-info text-white p-3 border">col-md-8</div>
    <div class="col-md-4 bg-warning text-dark p-3 border">col-md-4</div>
  </div>
  <div class="row">
    <div class="col bg-secondary text-white p-3 border">col (teng)</div>
    <div class="col bg-dark text-white p-3 border">col (teng)</div>
    <div class="col bg-secondary text-white p-3 border">col (teng)</div>
  </div>
</div>
📺 Jonli Natija:
📌 Grid tizimida 12 dan ortiq ustun bir qatorda bo'lsa, ortiqchasi avtomatik keyingi qatorga tushadi.

Layout Bootstrap Mavzu #6

Ustunlar (Columns)

Ustunlar Grid tizimining asosiy qurilish bloklari. .col-{breakpoint}-{size} sintaksisi orqali har bir ekran o'lchamida ustunning kengligini alohida boshqarishingiz mumkin.

  • .col-12 — to'liq kenglik (telefonda).
  • .col-md-6 — planshetda yarim kenglik.
  • .col-lg-3 — desktopda chorak kenglik.
  • Offset: .offset-md-3 — ustunni o'ngga surish.

<div class="container mt-3">
  <h6>Responsive ustunlar:</h6>
  <div class="row g-2">
    <div class="col-12 col-md-6 col-lg-3"><div class="bg-primary text-white p-3 rounded text-center">1</div></div>
    <div class="col-12 col-md-6 col-lg-3"><div class="bg-success text-white p-3 rounded text-center">2</div></div>
    <div class="col-12 col-md-6 col-lg-3"><div class="bg-info text-white p-3 rounded text-center">3</div></div>
    <div class="col-12 col-md-6 col-lg-3"><div class="bg-warning text-dark p-3 rounded text-center">4</div></div>
  </div>
</div>
📺 Jonli Natija:
💡 Ekran o'lchamini o'zgartirib ko'ring — ustunlar avtomatik moslashadi!

Layout Bootstrap Mavzu #7

Gutters (Ustunlar Orasidagi Bo'shliq)

Gutters — ustunlar orasidagi gorizontal va vertikal bo'shliqlardir. Bootstrap 5 da .g-*, .gx-* (gorizontal) va .gy-* (vertikal) klasslari mavjud.

  • .g-0 — bo'shliqsiz, .g-5 — eng katta bo'shliq.
  • .gx-3 — faqat gorizontal, .gy-3 — faqat vertikal.
  • Row ga qo'shiladi: <div class="row g-3">
  • Bo'shliqni olib tashlash: .g-0
HTML (Bootstrap 5) 
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
<div class="container mt-3">
  <h6>g-4 (katta bo'shliq):</h6>
  <div class="row g-4 mb-3">
    <div class="col-6"><div class="bg-primary text-white p-3 rounded">A</div></div>
    <div class="col-6"><div class="bg-success text-white p-3 rounded">B</div></div>
    <div class="col-6"><div class="bg-info text-white p-3 rounded">C</div></div>
    <div class="col-6"><div class="bg-warning text-dark p-3 rounded">D</div></div>
  </div>
</div>
📺 Jonli Natija:
📌 Gutters responsive ham bo'lishi mumkin: .g-md-4 — faqat planshetdan boshlab.

Mazmun Bootstrap Mavzu #8

Typography (Matn Stillari)

Bootstrap Typography klasslari matnni formatlash uchun tayyor stillar beradi: sarlavhalar, paragraflar, blockquote, ro'yxatlar va boshqa matn elementlari uchun.

  • .h1 — .h6 klasslari istalgan tegga sarlavha stili beradi.
  • .display-1 — .display-6 — katta dekorativ sarlavhalar.
  • .lead — paragrafni kattaroq va yengil ko'rsatadi.
  • .text-muted, .text-primary — matn ranglari.
HTML (Bootstrap 5) 
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
<div class="container mt-3">
  <h1 class="display-4">Display Sarlavha</h1>
  <p class="lead">Bu "lead" paragraf — kattaroq va yengil ko'rinishda.</p>
  <p class="text-muted">Bu xira matn (text-muted).</p>
  <p class="text-primary fw-bold">Birlamchi rang, qalin (fw-bold).</p>
  <blockquote class="blockquote border-start border-success border-4 ps-3">
    <p>"Oddiy yaxshi, murakkab yomondan yaxshi."</p>
    <footer class="blockquote-footer">Python falsafasi</footer>
  </blockquote>
</div>
📺 Jonli Natija:
💡 .fw-bold, .fst-italic, .text-decoration-underline — matn formatlash klasslari.

Mazmun Bootstrap Mavzu #9

Rasmlar (Images)

Bootstrap rasm klasslari rasmlarni responsive, yumaloq yoki chegara bilan chiroyli ko'rsatish imkonini beradi.

  • .img-fluid — rasm konteyner kengligiga moslashadi (responsive).
  • .rounded — yumaloq burchaklar.
  • .rounded-circle — to'liq doira shakli (avatar uchun).
  • .img-thumbnail — chegara va padding bilan.

      <div style="width:80px;height:80px;background:#E91E63;color:#fff;display:flex;align-items:center;justify-content:center;margin:auto" class="img-thumbnail">thumb</div>

Mazmun Bootstrap Mavzu #10

Jadvallar (Tables)

Bootstrap jadval klasslar oddiy HTML <table> ni chiroyli va o'qilishi oson ko'rinishga keltiradi. Qoramtir, chiziqli, hover effektli va responsive jadvallar yaratish mumkin.

  • .table — asosiy jadval stili.
  • .table-striped — qator almashlab rang.
  • .table-hover — sichqoncha ustiga kelganda qator ajralib turadi.
  • .table-responsive — kichik ekranlarda gorizontal skroll.

Mazmun Bootstrap Mavzu #11

Figures (Rasm + Izoh)

<figure> elementi rasm bilan uning tagidagi izohni (caption) birlashtiradi. Bootstrap .figure klassi bu juftlikni chiroyli formatlaydi.

  • .figure — asosiy wrapper.
  • .figure-img — rasm uchun.
  • .figure-caption — pastdagi izoh uchun.
  • Rasm va izoh semantik jihatdan bog'langan bo'ladi.
HTML (Bootstrap 5) 
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
<div class="container mt-3">
  <figure class="figure">
    <div class="figure-img img-fluid rounded" style="width:200px;height:120px;background:linear-gradient(135deg,#04AA6D,#2196F3);display:flex;align-items:center;justify-content:center;color:#fff;font-size:24px;">📸</div>
    <figcaption class="figure-caption text-center mt-2">Bootstrap 5 bilan chiroyli saytlar yarating</figcaption>
  </figure>
</div>
📺 Jonli Natija:
📌 .figure-caption ga .text-end qo'shib izohni o'ngga surish mumkin.

Komponent Bootstrap Mavzu #12

Alerts (Bildirishnomalar)

Alerts — foydalanuvchiga muhim xabar (muvaffaqiyat, xato, ogohlantirish) ko'rsatish uchun ishlatiladigan komponent. Yopish tugmasi bilan ham ishlaydi.

  • 8 xil rang: success, danger, warning, info, primary, secondary, light, dark.
  • .alert-dismissible + yopish tugmasi bilan foydalanuvchi yopishi mumkin.
  • .alert-heading — alert ichidagi sarlavha.
  • Ichida havolalar: .alert-link — rangga mos havola.
HTML (Bootstrap 5) 
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js"></script>
<div class="container mt-3">
  <div class="alert alert-success"><strong>✅ Muvaffaqiyat!</strong> Ma'lumot saqlandi.</div>
  <div class="alert alert-danger"><strong>❌ Xato!</strong> Parol noto'g'ri.</div>
  <div class="alert alert-warning alert-dismissible fade show">
    <strong>⚠️ Diqqat!</strong> Sessiya tugayapti.
    <button type="button" class="btn-close" data-bs-dismiss="alert"></button>
  </div>
  <div class="alert alert-info"><strong>ℹ️ Ma'lumot:</strong> Yangi versiya chiqdi. <a href="#" class="alert-link">Yangilash</a></div>
</div>
📺 Jonli Natija:
💡 .fade .show klasslari qo'shilsa, alert yopilganda silliq animatsiya bilan yo'qoladi.

Komponent Bootstrap Mavzu #15

Cards (Kartalar)

Card — kontent bloklarini chiroyli ko'rsatish uchun universal komponent. Rasm, sarlavha, matn, tugma va boshqalarni o'z ichiga oladi. Blog postlari, mahsulotlar, profil kartalari uchun ideal.

  • .card-body — asosiy kontent qismi.
  • .card-header va .card-footer — yuqori va pastki qism.
  • .card-img-top — rasm yuqorida.
  • Grid bilan birgalikda: kartalar to'plami yaratish.
HTML (Bootstrap 5) 
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
<div class="container mt-3">
  <div class="row g-3">
    <div class="col-md-4">
      <div class="card h-100">
        <div class="card-body">
          <h5 class="card-title">🌐 HTML</h5>
          <p class="card-text">Veb sahifalar tuzilishini yarating.</p>
          <a href="#" class="btn btn-success btn-sm">O'rganish</a>
        </div>
      </div>
    </div>
    <div class="col-md-4">
      <div class="card h-100 border-primary">

Flexbox Utilities

Bootstrap Flex utility klasslari CSS Flexbox ni klasslar orqali boshqarish imkonini beradi. Elementlarni tartibga solish, joylash va hizalash osonlashadi.

  • .d-flex — flex konteyner yaratish.
  • .justify-content-center/between/around — gorizontal joylash.
  • .align-items-center/start/end — vertikal hizalash.
  • .flex-column — vertikal tartib.
  • .flex-wrap — elementlar kerakli joyda o'raladi.
HTML (Bootstrap 5) 
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
<div class="container mt-3">
  <h6>justify-content-between:</h6>
  <div class="d-flex justify-content-between bg-light p-2 mb-3 rounded">
    <div class="bg-primary text-white p-2 rounded">Chap</div>
    <div class="bg-success text-white p-2 rounded">O'rta</div>
    <div class="bg-danger text-white p-2 rounded">O'ng</div>
  </div>
  <h6>align-items-center (balandlik: 100px):</h6>
  <div class="d-flex align-items-center bg-dark p-2 rounded" style="height:100px">
    <div class="bg-warning p-2 rounded me-2">A</div>
    <div class="bg-info text-white p-2 rounded me-2">B</div>
    <div class="bg-success text-white p-2 rounded">C</div>
  </div>
</div>

Utility Bootstrap Mavzu #31

Text Utilities (Matn Boshqaruvi)

Text utility klasslari matn hizalash, hajm, qalinlik, bosh harf va boshqa ko'rinishlarni CSS yozmasdan boshqaradi.

  • .text-center, .text-start, .text-end — hizalash.
  • .fw-bold, .fw-light — qalinlik.
  • .fst-italic — kursiv.
  • .text-uppercase, .text-lowercase, .text-capitalize.
  • .text-truncate — uzun matnni qisqartiradi (...).
  • .fs-1 — .fs-6 — matn hajmi.
HTML (Bootstrap 5) 
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
<div class="container mt-3">
  <p class="text-center bg-light p-2 rounded">text-center — Markazda</p>
  <p class="fw-bold">fw-bold — Qalin matn</p>
  <p class="fst-italic text-muted">fst-italic — Kursiv va xira</p>
  <p class="text-uppercase text-primary">text-uppercase — KATTA HARFLAR</p>
  <p class="text-capitalize">text-capitalize — Har So'z Bosh Harfdan</p>
  <p class="text-truncate" style="max-width:250px">text-truncate — Bu juda uzun matn bo'lib, qolgan qismi uch nuqta bilan kesiladi...</p>
  <p class="fs-3 text-success">fs-3 — Katta shrift</p>
</div>
