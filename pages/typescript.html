Asosiy TS Mavzu #1

TypeScript Nima?

TypeScript — bu Microsoft tomonidan ishlab chiqilgan va JavaScript ustiga qurilgan ochiq kodli dasturlash tili. U JavaScriptga statik tiplash (Static Typing) imkoniyatini qo'shadi.

  • TypeScript — bu JavaScriptning kengaytmasi (Superset of JS). Har qanday to'g'ri JavaScript kodi avtomatik TypeScript kodi ham hisoblanadi.
  • Koddagi xatolarni dastur ishga tushmasidan oldin (kompilyatsiya bosqichida) aniqlaydi.
  • Katta jamoaviy va korporativ loyihalarda kod xavfsizligi va qulayligini ta'minlaydi.
TypeScript Kodi 
// TypeScript kodi namunasi
let ism: string = "Anvar";
let yosh: number = 24;
let dasturchimi: boolean = true;

console.log(`Dasturchi: ${ism}, Yoshi: ${yosh}`);
📺 Natija:
💡 Brauzerlar TypeScriptni to'g'ridan-to'g'ri tushunmaydi. TypeScript kompilyatori (tsc) uni oddiy JavaScript kodiga o'girib beradi.

O'rnatish TS Mavzu #2

O'rnatish va Sozlash

TypeScriptni kompyuterga o'rnatish uchun Node.js va npm kerak bo'ladi.

  • Global o'rnatish: npm install -g typescript.
  • Versiyani tekshirish: tsc -v.
  • TypeScript fayllarini JavaScriptga o'girish: tsc faylNomi.ts.
TypeScript Kodi 
// Terminalda bajariladigan buyruqlar:
// 1. O'rnatish:
// npm install -g typescript

// 2. index.ts faylini index.js ga kompilyatsiya qilish:
// tsc index.ts
📺 Natija:
⚡ Agar kodni har safar qo'lda kompilyatsiya qilishni xohlamasangiz, tsc -w (watch mode) buyrug'ini ishlating.

Konfiguratsiya TS Mavzu #3

tsconfig.json Fayli

Loyihada TypeScript qoidalarini, qaysi JavaScript versiyasiga o'girilishini va qat'iylik darajasini belgilovchi boshqaruv fayli.

  • Yaratish buyrug'i: tsc --init.
  • target: "ES6" — chiqadigan JS versiyasi.
  • strict: true — tiplarni maksimal darajada qat'iy tekshirish.
  • outDir: "./dist" — tayyor JS fayllar saqlanadigan papka.
TypeScript Kodi 
{
  "compilerOptions": {
    "target": "es2022",
    "module": "commonjs",
    "strict": true,
    "outDir": "./dist"
  }
}
📺 Natija:
📌 "strict": true parametri yangi loyihalarda xatolarni minimallashtirish uchun eng tavsiya etilgan qoidadir.

Tiplar TS Mavzu #4

Primitiv Tiplar (Primitive Types)

TypeScriptdagi asosiy ma'lumot turlari bo'lib, o'zgaruvchi e'lon qilinayotganda ikki nuqta (:) dan keyin ko'rsatiladi.

  • string: matnlar uchun (let til: string = 'TS';).
  • number: butun va o'nlik sonlar (let ball: number = 95.5;).
  • boolean: rost yoki yolg'on (let aktiv: boolean = true;).
TypeScript Kodi 
let kurs: string = "TypeScript Pro";
let darslarSoni: number = 28;
let bepulmi: boolean = true;

// Xato beradi:
// kurs = 123; // Error: Type 'number' is not assignable to type 'string'
📺 Natija:
⚠️ Agar noto'g'ri turdagi qiymat berilsa, TypeScript darhol qizil to'lqinli chiziq bilan xatoni ko'rsatadi.

Tiplar TS Mavzu #5

Array va Tuple (Massivlar va Kortejlar)

Massiv ichida faqat ma'lum bir turdagi ma'lumotlar saqlanishini ta'minlash.

  • Array sintaksisi: number[] yoki Array<string>.
  • Tuple (Kortej): aniq o'lchamga va aniq tartibdagi tiplarga ega maxsus massiv: [string, number].
TypeScript Kodi 
// Oddiy massiv
let baholar: number[] = [5, 4, 5, 3];

// Tuple (birinchi matn, ikkinchi son bo'lishi shart)
let foydalanuvchi: [string, number] = ["Sherzod", 27];

// foydalanuvchi = [27, "Sherzod"]; // XATO! Tartib buzildi.
📺 Natija:
💡 Tuple funksiyadan bir vaqtning o'zida ikkita har xil turdagi natija qaytarishda juda qulay (React useState aynan tuple qaytaradi).

Tiplar TS Mavzu #7

any va unknown Tiplari

Qaysi turdagi ma'lumot kelishi oldindan noma'lum bo'lgan holatlar uchun mo'ljallangan.

  • any: har qanday qiymatni qabul qiladi va TypeScript tekshiruvini butunlay o'chirib qo'yadi (tavsiya etilmaydi!).
  • unknown: xavfsiz 'any'. U bilan ishlashdan oldin uning turini aniq tekshirish (type checking) talab qilinadi.
TypeScript Kodi 
let xavfli: any = "Salom";
xavfli = 42; // Hech qanday xatolik bermaydi

let xavfsiz: unknown = "Salom Dunyo";
if (typeof xavfsiz === "string") {
  console.log(xavfsiz.toUpperCase());
}
📺 Natija:
🛑 any dan iloji boricha qoching! Kodingiz to'la 'any' bo'lsa, TypeScript ishlatishdan ma'no qolmaydi.

Tiplar TS Mavzu #8

void va never Tiplari

Funksiyalarning natija qaytarishi bilan bog'liq maxsus tiplar.

  • void: hech qanday qiymat qaytarmaydigan funksiyalar (masalan, faqat console.log qiladigan).
  • never: hech qachon normal yakunlanmaydigan funksiyalar (doimiy xato tashlovchi yoki cheksiz sikl).
TypeScript Kodi 
function logChiqar(xabar: string): void {
  console.log("Xabar:", xabar);
}

function xatoTashla(xatolik: string): never {
  throw new Error(xatolik);
}
📺 Natija:
💡 Agar funksiyangiz oxirida return bo'lmasa, uning qaytarish turi avtomatik void deb olinadi.

Tiplar TS Mavzu #9

Union Types (Birlashma Tiplar |)

O'zgaruvchi bir vaqtning o'zida bir nechta ruxsat etilgan tiplardan birini qabul qilishi mumkin bo'lgan holat.

  • Tik chiziq | belgisi orqali yoziladi.
  • Masalan: id: string | number — ID matn ham, son ham bo'lishi mumkin.
TypeScript Kodi 
function chopEt(id: number | string) {
  if (typeof id === "string") {
    console.log("Matnli ID: " + id.toUpperCase());
  } else {
    console.log("Raqamli ID: " + id.toFixed(0));
  }
}
chopEt(101);
chopEt("usr_998");
📺 Natija:
✨ Union tiplar yordamida bitta funksiyani ko'p qirrali qilish mumkin.

Tiplar TS Mavzu #10

Intersection Types (Kesishma Tiplar &)

Bir nechta har xil tiplarni bitta yangi tip ostida birlashtirish (amalgamation).

  • Ampersand & belgisi bilan belgilanadi.
  • Natijaviy obyekt har ikkala tipning barcha maydonlariga ega bo'lishi shart.
TypeScript Kodi 
type Shaxs = { ism: string };
type Aloqa = { email: string; tel: string };

type Mijoz = Shaxs & Aloqa;

const yangiMijoz: Mijoz = {
  ism: "Jamshid",
  email: "jamshid@mail.uz",
  tel: "+998901234567"
};
📺 Natija:
📌 Turli modullardan kelgan kichik tiplarni bitta katta modelga yig'ishda Intersection tengsizdir.

Interface (Interfeyslar)

interface Avtomobil {

const mashina: Avtomobil = {
  brend: "Chevrolet Tracker",

Struktura TS Mavzu #12

Type Alias (Tip Taxallusi)

Istalgan murakkab tipga o'zingiz tushunarli yangi nom (taxallus) berish imkoniyati.

  • type Nom = ... sintaksisi orqali yoziladi.
  • Primitivlar, unionlar, tuplar va obyektlar uchun ham bemalol ishlatiladi.
TypeScript Kodi 
type ID = string | number;
type FoydalanuvchiRoli = "admin" | "moderator" | "talaba";

let joriyRol: FoydalanuvchiRoli = "talaba";
// joriyRol = "boshliq"; // XATO! Faqat ko'rsatilgan 3 ta so'zdan biri bo'lishi mumkin.

✨ Literal tiplar (aniq so'zlar to'plami) yaratishda type juda qulay.

Xavfsizlik TS Mavzu #14

Readonly (Faqat O'qish Uchun)

Obyekt xususiyatlarini faqat bir marta boshida yaratish va keyinchalik uni o'zgartirishni taqiqlash.

  • Xususiyat oldiga readonly so'zi qo'yiladi.
  • Massivlar uchun: ReadonlyArray<number>.
TypeScript Kodi 
interface Konfiguratsiya {
  readonly apiKey: string;
  readonly port: number;
}

const config: Konfiguratsiya = {
  apiKey: "AIzaSySecretKey",
  port: 8080
};

// config.port = 3000; // XATO: Cannot assign to 'port' because it is a read-only property
📺 Natija:
🔒 Tizim sozlamalari va o'zgarmas bazaviy konfiguratsiyalar uchun readonly majburiydir.

extends (Interfeysni Kengaytirish)

Mavjud interfeysning barcha qoidalarini yangi interfeysga meros qilib o'tkazish.

Ilg'or TS Mavzu #17

Generics (Umumlashgan Tiplar )

TypeScriptning eng qudratli imkoniyatlaridan biri bo'lib, har xil tiplar bilan birdek ishlay oladigan universal funksiya va sinflar yaratish imkonini beradi.

  • Burchakli qavsda o'zgaruvchi tip belgilanadi: <T> (Type so'zidan).
  • any dan farqi: u uzatilgan turning o'zini to'liq eslab qoladi.
TypeScript Kodi 
function birinchisiniOlish<T>(massiv: T[]): T {
  return massiv[0];
}

const son = birinchisiniOlish<number>([10, 20, 30]); // number
const matn = birinchisiniOlish<string>(["Salom", "Dunyo"]); // string
📺 Natija:
🌟 Reactda useState<string>("") yozganingizda aynan Generics dan foydalanasiz!

Funksiyalar TS Mavzu #18

Function Overloading (Haddan Tashqari Yuklash)

Bitta funksiya turli xil parametrlar to'plami bilan chaqirilganda har xil turdagi natijalar qaytarishi mumkinligini e'lon qilish.

  • Bir nechta deklaratsiya imzolari va bitta umumiy realizatsiya tanasi yoziladi.
TypeScript Kodi 
function birlashtir(a: string, b: string): string;
function birlashtir(a: number, b: number): number;
function birlashtir(a: any, b: any): any {
  return a + b;
}

console.log(birlashtir("Salom ", "O'zbekiston")); // "Salom O'zbekiston"
console.log(birlashtir(50, 50)); // 100
📺 Natija:
💡 Foydalanuvchiga turli xil parametrlar berish imkonini taqdim etuvchi qulay vosita.

OOP TS Mavzu #19

TypeScript Classes (Sinflar)

TypeScriptda sinflar qat'iy tiplash, konstruktorlar va xususiyatlar bilan to'liq qurollangan.

  • Xususiyatlar konstruktordan oldin e'lon qilinishi shart.
  • Metodlar va ularning parametrlariga ham tiplar beriladi.
TypeScript Kodi 
class Talaba {
  ism: string;
  kurs: number;

  constructor(ism: string, kurs: number) {
    this.ism = ism;
    this.kurs = kurs;
  }

  malumot(): string {
    return `${this.ism} ${this.kurs}-kurs talabasi`;
  }
}

const t1 = new Talaba("Javohir", 3);
📺 Natija:
📌 TypeScript sinflari toza JavaScript kodiga (ES6 class yoki ES5 function prototype) kompilyatsiya bo'ladi.

OOP TS Mavzu #20

Access Modifiers (public, private, protected)

Sinf maydonlari va metodlarining tashqi dunyodan himoyalanish darajasi.

  • public: hamma joydan erkin foydalanish mumkin (standart holat).
  • private: faqat shu sinfning o'z ichida ko'rinadi (tashqaridan o'zgartirib bo'lmaydi).
  • protected: shu sinf va undan meros olgan bolalar sinflarida ko'rinadi.
TypeScript Kodi 
class BankHisobi {
  public egasi: string;
  private balans: number;

  constructor(egasi: string, balans: number) {
    this.egasi = egasi;
    this.balans = balans;
  }

  public balansniKorish(): number {
    return this.balans;
  }
}

const hisob = new BankHisobi("Alisher", 5000);
// console.log(hisob.balans); // XATO: 'balans' is private!
📺 Natija:
🔒 Ma'lumotlar xavfsizligi va inkapsulyatsiyaning asosi hisoblanadi.

OOP TS Mavzu #21

Abstract Classes (Abstrakt Sinflar)

O'zidan to'g'ridan-to'g'ri obyekt yaratib bo'lmaydigan, faqat boshqa sinflar uchun andoza (baza) bo'lib xizmat qiluvchi sinflar.

  • abstract class kalit so'zi bilan belgilanadi.
  • abstract metodlar bolalar sinfida majburiy ravishda realizatsiya qilinishi shart.
TypeScript Kodi 
abstract class Shakl {
  abstract maydonniHisobla(): number;
}

class Tortburchak extends Shakl {
  constructor(public eni: number, public boyi: number) { super(); }
  maydonniHisobla(): number {
    return this.eni * this.boyi;
  }
}
📺 Natija:
💡 Barcha bolalar sinflari ma'lum bir metodga ega bo'lishini qat'iy majburlash uchun ishlatiladi.

Standart Tiplar TS Mavzu #24

Utility Types (Yordamchi Tiplar)

Mavjud tiplardan yangi hosilaviy tiplar yasash uchun TypeScript ichida o'rnatilgan tayyor yordamchilar.

  • Partial<T>: barcha maydonlarni ixtiyoriy (optional) qiladi.
  • Required<T>: barcha maydonlarni majburiy qiladi.
  • Pick<T, 'maydon1' | 'maydon2'>: faqat kerakli maydonlarni tanlab oladi.
  • Omit<T, 'parol'>: ko'rsatilgan maydonni o'chirib, qolganlarini oladi.
TypeScript Kodi 
interface Foydalanuvchi {
  id: number;
  ism: string;
  email: string;
  parol: string;
}

// Parolsiz ochiq profil
type OchiqProfil = Omit<Foydalanuvchi, "parol">;
📺 Natija:
🚀 Utility types kodni takroran yozishdan asraydi va yuzlab qator ortiqcha interfeyslardan xalos qiladi.

Chuqurlashtirilgan TS Mavzu #25

Conditional Types (Shartli Tiplar)

Tiplar darajasidagi ternar operator (T extends U ? X : Y).

TypeScript Kodi 
type Matnmi<T> = T extends string ? "Ha, bu matn" : "Yo'q, boshqa tip";

type Test1 = Matnmi<string>; // "Ha, bu matn"
type Test2 = Matnmi<number>; // "Yo'q, boshqa tip"
📺 Natija:
💡 Katta kutubxona va freymvork mualliflari tomonidan murakkab tiplarni loyihalashda ishlatiladi.

Chuqurlashtirilgan TS Mavzu #26

Mapped Types (Akslantirilgan Tiplar)

Mavjud tipdagi har bir kalit ustida aylanib chiqib, uning xususiyatlarini yangicha shaklga keltirish.

  • Sintaksis: [K in keyof T].

  [K in keyof T]: string;

ES2021 TS Mavzu #27

Template Literal Types

Matnli literal tiplarni xuddi JavaScript template literallari kabi birlashtirish.

  • Kombinatsiyalangan hodisalar nomlarini yaratish uchun qulay: `on${Capitalize<Hodisa>}`.
TypeScript Kodi 
type Holat = "boshlandi" | "tugadi";
type Xabar = `kurs_${Holat}`; // "kurs_boshlandi" | "kurs_tugadi"

Arxitektura TS Mavzu #28

TypeScript Modullari

Katta dasturlarni bir nechta mustaqil fayllarga bo'lib, ular orasida tiplar va kodlarni almashish.

  • export interface ... va import { ... } from './fayl'.
  • import type { ... }: faqat tiplarni import qilish (JS kodiga kirmaydi, fayl hajmi kamayadi).
TypeScript Kodi 
// types.ts faylida:
// export interface Kurs { id: number; nomi: string; }

// app.ts faylida:
// import type { Kurs } from './types';
📺 Natija:
⚡ import type orqali import qilingan narsalar yakuniy JavaScript faylida butunlay tozalab tashlanadi.
