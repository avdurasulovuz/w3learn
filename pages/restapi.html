REST API Nima?

⏱ 10 daqiqa 🟡 O'rta 👁 21,300 marta ko'rilgan

REST (Representational State Transfer) — veb xizmatlarni loyihalash arxitektura uslubi. API (Application Programming Interface) — dasturlar o'rtasida ma'lumot almashish interfeysi.

REST API orqali frontend (brauzer/mobil ilova) va backend server o'rtasida HTTP protokoli yordamida ma'lumotlar almashiladi.

💡 REST prinsiplari: Stateless (holatsiz), Client-Server, Cacheable (keshlanishi mumkin), Uniform Interface (bir xil interfeys), Layered System.

HTTP Asoslari

REST API HTTP protokoli ustida ishlaydi. So'rov va javob tuzilmasi:

http 
### HTTP SO'ROV (Request)
GET /api/users/1 HTTP/1.1
Host: example.com
Authorization: Bearer eyJhbGc...
Content-Type: application/json
Accept: application/json

### HTTP JAVOB (Response)
HTTP/1.1 200 OK
Content-Type: application/json
X-RateLimit-Remaining: 99

{
  "id": 1,
  "name": "Ali Karimov",
  "email": "ali@example.com",
  "createdAt": "2024-01-15T10:30:00Z"
}

URL Tuzilmasi

REST API URL lari resurs nomlaridan (ot) iborat bo'lishi kerak:

http 
# ✅ TO'G'RI — ko'plik ot, kichik harf
GET    /api/v1/users          # Barcha foydalanuvchilar
GET    /api/v1/users/42       # Bitta foydalanuvchi
POST   /api/v1/users          # Yangi foydalanuvchi
PUT    /api/v1/users/42       # Yangilash
DELETE /api/v1/users/42       # O'chirish

# Ichma-ich resurslar
GET    /api/v1/users/42/posts       # Foydalanuvchi postlari
GET    /api/v1/users/42/posts/5     # Bitta post

# ❌ NOTO'G'RI — fe'l ishlatish
GET /api/getUsers
POST /api/createUser
DELETE /api/deleteUser/42

GET — Ma'lumot Olish

javascript 
// JavaScript Fetch API bilan GET so'rov
const getUsers = async () => {
  const response = await fetch('https://api.example.com/users', {
    method: 'GET',
    headers: {
      'Authorization': 'Bearer ' + token,
      'Content-Type': 'application/json'
    }
  });

  if (!response.ok) {
    throw new Error(`HTTP xato: ${response.status}`);
  }

  const data = await response.json();
  console.log(data);
};

// Axios bilan (npm install axios)
const { data } = await axios.get('/api/users', {
  params: { page: 1, limit: 10 },
  headers: { Authorization: `Bearer ${token}` }
});

// curl bilan (terminal)
// curl -H "Authorization: Bearer TOKEN" https://api.example.com/users

POST — Yangi Ma'lumot Yaratish

javascript 
// POST — yangi foydalanuvchi yaratish
const createUser = async (userData) => {
  const response = await fetch('/api/users', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': 'Bearer ' + token
    },
    body: JSON.stringify({
      name: 'Ali Karimov',
      email: 'ali@example.com',
      password: 'SecurePass123'
    })
  });

  const newUser = await response.json();
  // Javob: { id: 123, name: 'Ali Karimov', ... }
  console.log('Yaratildi:', newUser);
};

// PUT — to'liq yangilash
await fetch('/api/users/123', {
  method: 'PUT',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ name: 'Vali', email: 'vali@example.com' })
});

// PATCH — qisman yangilash
await fetch('/api/users/123', {
  method: 'PATCH',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ name: 'Yangi Ism' }) // faqat ismni o'zgartirish
});

// DELETE
await fetch('/api/users/123', { method: 'DELETE' });

HTTP Status Kodlar

http 
### 2xx — MUVAFFAQIYAT
200 OK            # GET, PUT, PATCH muvaffaqiyatli
201 Created       # POST — yangi resurs yaratildi
204 No Content    # DELETE — o'chirildi, javob yo'q

### 3xx — YO'NALTIRISH
301 Moved Permanently  # Doimiy ko'chirish
302 Found              # Vaqtinchalik ko'chirish
304 Not Modified       # Kesh ishlatildi

### 4xx — MIJOZ XATOSI
400 Bad Request        # Noto'g'ri so'rov (validatsiya xatosi)
401 Unauthorized       # Autentifikatsiya kerak
403 Forbidden          # Ruxsat yo'q (autentifikatsiya bor, lekin huquq yo'q)
404 Not Found          # Resurs topilmadi
405 Method Not Allowed # Bu URL da bu metod yo'q
409 Conflict           # Ziddiyat (email allaqachon mavjud)
422 Unprocessable      # Ma'lumot formati noto'g'ri
429 Too Many Requests  # Rate limit oshib ketdi

### 5xx — SERVER XATOSI
500 Internal Server Error  # Umumiy server xatosi
502 Bad Gateway            # Proksi xatosi
503 Service Unavailable    # Server vaqtincha ishlamayapti

JWT Autentifikatsiya

JWT (JSON Web Token) — API autentifikatsiyasining eng keng tarqalgan usuli:

javascript 
// 1. LOGIN — token olish
const login = async () => {
  const res = await fetch('/api/auth/login', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ email: 'ali@gmail.com', password: '1234' })
  });
  const { token } = await res.json();
  localStorage.setItem('token', token);
  // token: "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
};

// 2. TOKEN BILAN SO'ROV
const getProfile = async () => {
  const token = localStorage.getItem('token');
  const res = await fetch('/api/users/me', {
    headers: { 'Authorization': `Bearer ${token}` }
  });
  return res.json();
};

// Node.js da JWT yaratish (jsonwebtoken)
const jwt = require('jsonwebtoken');

// Token yaratish
const token = jwt.sign(
  { userId: 42, role: 'admin' },   // payload
  process.env.JWT_SECRET,           // maxfiy kalit
  { expiresIn: '7d' }              // muddati
);

// Tokenni tekshirish
const decoded = jwt.verify(token, process.env.JWT_SECRET);
console.log(decoded); // { userId: 42, role: 'admin', iat: ..., exp: ... }

CORS

CORS (Cross-Origin Resource Sharing) — boshqa domaindan API ga so'rov yuborishga ruxsat berish:

javascript 
// Express.js da CORS sozlash
const cors = require('cors');

// Barcha domenlar uchun (development)
app.use(cors());

// Faqat ruxsat etilgan domenlar (production)
app.use(cors({
  origin: ['https://myapp.uz', 'https://www.myapp.uz'],
  methods: ['GET', 'POST', 'PUT', 'DELETE'],
  allowedHeaders: ['Content-Type', 'Authorization'],
  credentials: true  // cookie/session uchun
}));

// HTTP sarlavhalari qo'lda qo'shish
app.use((req, res, next) => {
  res.header('Access-Control-Allow-Origin', 'https://myapp.uz');
  res.header('Access-Control-Allow-Methods', 'GET,POST,PUT,DELETE');
  res.header('Access-Control-Allow-Headers', 'Content-Type, Authorization');
  next();
});

Pagination va Filtering

http 
# Pagination (sahifalash)
GET /api/users?page=2&limit=20
GET /api/users?offset=40&limit=20

# Javob formati
{
  "data": [...],
  "pagination": {
    "total": 150,
    "page": 2,
    "limit": 20,
    "totalPages": 8,
    "hasNext": true,
    "hasPrev": true
  }
}

# Filtering (filtrlash)
GET /api/products?category=electronics&minPrice=100&maxPrice=500
GET /api/users?role=admin&status=active

# Sorting (tartiblash)
GET /api/products?sortBy=price&order=asc
GET /api/users?sortBy=createdAt&order=desc

# Qidirish
GET /api/products?search=iphone

# Maydonlarni tanlash (sparse fieldsets)
GET /api/users?fields=id,name,email
