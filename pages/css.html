CSS Nima?

⏱ 6 daqiqa 🟢 Boshlang'ich 👁 12,840 marta ko'rilgan

CSS (Cascading Style Sheets) — HTML elementlariga dizayn, rang, o'lcham va joylashuv beruvchi til. CSS orqali sahifangizni chiroyli va jozibali qilasiz.

CSS HTML faylga 3 usulda ulanadi: Inline (teg ichida), Internal (<style> teg orqali) va External (alohida .css fayl).

💡 Eslatma: "Cascading" so'zi CSS da stillar qanday ustun kelishini bildiradi — pastki qator yuqorisini bekor qiladi.

CSS Sintaksisi

CSS 
<style>
  h1 {
    color: #04AA6D;
    font-size: 36px;
    text-align: center;
  }
  p {
    background-color: #f0f0f0;
    padding: 15px;
    border-radius: 8px;
    font-size: 16px;
    line-height: 1.6;
  }
  .ajratilgan {
    color: #E91E63;
    font-weight: bold;
    text-decoration: underline;
  }
</style>
<h1>Salom, CSS!</h1>
<p>Bu <span class="ajratilgan">CSS bilan</span> stilini o'zgartirgan paragraf.</p>

Flexbox

Flexbox — elementlarni qator yoki ustun bo'yicha tartiblashtirish uchun eng qulay CSS vositasi.

CSS 
<style>
  .flex-container {
    display: flex;
    gap: 12px;
    justify-content: center;
    align-items: center;
    padding: 20px;
    background: #f5f5f5;
    border-radius: 8px;
  }
  .flex-item {
    background: #04AA6D;
    color: white;
    padding: 20px 28px;
    border-radius: 8px;
    font-weight: bold;
    font-size: 18px;
  }
  .flex-item:nth-child(2) { background: #2196F3; }
  .flex-item:nth-child(3) { background: #E91E63; }
</style>
<div class="flex-container">
  <div class="flex-item">1</div>
  <div class="flex-item">2</div>
  <div class="flex-item">3</div>
</div>

CSS Animatsiyalar

CSS 
<style>
  @keyframes sakrash {
    0%   { transform: translateY(0); background: #04AA6D; }
    50%  { transform: translateY(-30px); background: #E91E63; }
    100% { transform: translateY(0); background: #04AA6D; }
  }
  .animatsiya-box {
    width: 80px; height: 80px;
    background: #04AA6D;
    border-radius: 12px;
    margin: 20px auto;
    animation: sakrash 1.5s infinite ease-in-out;
  }
  p { text-align: center; color: #555; }
</style>
<div class="animatsiya-box"></div>
<p>⬆️ Animatsiya ishlayapti!</p>
