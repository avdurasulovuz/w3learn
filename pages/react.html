Asosiy React Mavzu #1

React Nima?

React — Meta (Facebook) kompaniyasi tomonidan yaratilgan, zamonaviy va tezkor foydalanuvchi interfeyslari (UI) yaratishga mo'ljallangan eng mashhur JavaScript kutubxonasidir.

  • Komponentlarga asoslangan (Component-Based): butun interfeys alohida, mustaqil va qayta ishlatiluvchi g'ishtchalarga bo'linadi.
  • Virtual DOM: faqat o'zgargan elementnigina qayta chizadi (re-render), shuning uchun juda tez ishlaydi.
  • Deklarativ (Declarative): siz faqat natija qanday ko'rinishi kerakligini aytasiz, brauzer bilan ishlashni React o'zi hal qiladi.
React & JSX Kodi 
// React oddiy komponenti
function Salom() {
  return (
    <div style={{ background: '#0f172a', color: '#61dafb', padding: '15px', borderRadius: '8px' }}>
      <h2>Salom, React Dunyosi! ⚛️</h2>
      <p>React yordamida interfeyslar yaratish juda oson.</p>
    </div>
  );
}
📺 Natija:
💡 Dunyodagi eng mashhur saytlar: Instagram, Facebook, Netflix, Airbnb aynan React ustiga qurilgan.
O'rnatish React Mavzu #2

React O'rnatish (Vite va CRA)

Yangi React loyihasini kompyuterda boshlash uchun Node.js o'rnatilgan bo'lishi kerak.

  • Vite (Tavsiya etiladi): zamonaviy, bir soniyada ochiluvchi o'ta tez vosita: npm create vite@latest mening-app -- --template react
  • Loyihaga kirish va ishga tushirish: cd mening-app && npm install && npm run dev
  • Create React App (CRA): eskiroq klassik usul (hozirda Vite tavsiya etiladi).
React & JSX Kodi 
// Terminalda 3 ta buyruq:
// 1. Yangi loyiha ochish:
// npm create vite@latest mening-app -- --template react

// 2. Kutubxonalarni yuklash:
// cd mening-app
// npm install

// 3. Ishga tushirish:
// npm run dev
📺 Natija:
⚡ Vite bilan loyihani ishga tushirish atigi 300 millisekund vaqt oladi!
Tuzilma React Mavzu #3

React Loyiha Tuzilmasi

React loyihasining ichidagi asosiy papka va fayllarning vazifalari.

  • node_modules/: barcha tashqi o'rnatilgan kutubxonalar saqlanadigan papka.
  • public/: rasm va faviconlar kabi statik fayllar.
  • src/: asosiy kodlar yoziladigan yurak qismi.
  • src/App.jsx: asosiy bosh komponent.
  • src/main.jsx: Reactni haqiqiy HTML sahifaga (root elementga) ulovchi fayl.
  • package.json: loyihaning passporti (nomi, versiyasi, paketlar).
React & JSX Kodi 
// src/main.jsx
import React from 'react'
import ReactDOM from 'react-dom/client'
import App from './App.jsx'

ReactDOM.createRoot(document.getElementById('root')).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>
)
📺 Natija:
📌 Butun React ilovangiz index.html dagi yagona <div id="root"></div> ichiga render qilinadi.
Asoslar React Mavzu #4

JSX Nima? (JavaScript XML)

JSX — bu JavaScript kodining ichida xuddi HTML kabi teglarni to'g'ridan-to'g'ri yozish imkonini beruvchi sintaksisdir.

  • JSX na toza HTML, na toza JavaScript emas.
  • Babel kompilyatori uni React.createElement() funksiyalariga aylantirib beradi.
  • Kodni vizual tushunishni nihoyatda osonlashtiradi.
React & JSX Kodi 
// JSX kodi:
const element = <h1 className="sarlavha">Salom, JSX!</h1>;

// Orqa fonda u quyidagiga aylanadi:
// const element = React.createElement('h1', {className: 'sarlavha'}, 'Salom, JSX!');
📺 Natija:
💡 JSX tufayli HTML va JavaScript mantiqini bitta fayl ichida uyg'un holda yozish mumkin bo'ldi.
Sintaksis React Mavzu #5

JSX Asosiy Qoidalari

JSX da yozayotganda qat'iy amal qilinishi kerak bo'lgan bir nechta muhim qoidalar mavjud.

  • Yagona ota element: komponent har doim bitta umumiy ota teg yoki Fragment (<> ... </>) ichida bo'lishi shart.
  • Barcha teglar yopilishi shart: hatto <img />, <br />, <input /> ham /> bilan yopilishi lozim.
  • camelCase nomlar: onclick o'rniga onClick, tabindex o'rniga tabIndex.
React & JSX Kodi 
function MeningSahifam() {
  return (
    <>
      <h2>Fragment ichidagi sarlavha</h2>
      <p>Ikkita teg bitta ota fragmentda o'ralgan.</p>
      <input type="text" placeholder="Yopiq input" />
    </>
  );
}
📺 Natija:
⚠️ <>...</> (React Fragment) DOMga ortiqcha div qo'shmasdan elementlarni guruhlash imkonini beradi.
Sintaksis React Mavzu #6

JSX da JavaScript Ifodalari ({ })

JSX ichida istalgan JavaScript o'zgaruvchisi, matematik hisob-kitob yoki funksiyani ishlatish uchun jingalak qavs { } qo'yiladi.

  • Jingalak qavs ichiga istalgan JS ifodasini (expression) yozish mumkin.
  • O'zgaruvchi qiymatini chiqarish: <h1>Salom, {ism}!</h1>.
  • Matematik amal: <p>Natija: {5 * 10}</p>.
React & JSX Kodi 
function Hisoblagich() {
  const foydalanuvchi = "Malika";
  const ball = 95;

  return (
    <div>
      <h3>Talaba: {foydalanuvchi}</h3>
      <p>Foiz natijasi: {ball}% — {ball >= 70 ? 'O'tdi ✅' : 'Qayta topshirish ❌'}</p>
    </div>
  );
}
📺 Natija:
✨ Jingalak qavs ichida if/else yozib bo'lmaydi, lekin ternar operator (? :) yoki && bemalol ishlaydi.
Sintaksis React Mavzu #7

JSX Atributlari (className va htmlFor)

JavaScriptda class va for maxfiy so'zlar bo'lgani sababli, JSX da ularning o'rniga maxsus nomlar ishlatiladi.

  • class o'rniga className yoziladi.
  • for o'rniga htmlFor yoziladi.
  • Inline stillar ob'ekt ko'rinishida beriladi: style={{ color: 'red', fontSize: '20px' }}.
React & JSX Kodi 
<div className="card-box" style={{ background: '#1e293b', padding: '15px', borderRadius: '8px' }}>
  <label htmlFor="userEmail" style={{ color: '#04AA6D' }}>Email:</label>
  <input id="userEmail" className="input-field" type="email" />
</div>
📺 Natija:
📌 Inline CSSda ikkita jingalak qavs {{ }} bo'lishi sababi: tashqi qavs JSX ifodasi, ichkisi esa oddiy JS ob'ektidir.

Ma'lumot Oqimi React Mavzu #10

Props (Parametrlar)

Props (Properties) — ota komponentdan bola komponentga ma'lumot uzatishning yagona usulidir.

  • Props faqat yuqoridan pastga qarab oqadi (Unidirectional Data Flow).
  • Read-Only: Bola komponent o'ziga kelgan propsni o'zgartira olmaydi (faqat o'qiy oladi).
  • Destructuring orqali qabul qilish juda qulay: function Karta({ sarlavha, narx }).
React & JSX Kodi 
function Mahsulot({ nomi, narxi }) {
  return (
    <div style={{ background: '#1e293b', padding: '10px', margin: '6px 0', borderRadius: '4px' }}>
      <strong>{nomi}</strong> — <span style={{ color: '#04AA6D' }}>${narxi}</span>
    </div>
  );
}

// Ishlatilishi:
// <Mahsulot nomi="Noutbuk" narxi={850} />
// <Mahsulot nomi="Sichqoncha" narxi={25} />

✨ Props yordamida bitta komponentni yuzlab turli xil ma'lumotlar bilan qayta-qayta ishlatish mumkin.

Hooklar React Mavzu #13

useState Hook (Holat Boshqaruvi)

Komponent ichida o'zgaruvchi ma'lumotlarni (state) saqlash va ular o'zgarganda ekranni avtomatik qayta chizish uchun eng ko'p ishlatiladigan hook.

  • Sintaksis: const [qiymat, setQiymat] = useState(boshlangichQiymat);
  • setQiymat() chaqirilishi bilan React komponentni yangi qiymat bilan qayta render qiladi.
  • Hech qachon qiymat = 5 deb to'g'ridan-to'g'ri o'zgartirmang, faqat setter funksiya orqali o'zgartiring!
React & JSX Kodi 
import { useState } from 'react';

function Hisoblagich() {
  const [son, setSon] = useState(0);

  return (
    <div>
      <h3>Hisob: {son}</h3>
      <button onClick={() => setSon(son + 1)} style={{ background: '#04AA6D', color: '#fff', border: 'none', padding: '6px 12px', borderRadius: '4px' }}>
        +1 Qo'shish
      </button>
    </div>
  );
}
📺 Natija:
🌟 Reactning sehri aynan shu yerda: ma'lumot o'zgarsa, interfeys bir zumda o'z-o'zidan yangilanadi!
Hooklar React Mavzu #14

useEffect Hook (Yon Ta'sirlar)

Serverdan API orqali ma'lumot tortish, taymerlar o'rnatish yoki DOM bilan to'g'ridan-to'g'ri ishlash (Side Effects) uchun ishlatiladi.

  • useEffect(() => { ... }, [dependencies]);
  • Bo'sh massiv []: kod faqat komponent ekranga chiqqanda bir marta ishlaydi (mount).
  • Tozalash (cleanup): komponent yopilganda taymerlarni o'chirish uchun funksiya qaytariladi.
React & JSX Kodi 
import { useState, useEffect } from 'react';

function Foydalanuvchilar() {
  const [data, setData] = useState([]);

  useEffect(() => {
    fetch('https://jsonplaceholder.typicode.com/users')
      .then(res => res.json())
      .then(users => setData(users));
  }, []); // Faqat bir marta ishlaydi!

  return <div>Yuklangan foydalanuvchilar soni: {data.length}</div>;
}
📺 Natija:
⚠️ [] bog'liqliklar massivini qo'yishni unutsangiz, cheksiz so'rovlar tsikli yuzaga kelib serveringizni qulatishi mumkin!
Hooklar React Mavzu #15

useContext Hook (Global Holat)

Ma'lumotni o'rtadagi komponentlarga birma-bir props orqali uzatib o'tirmasdan (Prop Drilling siz), to'g'ridan-to'g'ri istalgan bola komponentga yetkazish.

  • Sayt tili (O'zbek/Rus), Tungi rejim (Dark/Light) va Autentifikatsiya (Login/User) uchun ideal yechim.
React & JSX Kodi 
import { createContext, useContext } from 'react';

const MavzuContext = createContext('dark');

function Sahifa() {
  const mavzu = useContext(MavzuContext);
  return <div>Joriy rejim: {mavzu}</div>;
}
📺 Natija:
💡 Prop Drilling (propslarni 5 ta qavat pastga behuda uzatish) dardiga eng sodda davo — bu useContext.
Hooklar React Mavzu #16

useRef Hook

Qayta render chaqirmasdan o'zgaruvchi qiymatni saqlash yoki haqiqiy DOM elementiga to'g'ridan-to'g'ri bog'lanish (masalan, inputga fokus berish).

  • const myRef = useRef(boshlangich);
  • Qiymat myRef.current ichida yotadi.
  • inputRef.current.focus() — maydonni faollashtirish.
React & JSX Kodi 
import { useRef } from 'react';

function QidiruvMaydoni() {
  const inputRef = useRef(null);

  const fokusBer = () => {
    inputRef.current.focus();
  };

  return (
    <div>
      <input ref={inputRef} type="text" placeholder="Qidiruv..." />
      <button onClick={fokusBer}>Klaviatura Fokusini Ochish</button>
    </div>
  );
}
📺 Natija:
📌 useRef qiymati o'zgarganda komponent qayta render bo'lmaydi.
Optimizatsiya React Mavzu #17

useMemo Hook (Optimizatsiya)

Og'ir va sekin ishlaydigan matematik hisob-kitoblar natijasini xotiraga saqlab qolish (memoizatsiya) va behuda qayta hisoblashdan saqlanish.

  • Faqat bog'liq bo'lgan parametrlar o'zgargandagina qayta hisoblaydi.
React & JSX Kodi 
import { useMemo } from 'react';

function Saralash({ royxat }) {
  const saralangan = useMemo(() => {
    return royxat.sort((a, b) => b.ball - a.ball);
  }, [royxat]);

  return <div>Top natija: {saralangan[0]?.ism}</div>;
}
📺 Natija:
⚡ Har bir narsaga useMemo ishlatavermang, faqatgina haqiqatan og'ir operatsiyalardagina samara beradi.
Optimizatsiya React Mavzu #18

useCallback Hook

Komponent har safar qayta render bo'lganda funksiyaning xotirada qaytadan yangi obyekt bo'lib yaratilishini oldini olish.

  • Funksiyaning o'zini keshlab oladi.
  • Bola komponentlarga parametr sifatida funksiya uzatganda uning behuda render bo'lishidan asraydi.
React & JSX Kodi 
import { useCallback } from 'react';

function Asosiy({ id }) {
  const ochirish = useCallback(() => {
    console.log("O'chirildi:", id);
  }, [id]);

  return <Tugma onClick={ochirish} />;
}
📺 Natija:
💡 useMemo hisoblangan qiymatni saqlasa, useCallback funksiyaning o'zini saqlaydi.
Modullik React Mavzu #19

Custom Hooklar (O'z Shaxsiy Hookingiz)

Bir nechta komponentlar o'rtasida takrorlanuvchi holat mantiqini (stateful logic) alohida ajratib olish.

  • Custom hook nomi doimo use so'zi bilan boshlanishi shart (masalan: useFetch, useWindowSize).
  • Ichida boshqa standart hooklardan erkin foydalanishi mumkin.
React & JSX Kodi 
import { useState, useEffect } from 'react';

function useOynaKengligi() {
  const [width, setWidth] = useState(window.innerWidth);
  useEffect(() => {
    const handleResize = () => setWidth(window.innerWidth);
    window.addEventListener('resize', handleResize);
    return () => window.removeEventListener('resize', handleResize);
  }, []);
  return width;
}
📺 Natija:
🚀 Kodni modulli qilish va DRY qoidasiga amal qilishning eng oliy usuli.

State Boshqaruvi Tamoyillari

function Ota() {

Global State React Mavzu #22

Context API

Katta dasturlarda alohida kutubxona o'rnatmasdan global holatni boshqarish uchun Reactning o'z ichki tizimi.

  • createContext() orqali kontekst yaratiladi.
  • <MeningContext.Provider value={...}> orqali ma'lumot taqsimlanadi.
  • Bolalar useContext() orqali uni qabul qiladi.
React & JSX Kodi 
// AuthContext orqali kirgan foydalanuvchini bilish
export const AuthContext = createContext(null);

export function AuthProvider({ children }) {
  const [user, setUser] = useState({ ism: "Dilmurod", rol: "admin" });
  return (
    <AuthContext.Provider value={{ user, setUser }}>
      {children}
    </AuthContext.Provider>
  );
}
📺 Natija:
✨ O'rta miqyosli loyihalar uchun Redux keraksiz, Context API ning o'zi to'liq yetarlidir.

Formalar React Mavzu #26

Reactda Formalar (Controlled Components)

Forma inputlarining qiymatini to'liq React statei orqali nazorat qilish.

  • value={state} va onChange={(e) => setState(e.target.value)}.
  • Har bir bosilgan klaviatura harfi React nazoratida bo'ladi.
  • Murakkab formalar uchun: React Hook Form kutubxonasi.

function Login() {
  const [email, setEmail] = useState('');

  const submit = (e) => {
    e.preventDefault();
    alert('Yuborildi: ' + email);
  };

  return (
    <form onSubmit={submit}>
      <input value={email} onChange={(e) => setEmail(e.target.value)} placeholder="Email kiriting" />
      <button type="submit">Kirish</button>
    </form>
  );
}
